## 2. วัตถุประสงค์ (Objective & Business Logic)

- **ขอบเขต:** หน้านี้คุมเฉพาะ **ระยะห่างระดับจัดหน้า** ระยะห่างภายในชิ้นงานสำเร็จรูป (ปุ่ม แท็ก การ์ด ช่องกรอก) เป็นกายวิภาคของชิ้นงานนั้น แต่ละ component มีชุดของตัวเองและมีเอกสาร Spec อยู่ที่หน้าของ component นั้น
- **เป้าหมาย:** ให้ทุกเว็บในเครือใช้จังหวะการจัดหน้าเดียวกัน และแก้ค่าที่เดียวมีผลทุกที่
- **Business logic:** ระยะห่างคือสิ่งที่ทำให้หน้าอ่านง่ายหรืออ่านยาก ถ้าปล่อยให้แต่ละหน้าพิมพ์ตัวเลขเอง เว็บเดียวกันจะมีจังหวะการหายใจไม่เท่ากัน และเวลาปรับความหนาแน่นของหน้าจะต้องไล่แก้ทีละจุด
- **คุณค่า:** ตรวจได้ว่าไม่มีค่าดิบหลุดเข้ามา และสลับความหนาแน่นทั้งชุดได้ในอนาคตโดยไม่ต้องแก้ชิ้นงานทีละตัว

## 3. ขั้นตอนการใช้งาน (Workflow)

### สำหรับ Designer
1. **ถามก่อนว่ากำลังตั้งระยะอะไร** ถ้าเป็นการจัดหน้าหรือจัด section ให้ใช้สเกลกลาง แต่ถ้าเป็นระยะภายในชิ้นงานสำเร็จรูป ให้ใช้ตัวแปรของ component นั้น
2. ตั้ง padding หรือ gap ของ auto layout แล้วผูกตัวแปรจาก collection **component** หมวด `size/space` **ห้ามพิมพ์ตัวเลขเอง**
3. เลือกขั้นตามช่วงการใช้งาน (ดูข้อ 4.2) ไม่ใช่เลือกจากความรู้สึก
4. ถ้าค่าที่ต้องการไม่มีในสเกล **แจ้งก่อน** อย่าพิมพ์ค่าดิบไปก่อน เพราะต้องไปเพิ่มขั้นในโค้ดแล้ว build ออกมา

### สำหรับ Developer
1. เรียกตัวแปรจาก CSS เช่น `padding: var(--ntg-size-space-s2-sm);` (16px)
2. ระยะห่างของปุ่มใช้ตัวที่แยกตามขนาด เช่น `var(--ntg-button-padding-left-md)` ไม่ใช่สเกลกลาง
3. **ห้ามคัดลอกตัวเลข** ตัวเลขในเอกสารมีไว้ตรวจว่าสองฝั่งตรงกันเท่านั้น
4. ต้องการเปลี่ยนค่า ให้แก้ที่ `tokens/scale/global-scale.config.mjs` แล้วรัน `npm run tokens:build` ไม่ใช่แก้ที่ Figma

### สำหรับการ sync
1. แก้ `SPACE_GROUPS` ในโค้ด แล้ว `npm run tokens:build` (ต้องได้ collision 0)
2. อัปเดตค่าตัวแปร `size/space/*` ใน Figma ให้ตรงกับผลลัพธ์ (ตอนนี้ 26 ตัว)
3. กด Publish library ไม่งั้นไฟล์อื่นยังเห็นค่าเดิม

## 4. โครงสร้างข้อมูลและ UI (Structure)

### 4.1 สามชั้น และชั้นไหนกลายเป็นตัวแปร

```
โค้ด   1. SPACE_GROUPS              s1 2..10  s2 12..28  s3 32..64  s4 72..104  s5 112..144
         ↓ npm run tokens:build      เป็นตัวแปรใน Figma ชื่อ size/space/<กลุ่ม>/<ขนาด>
โค้ด   2. สูตรต่อ component          ปุ่มใช้ base 8 step 2 ปุ่มไอคอน base 4 step 3
                                     ไม่เป็นตัวแปร เป็นวิธีคำนวณเท่านั้น
Figma  3. ค่าที่ใช้จริงของ component   button/padding/left/md = 12
                                     เป็นตัวแปร
```

**ต่างจากระบบมุมโค้งตรงชั้นที่ 1** มุมโค้งตัดสินว่าชั้นกลางไม่เป็นตัวแปร เพราะกล่องที่มีมุมโค้งเกือบทั้งหมดเป็น component อยู่แล้ว แต่ระยะห่างระดับจัดหน้าอยู่บน frame ที่ไม่ใช่ component เช่นโครง section ของเอกสารทุกหน้า ถ้าไม่มีตัวแปรกลางให้ผูก นักออกแบบจะพิมพ์ตัวเลขดิบ ซึ่งเป็นสภาพเดียวกับสีดิบที่ Definition of Done ห้ามไว้

**ชั้น 1 กับชั้น 3 แยกจากกันโดยตั้งใจ** ค่าจากสูตรของ component ไม่จำเป็นต้องตรงกับขั้นในสเกลกลาง ปัจจุบันปุ่มมีค่าที่ตรงกับสเกล 7 ค่า (2, 4, 6, 8, 10, 12, 16) และค่าที่อยู่นอกสเกล 3 ค่า (7, 13, 14) ซึ่งถูกต้องตามกติกาเพราะเป็นผลจากสูตรของปุ่มเอง **สเกลมุมโค้งกลางไม่ได้อยู่ที่หน้านี้** อยู่ที่หน้า 06 Shape หน้านี้อ้างถึงเท่านั้น

## 5. ข้อจำกัดและข้อห้าม (Constraints)

- **ห้ามพิมพ์ค่าระยะห่างเอง** ทั้งใน Figma และในโค้ด ให้ผูกตัวแปรเสมอ
- **ห้ามเอาสเกลกลางไปใช้เป็นระยะห่างภายใน component** และห้ามเอาตัวแปรของ component หนึ่งไปใช้กับอีก component หนึ่ง
- **ห้ามใช้ค่าที่ไม่มีในสเกล** สเกลนี้เป็นชุดเดิมที่ทีมออกแบบไว้ คืนกลับมาครบทั้ง 26 ค่าเมื่อ 2026-08-26
- **ห้ามเพิ่มขั้นใหม่เองโดยไม่ขออนุมัติ** ทุกขั้นที่เพิ่มคือทางเลือกที่คนต้องตัดสินใจเพิ่มขึ้นหนึ่งครั้ง
- **ห้ามแก้ค่าที่ Figma ฝ่ายเดียว** รอบถัดไปที่ build ค่าจะถูกเขียนทับ
- **ยังไม่มีชั้นชื่อตามบทบาท** เช่น `space/section` หรือ `space/card-gap` เพราะ Spectrum ทำแล้วต้องยกเลิกทั้งตระกูล และเราเคยถอยแบบเดียวกันมาแล้วกับมุมโค้ง ถ้าภายหลังพบว่ามีของหลายชิ้นต้องเท่ากันจริง ค่อยเพิ่มทีละตัว
- **ยังไม่แยกสเกล layout ออกจาก component** เพราะ Carbon เคยแยกแล้วต้องยกเลิกเนื่องจากค่าซ้ำกันทุกตัว ใช้กฎแบ่งช่วงแทน
- **ยังไม่ทำชุดค่าตาม breakpoint และยังไม่ทำโหมดความหนาแน่น** (ดูเหตุผลที่ `docs/research/spacing-scale.md` §17.7)
- **งานที่ยังค้าง** ไล่ผูกระยะห่างระดับจัดหน้าของทุกหน้า จะทยอยทำตอนถึงคิวของแต่ละหน้า และยังไม่มีเอกสาร Spec ประจำ component (ชนิดที่ 5) ซึ่งจะเปิดเป็นงานแยกหลังหน้านี้เคลียร์
- **ยังไม่มีด่านตรวจตอน build สำหรับระยะห่าง** ต่างจากมุมโค้งที่มีแล้ว ตอนนี้ถ้าใครพิมพ์ค่าระยะห่างที่ไม่มีในสเกลลงไฟล์ token จะยังผ่าน
