# Worklog 2026-07-24
> Task: [03 Typography]-[Document] อัปเดต variable จัดหน้าเอกสาร

## งานค้าง
- **ทำแม่แบบเอกสารตารางค่า** และตัวจริงของหน้าตัวอักษร ค้างเพราะโควตาเครื่องมือหมด
- **ปรับภาษาเอกสารหลัก 4 หน้า** ให้คนทั่วไปอ่านเข้าใจ รอโควตากลับมา

## งานที่ทำวันนี้
- **รื้อระบบตัวอักษรใหม่ทั้งหมด** ให้เลือกตามบทบาทแทนการจำขนาด ได้ชุดสำเร็จรูปหยิบใช้ทั้งเครือ
- **แยกฟอนต์ตามงานให้ชัด** ตัวหนึ่งสำหรับหน้าจอและหัวข้อ อีกตัวสำหรับหน้าอ่านบทความ
- **เพิ่มขนาดให้ครบทุกกลุ่ม** และนำน้ำหนักกลางมาใช้กับหัวรองและปุ่มให้ดูนุ่มขึ้น
- **เขียนคำอธิบายกำกับทุกแบบ** ว่าใช้ทำอะไรที่ไหน คนทั่วไปเลือกเองได้ไม่ต้องเดา
- **แยกหน้าโชว์ตัวอย่างออกเป็นเอกสารเดี่ยว** และจัดหน้าเอกสารหลักใหม่ตามมาตรฐาน
- **ทำค่าฝั่งออกแบบกับฝั่งโค้ดให้ตรงกัน** ตรวจครบทุกแบบ

## ผลลัพธ์
- เลือกตัวอักษรได้ตามหน้าที่ ไม่ต้องจำตัวเลขขนาด งานออกมาสม่ำเสมอทั้งเครือ
- แก้ค่ากลางจุดเดียวเปลี่ยนพร้อมกันทั้งระบบ สองฝั่งพูดภาษาเดียวกัน

## ติดปัญหา
- โควตาเครื่องมือเชื่อมไฟล์ออกแบบหมดกลางทาง ต้องรอรีเซ็ต ไม่มีของค้างครึ่ง ๆ
- ไฟล์ออกแบบถูกปรับโครงจากอีกฝั่งระหว่างทำ บทเรียนคือต้องตรวจของจริงก่อนแก้ทุกครั้ง
