# Worklog 2026-07-17
> Task: [11 Button]-[Variable Scale] Variable scale (base × scale = component size)

## งานค้าง
- สีขาวที่พิมพ์ค่าตายไว้ในต้นฉบับช่องตาราง ถ้าอยากให้สะอาดต้องแก้ที่ต้นฉบับ
- ระบบขนาดของชิ้นงานอื่น ทยอยทำตามแบบเดียวกับปุ่ม
- เอกสารภาพของปุ่มและหน้าอื่นตามผลวิจัย

## งานที่ทำวันนี้
- **วางระบบขนาดปุ่มใหม่** คิดจากขนาดเริ่มต้นแล้วเพิ่มทีละขั้น ปรับทั้งชุดได้จากจุดเดียว
- **ส่งค่าขนาดใหม่เข้าไฟล์ออกแบบ** กระจายครบทุกแบบอัตโนมัติ พร้อมจัดชื่อให้ตรงฝั่งโค้ด
- **ทำแม่แบบเอกสาร 3 ชนิด** พร้อมกฎว่าจะเขียนเอกสารต้องถามก่อนว่าใช้ชนิดไหน
- **จัดหน้าเอกสารสีกับไอคอนให้เป็นมาตรฐานเดียวกัน**
- **จัดหน้าตารางครบชุด** ชิ้นส่วนช่อง หน้าเอกสารหลัก และตัวอย่างตารางประกอบจริง

## ผลลัพธ์
- ปุ่มมี 5 ขนาด แก้ที่เดียวกระจายครบทุกแบบ
- มีแม่แบบเอกสาร 3 ชนิดพร้อมใช้กับทุกหน้า
- หน้าสี ไอคอน ตาราง มีเอกสารครบและอ่านง่ายขึ้นมาก

## ติดปัญหา
- **เข้าใจโจทย์เอกสารผิดรอบแรก** ไปยุบรวมทั้งหน้าและลบของอื่น แก้คืนครบแล้ว ได้กฎใหม่ว่าเอกสารต้องจบในกรอบเดียว
- ค่าขนาดเก่าตกค้างในไฟล์ออกแบบ ลบไม่ออกแต่ไม่มีใครใช้แล้ว
