# Worklog 2026-07-23
> Task: [03 Typography]-[Document] อัปเดต variable จัดหน้าเอกสาร

## งานค้าง
- คู่มือการใช้รูปแบบตัวอักษรแบบมีภาพประกอบทีละขั้น ตอนนี้ใส่เป็นคำอธิบายสั้นไว้ก่อน

## งานที่ทำวันนี้
- **ศึกษาระบบตัวอักษรของสื่อใหญ่** แล้ววางระบบตามหน้าที่ใช้งาน ไม่ใช่แค่แบ่งตามขนาด
- **ขยายชุดขนาดให้ครบ** เพิ่มขนาดที่ขาดพร้อมค่าระยะบรรทัดและระยะตัวอักษร
- **สร้างรูปแบบตัวอักษรตามบทบาท 40 แบบ** แบ่ง 4 หมวด หัวเรื่อง เนื้อข่าว ข้อมูลประกอบ และส่วนติดต่อผู้ใช้
- **เขียนกฎห้ามผสมเอง** ต้องเลือกจากรูปแบบที่ประกาศไว้เท่านั้น พร้อมกฎว่าฟอนต์ไหนใช้กับอะไร
- **รื้อหน้าเอกสารตัวอักษรใหม่** ให้เห็นทุกบทบาทพร้อมตัวอย่างจริงและค่ากำกับ
- **ซิงก์เข้าโค้ด** ให้ฝั่งพัฒนาเรียกใช้ได้ครบทุกแบบ

## ผลลัพธ์
- มีรูปแบบตัวอักษรตามบทบาทครบ เลือกใช้ตามงานได้ ไม่ต้องเดา
- แยกชัดว่าฟอนต์ไหนใช้กับส่วนติดต่อผู้ใช้ ฟอนต์ไหนใช้กับเนื้อข่าว
- ฝั่งโค้ดตรงกับไฟล์ออกแบบ

## ติดปัญหา
- หัวเอกสารมาตรฐานต้องสร้างจากแบบย่อย ใช้ตัวชุดรวมตรง ๆ ไม่ได้
