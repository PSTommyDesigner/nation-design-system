# Worklog 2026-07-27
> Task: [03 Typography]-[Document] อัปเดต variable จัดหน้าเอกสาร

## งานค้าง
- **ปรับภาษาเอกสารประจำหน้าทุกหน้า** หน้าไหนยังใช้ศัพท์เทคนิคมากเกินไปให้แก้เป็นภาษาทั่วไป
- **งานใหม่** แก้แอปโปรไฟล์พนักงาน

## งานที่ทำวันนี้
- **เพิ่มเอกสารชนิดใหม่ ตารางค่ากลาง** ให้สองทีมเรียกของชิ้นเดียวกันด้วยชื่อที่ตรงกัน ทำครบทุกหน้า
- **ทำการ์ดข้อมูลที่ใช้ซ้ำเป็นชิ้นสำเร็จรูป** แทนการ์ดที่วาดมือ แก้ที่ต้นแบบทีเดียวเปลี่ยนทุกที่
- **เปลี่ยนตารางในเอกสารมาใช้ช่องสำเร็จรูปจากคลังกลาง** แทนการวาดเอง
- **ปรับภาษาเอกสารหลักให้อ่านง่าย** เหลือศัพท์เทคนิคเฉพาะส่วนที่นักพัฒนาจำเป็น
- **เก็บตัวอักษรที่หลุดจากรูปแบบกลางให้ผูกครบทุกหน้า** รวมป้ายบนปุ่ม

## ผลลัพธ์
- สองทีมมีภาษากลางเรียกของตรงกัน ส่งงานไม่หลง
- การ์ดและตารางเป็นชิ้นสำเร็จรูป แก้ทีเดียวเปลี่ยนทั้งระบบ
- เอกสารอ่านง่ายขึ้นและตัวอักษรผูกรูปแบบครบ

## ติดปัญหา
- **พลาดซ้ำเรื่องเดิม** ขีดคั่นผิด วาดของเองทั้งที่มีของกลาง หัวเอกสารค้างค่าเริ่มต้น
- แก้ต้นเหตุด้วยการย้ายกฎมาเป็นรายการตรวจบังคับก่อนบอกเสร็จ เพราะบันทึกเฉย ๆ ไม่กันพลาดตอนลงมือ
