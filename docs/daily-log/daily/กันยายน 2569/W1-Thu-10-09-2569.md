## งานที่ทำวันนี้

- user ตรวจงานแท็กผ่าน ปิดการ์ดแก้สีไอคอนปิดและคุณสมบัติที่ไม่ได้ใช้
- ปิดการ์ดสถานะกดทั้งระบบที่ค้างมาตั้งแต่ 4 กันยายน พร้อมแก้สถานะและวันที่ให้ตรงกับที่ทำจริง
- เขียน worklog ย้อนของวันที่ 7 กันยายน ซึ่งมีงานจริงแต่ยังไม่ได้สร้างไฟล์ไว้
- ปิดไอคอนปิดของแท็กกลับเป็นค่าเริ่มต้นครบ 50 ชุด และพิสูจน์ว่าการผูกสีไม่ได้หายตอนซ่อน ด้วยการเปิดอ่านค่าจริงทั้งหมดแล้วปิดกลับ แทนที่จะเดาว่าปลอดภัย
- จัดเรียงชุด component หน้า 21 ให้ตรงกันทั้ง 10 ตระกูล แก้ 7 ชุด คือ Brand filled-tag ที่จัดชิดล่างชุดเดียวในหน้า และ Neutral อีก 6 ชุดที่ความกว้างหลุด
- เปิดการ์ดใหม่ 2 ใบแล้วทำจบภายในวันเดียว คือชื่อ variant หน้า 12 Buttons และตัวแปรตระกูล alt
- เปลี่ยนชื่อ variant หน้า 12 Buttons ครบ 22 ชุด 1,480 แบบ พร้อมเปลี่ยนชื่อแกน Icon only เป็น icon-only ผ่าน API ที่ Figma ย้าย instance ให้เอง
- แก้ตัวแปรตระกูล alt 8 ตัว ทั้งใน Figma และไฟล์ token ในเครื่อง แล้ว build ใหม่
- แยกคอมเมนต์ subtask งานที่ทำให้เป็น 1 วันต่อ 1 ใบ รวม 6 ใบ และเขียนใบวันที่ 3 กันยายนที่มีงานจริงแต่ไม่เคยถูก push ขึ้นไป
- รวมคอมเมนต์ subtask งานค้างจาก 2 ใบที่ขัดกันเองให้เหลือใบเดียว 18 ข้อ

- เพิ่มคุณสมบัติ icon และ icon-swap ให้แท็กครบ 50 ชุด ตามโครงที่หัวหน้าวางไว้ ผูก instance 1,395 จุด และปรับชุด Brand filled-tag กลับมาตรงกับเพื่อน
- เปลี่ยนชื่อลูกของแท็กรูปภาพจาก number เป็น image 300 จุดใน 20 ชุด ส่วนชื่อ number ในแท็กตัวเลขถูกอยู่แล้วจึงไม่แตะ
- แก้จุดคั่นในแม่แบบเอกสารหน้า 00 จำนวน 6 จุด โดยยึดถ้อยคำเดียวกับหน้า 13 ที่แก้ไปแล้ว เช่น Usage ควรและไม่ควร
- ปิดการ์ดสรุปเดือนสิงหาคมพร้อม subtask ทั้ง 2 อัน และแก้สถานะที่ค้างอยู่ในกองรับบรีฟทั้งที่งานจบไปแล้ว
- เติมกติกา worklog 3 ข้อ และแก้สคริปต์ push ให้ทำตามโครงใหม่ 1 วัน 1 คอมเมนต์ ไม่งั้นรอบ 16:30 จะยัดทุกวันกลับเป็นใบเดียว

- แยกคอมเมนต์ของการ์ดเดือนสิงหาคมเป็น 1 วัน 1 ใบ จากเดิมใบเดียว 20,421 ตัวอักษรที่มี 13 วันซ้อนกัน ได้ 14 ใบ
- แก้หัวข้อวันให้เป็นระดับบล็อก 20 ใบทั้งสองเดือน หลังพบว่าหัวข้อติดกับเนื้อหาในวันที่ไม่ได้ขึ้นต้นด้วยรายการ

- ตอบคำถามว่า Badge กับ Tag ต่างกันอย่างไร แล้วบันทึกเป็นงานวิจัยพร้อมเกณฑ์ตัดสิน 4 ข้อ สรุปว่า Badge คือของที่ระบบพูดกับผู้ใช้ ส่วน Tag คือของที่ผู้ใช้พูดกับระบบ
- สร้างระบบสเกลของป้าย ยกความสูงมาใช้ชุดเดียวกับแท็ก พร้อมด่านตรวจ 5 ข้อ ได้ token 50 ตัว
- สร้างตัวแปรใน Figma 45 ตัว ผูกครบทุกมิติ และผูก text style ให้ข้อความทั้ง 800 แบบ จากเดิมที่ไม่ได้ผูกเลยสักชุด
- หลังหัวหน้าทักว่าชื่อชนิดของแท็กกับของปุ่มไม่เข้าพวกกัน สำรวจแล้วพบต้นเหตุจริงคือสไตล์ถูกเก็บคนละชั้น ปุ่มเก็บเป็นแกน variant ส่วนแท็กกับป้ายเก็บเป็นชื่อชุด
- ยุบโครงป้ายให้ใช้แกน hierarchy ตามแบบปุ่ม จาก 140 ชุดเหลือ 40 ชุด และชื่อขนานกับปุ่มพอดี
- ทำเอกสารหน้า 22 ครบ 5 ชนิด และจัดตำแหน่งบนแคนวาสตามกติกาการเรียง
- เปิดการ์ดหน้า 21 Tags เพื่อยุบโครงแบบเดียวกัน พร้อมสำรวจไว้แล้วว่ามีคนใช้แท็กจริง 167 จุด

## ผลลัพธ์

- หน้า 21 Tags ทั้ง 130 ชุด ความกว้างเท่ากันทุกตระกูลในชนิดเดียวกัน จัดกึ่งกลางหมด และตัดบรรทัด 5 ชิ้นต่อแถวทุกชุด คือ 1 แถวเท่ากับ 1 สถานะ
- ไอคอนปิดของแท็ก 1,425 จุด ผูกตัวแปรครบ ไม่เหลือสีดิบ สแกนทั้งหน้า 15,018 ชิ้น สีดิบ 0 และไม่มีตัวคั่นขีดยาว
- หน้า 12 Buttons ตัวใหญ่เหลือ 0 variant ไม่หายสักตัว รหัสโหนดเดิมครบ 1,480 ตัว และขนาด component ต้นฉบับไม่เปลี่ยน
- ตัวแปรตระกูล alt ทั้ง 53 ตัวเดินตามกฎเดียวกันหมด ตัวหลุดเหลือ 0 build ผ่านโดยไม่มีชื่อชนกัน
- การ์ดที่ปิดวันนี้ 3 ใบ มีวันที่ครบทั้งสามค่าทุกใบ และวันเริ่มงานไม่หายตอนยิงวันเสร็จ

- แท็กทั้ง 50 ชุดมี icon และ icon-swap ครบ ค่าเริ่มต้นตรงกันหมด และ 9 ตระกูลได้ขนาด variant ตรงกันเป๊ะทุกขนาด
- แม่แบบหน้า 00 เหลือจุดกลาง 3 จุด ซึ่งอยู่ในบรรทัดรายการจริง จึงไม่ผิดกติกา และขีดยาวเป็น 0
- ขนาด COMPONENT ต้นฉบับหน้า 21 เทียบก่อนหลัง 2,625 ตัว ไม่เปลี่ยนสักตัว และทั้ง 130 ชุดยังตัดบรรทัด 5 ชิ้นต่อแถว

- คอมเมนต์สรุปเดือนทั้งสิงหาคมและกันยายน เป็น 1 วัน 1 ใบครบแล้ว ไม่มีใบไหนมีหลายวันซ้อน และ subtask งานค้างมีใบเดียวทั้งสองเดือน

- ป้ายเหลือ 40 ชุด 800 แบบ จากเดิม 140 ชุด 700 แบบ แบบเพิ่มขึ้น 100 เพราะเติมช่องที่เดิมขาดหายไปเงียบ ๆ
- ความสูงป้ายเป็น 16 20 24 28 32 เท่ากับแท็กทุกขนาด วางคู่กันในแถวเดียวได้แล้ว
- หน้า 22 สแกน 4,934 ชิ้น สีดิบ 0 ขีดยาว 0 ระยะขอบไม่ผูกตัวแปร 0 การผูกคุณสมบัติที่ขาด 0
- ยืนยันก่อนยุบว่าไม่มี instance ที่ไหนหยิบป้ายไปใช้ สแกน 51 หน้า 16,784 instance พบ 0
- แท็กต่างจากป้าย มีคนใช้จริง 167 จุด อยู่ที่หน้า 13 Input 124 จุด และหน้า 21 เอง 43 จุด

## ติดปัญหา

- Asana ตั้ง Start date เดี่ยว ๆ ไม่ได้ ต้องส่ง Due date คู่กันเสมอ ทำให้เช็คลิสต์ที่เขียนว่าให้ตั้งวันเริ่มงานตอนลงมือ ทำตามตรง ๆ ไม่ได้ ต้องยิงสองวันพร้อมกันตอนปิดแทน ยังไม่ได้เขียนลงกติกา
- subtask งานค้างเคยมี 2 คอมเมนต์ที่ขัดกันเอง เพราะตอนอัปเดตผมโพสต์ใบใหม่แทนที่จะแก้ใบเดิม กติกาปัจจุบันเขียนว่าอัปเดตให้ตรงปัจจุบัน ซึ่งยังตีความเป็นโพสต์ใบใหม่ได้
- ตัวเลขที่จดไว้ว่าตระกูล alt ไม่สอดคล้อง 10 ตัว สร้างซ้ำจากข้อมูลไม่ได้ ของจริงคือ 8 ตัวแปร 9 อาการ เพราะมีตัวหนึ่งผิดสองอย่างพร้อมกัน
- ระหว่างยุบโครงป้าย ตั้งชื่อ variant ก่อนย้ายเข้าชุดใหม่ ทำให้ Figma ตีความชื่อกับแกนของชุดเดิม ชื่อเพี้ยน 15 ตัว ต้องแก้เป็นย้ายก่อนแล้วค่อยตั้งชื่อ
- การโคลน component ทำให้การผูกคุณสมบัติหลุด 10 แบบ ซึ่งเป็นกับดักเดิมที่เคยเจอตอนทำสวิตช์ ต้องผูกกลับแบบอิงบทบาทแทนอิงชื่อชั้น
- สคริปต์ยุบโครงล้ม 2 ครั้งแรกเพราะ COMPONENT ที่ถูกดึงออกมาลอยพกคุณสมบัติของตัวเองติดไปด้วย Figma ย้อนกลับให้ครบทุกครั้ง ไม่มีอะไรค้างเสียหาย
