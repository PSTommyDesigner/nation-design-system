# W2 จันทร์ 14 กันยายน 2569

## งานค้าง

- แท็กที่มีของนำหน้า ฝั่งโทนเทาสถานะชี้ยังใช้สีเกือบดำที่ลอกมาจากตระกูล Neutral หัวหน้าสั่งให้ใช้สีเดิม แต่ยังไม่ได้ตอบว่าหมายถึงคงสีตระกูลไว้ หรือใช้สีเดียวกับสถานะปกติของฝั่งเทา รอตอบก่อนแก้ 400 แบบ
- ระยะขอบซ้ายขวาของกรอบข้อความแท็ก ตัวอักษรชิดขอบเกินไปโดยเฉพาะขนาดเล็กที่ได้ระยะรวมแค่ 7 เท่ากันสองขนาด เสนอเพิ่มเป็น 4 4 5 6 7 ซึ่งทำให้แท็กกว้างขึ้นข้างละ 2 ถึง 3 และกระทบชิ้นงานที่ใช้อยู่ 167 จุด รอยืนยันตัวเลข
- ชุดแท็กธรรมดาตระกูล Neutral สองชื่อ คือแบบมุมมนกับแบบแคปซูล ยังไม่มีแกนโทนเทา ต่างจากอีก 9 ตระกูลที่มีครบ ของเดิมเป็นแบบนี้มาก่อน ไม่ได้เกิดจากงานวันนี้ ต้องตัดสินว่าจะเติมให้เหมือนกันหรือปล่อยไว้เพราะตระกูลนี้เป็นสีเทาอยู่แล้ว

- ดาวให้คะแนนในเซลล์ตาราง 10 จุด ยังใช้ไอคอนชุดเก่า ตัดสินแล้วว่ายกเว้น ไม่ต้องแก้ เพราะเป็นชุดที่มีแกนเปอร์เซ็นต์ 11 ขั้นสำหรับดาวเติมบางส่วน ซึ่งเซ็ต Nation UI Icons ไม่มีของแทน
- เอกสารประจำหน้า ยังไม่เริ่ม 20 หน้า และหน้า 03 Typography ที่ทำครึ่งทาง
- หน้า 16 Radio กับ 17 Sliders มี component แล้วแต่ยังไม่มี token สักตัว

## งานที่ทำวันนี้

- เปิดการ์ดย้อนหลังให้งานวันศุกร์ 2 ใบ คือหน้า 15 Checkbox และเอกสารภาพรวมระบบ แล้วปิดใบเอกสารพร้อมบันทึกงาน
- จัดเอกสารที่เก็บชุดจริงของหน้า 15 ให้ตรงกับหน้า 14 ทั้งระยะขอบใน ช่องไฟ ความกว้าง และลำดับการเรียง
- เรียงแบบใหม่ให้จัดกลุ่มตามสถานะการติ๊กก่อนแล้วค่อยไล่ขนาด อ่านง่ายขึ้นและตรงกับหน้าอ้างอิง
- ตอบคำถามเรื่องควรยุบสองชุดเป็นชุดเดียวไหม โดยนับการใช้เดี่ยวของกล่องติ๊กได้ 282 จุด จึงเสนอให้คงไว้
- ตอบคำถามเรื่องสวิตช์ใช้แทนช่องติ๊กในตารางได้ไหม โดยแยกให้เห็นว่าคอลัมน์เลือกแถวกับคอลัมน์ตั้งค่าเป็นคนละงาน
- เปลี่ยนสูตรมุมโค้งของกล่องติ๊กจาก base 0 step 2 เป็น base 2 step 1 เพราะของเดิมทำให้สัดส่วนต่อขนาดกล่องห่างกันถึง 28.6 จุด ของใหม่เหลือ 4.8 จุด
- อัปเดตตัวแปรมุมโค้ง 20 ตัวและเอกสารที่อ้างค่าเดิม 6 จุดให้ตรงกัน
- เปลี่ยนชื่อชุดใหม่ กล่องเปล่าเป็น checkbox ตัวจริง และตัวที่มีข้อความเป็น text-checkbox เพราะชื่อขึ้นต้นด้วยขีดล่างทำให้ Figma ไม่ publish ออกไปไฟล์อื่น
- ตัดคุณสมบัติเปิดปิดหัวข้อออก เพราะถ้าไม่ต้องการข้อความก็ใช้ checkbox ซึ่งเป็นคนละชุดอยู่แล้ว
- เพิ่มกฎขีดล่างหน้าชื่อเข้า CLAUDE.md พร้อมเกณฑ์ว่าเมื่อไหร่ควรแยกเป็นชิ้นส่วนฐาน
- ตรวจไอคอนของหน้าที่ทำมา พบว่าหน้า 15 ใช้ไอคอนจากไลบรารีนอกไฟล์ทั้งหมด 80 จุด และหน้า 28 ผสมกัน 3 แหล่ง
- เปลี่ยนไอคอนช่องติ๊กทั้ง 80 จุดเป็นไอคอนจากเซ็ต Nation UI Icons พร้อมผูกขนาดและสีกลับครบ
- เปลี่ยนปุ่มลิงก์รุ่นเก่าที่มาจากนอกไฟล์ 4 ตัวในเซลล์ตารางชนิดไอคอน ให้เป็นปุ่มลิงก์ไอคอนตระกูล Neutral ปัจจุบัน แล้วตั้งไอคอนผ่านคุณสมบัติสลับ
- เพิ่มคุณสมบัติสลับไอคอนให้ปุ่มลิงก์ไอคอนตระกูล Error ที่ไม่มี แล้วผูกกับเลเยอร์ครบทั้ง 40 แบบ
- สแกนต่อแล้วพบว่าปัญหาการอ้างคุณสมบัติหลุดกระจายทั้งหน้า 12 รวม 19 ชุด จึงไล่แก้ให้ครบ
- ผูกคุณสมบัติสลับไอคอนที่ขาด 266 จุด และคุณสมบัติเปิดปิดไอคอนกับช่องข้อความหัวข้อที่ขาดอีก 284 จุด รวม 550 จุด
- ตรวจก่อนผูกทุกจุดว่าค่าปัจจุบันตรงกับค่าเริ่มต้นของคุณสมบัติ ได้ 550 จาก 550 จึงไม่มีอะไรเปลี่ยนหน้าตา
- ทดสอบจริงด้วยการสร้าง instance ชั่วคราว เปลี่ยนข้อความ เปิดไอคอน เปลี่ยนไอคอน แล้วสลับไปสถานะโฟกัส ผ่านครบทุกชุดที่ทดสอบ
- สแกนหน้า 13 Input หน้า 21 Tags และหน้า 22 Badge เพิ่ม ไม่พบอาการเดียวกัน
- เคลียร์ของค้างจากหน้าที่ทำมาแล้วก่อนไปหน้าใหม่ ตามที่หัวหน้าสั่ง
- แก้เอกสาร Table Space ที่ยังเขียนว่าเซลยังไม่ผูกตัวแปร ทั้งหัวข้อสรุปและหัวข้อกติกา ให้ตรงกับสถานะจริง
- แก้คำอธิบายตัวแปรมุมโค้งตาราง 4 ตัวที่อ้างเลขหน้าเก่า
- ผูกสีที่ยังดิบของหน้า 28 จำนวน 1 จุด และหน้า 12 จำนวน 23 จุด ทั้งขอบกล่องรวมชุดและข้อความหัวข้อที่ค้างเป็นสีดำ
- เปลี่ยนชื่อ component หน้า 28 ที่ยังมีขีดทับครบ 21 ตัว ให้ลงท้ายด้วยชนิดตามกฎ เช่นเซลหัวตารางและเซลข้อความ
- ไล่แก้ที่อ้างชื่อเก่าให้ครบ ทั้งข้อความในเอกสารหน้า 28 จำนวน 9 จุด กติกาใน CLAUDE.md มาตรฐานเอกสาร รายชื่อหน้า เอกสารหน้าสี และบันทึกความจำ
- ทำด่านตรวจรูปแบบคอมเมนต์การ์ดพร้อมกฎห้ามยิง API ตรง แล้วถูกสั่งยกเลิกหลังทบทวนข้อเสีย จึงถอดกฎออกทั้งหมดและกลับไปยิง API ตรงตามเดิม
- บันทึกไว้ในไฟล์กติกาว่าเคยทำแล้วถูกยกเลิกเพราะอะไร เพื่อไม่ให้เสนอซ้ำ
- เพิ่มระยะขอบของกรอบข้อความปุ่มเข้าไฟล์สูตร จากเดิมที่มีตัวแปรในไฟล์ออกแบบ 25 ตัวแต่โค้ดไม่รู้จัก พร้อมบันทึกเหตุผลว่ามีไว้ถ่วงสายตาเวลาเปิดปิดไอคอน และเขียนห้ามยุบรวมกับระยะขอบปุ่ม
- เพิ่มแกนโทนเทาให้แท็กที่มีของนำหน้าทั้ง 8 ชื่อ ครบ 10 ตระกูล รวม 80 ชุด สร้างแบบใหม่ 1,200 แบบ
- ลอกสีฝั่งเทาจากตระกูล Neutral ที่มีอยู่แล้ว ไม่ได้ตั้งสีขึ้นเอง และเว้นจุดสถานะไว้ไม่เปลี่ยนตามที่หัวหน้าสั่ง
- ผูกสีขอบของกล่องรวมชุดทั้ง 100 ชุดบนหน้า 21 ที่เดิมยังเป็นสีดิบ

## ผลลัพธ์

- หน้า 15 ไม่เหลือไอคอนนอกเซ็ตแล้วสักจุด และไม่พึ่งไลบรารีนอกไฟล์อีกต่อไป
- หน้า 28 เหลือเฉพาะดาวให้คะแนน 10 จุดที่ตัดสินว่ายกเว้น
- เซลล์ตารางชนิดไอคอนเปลี่ยนจากปุ่มนอกไฟล์ 4 ตัวเป็นของในระบบครบ และเปลี่ยนไอคอนได้ด้วยคุณสมบัติโดยไม่ต้องเจาะเข้าไปสลับเอง
- ชื่อชุดทั้งสองไม่มีขีดล่างแล้ว publish ออกไฟล์อื่นได้ทั้งคู่
- ทดสอบรอบแรกได้ผลว่าผ่านทั้งที่ยังไม่ได้แก้ เพราะจุดที่ขาดอยู่ในคอมโบเฉพาะที่ทดสอบไม่โดน บทเรียนคือต้องดูก่อนว่าจุดที่ขาดอยู่คอมโบไหน แล้วทดสอบให้ตรงคอมโบนั้น
- วิเคราะห์ผลกระทบรอบแรกได้จุดเสี่ยง 191 จุด ซึ่งเกิดจากตรรกะหาเลเยอร์ของผมผิดเอง ไม่ใช่ของจริงมีปัญหา พอแก้วิธีหาแล้วเหลือศูนย์ บทเรียนคือตัวเลขที่ดูน่าตกใจต้องตรวจวิธีวัดก่อนรายงาน
- เสนอด่านตรวจโดยยังไม่ได้ทบทวนข้อเสียให้ครบก่อน พอทบทวนแล้วพบว่ากฎห้ามยิง API ตรงปิดทางแก้คอมเมนต์ใบเดิม ซึ่งเป็นสิ่งที่เพิ่งต้องใช้จริงในวันเดียวกัน บทเรียนคือก่อนเสนอกฎที่ห้ามอะไรบางอย่าง ต้องไล่ดูก่อนว่าสิ่งที่ห้ามนั้นมีเคสจำเป็นอยู่หรือเปล่า

## ติดปัญหา

- สลับไอคอนดาวไปแล้วก่อนจะรู้ว่าเป็นชุดที่มีแกนเปอร์เซ็นต์ ทำให้สีกลายเป็นเทาและขนาดโตจาก 20 เป็น 24 เซลล์ขยายตาม จับได้เพราะดูภาพจริงหลังสลับ คืนสภาพเดิมครบแล้ว บทเรียนคือก่อนสลับต้องดูว่าไอคอนเดิมมีแกน variant ไหม ไม่ใช่ดูแค่ชื่อกับหน้าตา
- จับคู่ไอคอนจากชื่อ component ต้นทางอย่างเดียว ทำให้พลาดของที่ชื่อเลเยอร์กับต้นทางไม่ตรงกัน ต้องเทียบทั้งสองชื่อ
- รายงานตอนแรกว่าไม่มีการใช้คุณสมบัติสลับ instance เลย ซึ่งจริงเฉพาะสามหน้าที่สแกน ของจริงหน้า 12 Buttons ใช้อยู่แล้วทั้ง link-button และ link-icon-button บทเรียนคือระบุขอบเขตที่สแกนให้ชัดก่อนสรุปเป็นภาพรวม
- สลับ component แล้วชื่อเลเยอร์เดิมค้างเป็น override ต้องล้างเอง ไม่งั้นเอกสารจะอ่านแล้วเข้าใจผิดว่ายังเป็นของเก่า
