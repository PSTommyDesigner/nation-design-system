## 1. หน้า 21 Tags ปิดการ์ดแล้ว

การ์ด `[DS]-[Tags] Design เอกสารและผูกตัวแปร หน้า 21 Tags` (`1218055780210237`) เริ่ม 1 กันยายน เสร็จ 2 กันยายน สถานะ `Internal Review / Feedback` ชุดปิดงาน

### จัดเรียงใหม่ทั้ง 10 ตระกูล

จับทรงเหลี่ยมกับทรงแคปซูลของชนิดเดียวกันมาวางข้างกันเป็น 7 แถว ซ้ายขวาแบ่งครึ่งเท่ากันข้างละ 795 ตามตัวอย่างที่ user ทำไว้ จาก 14 ก้อนเหลือ 8 ก้อนต่อตระกูล ความสูงตระกูลลดจาก 7,833 เหลือ 4,402

แปลงชุด variant ที่เหลือ 117 ชุดเป็น auto layout แบบตัดบรรทัด พบว่า Figma ตัดบรรทัดเร็วไป 1 คอลัมน์เมื่อความกว้างพอดีเป๊ะ แก้ด้วยตัวตรวจนับจำนวนต่อแถวแล้วเติมความกว้างทีละพิกเซล

### เปลี่ยนชื่อ component ทั้งหมด

ตั้งกฎใหม่ว่าชื่อ COMPONENT ต้องลงท้ายด้วยชนิดของมันเสมอ ตามแบบหน้า 12 Buttons เพราะแผง Assets แสดงแค่ชื่อ ชื่ออย่าง `number` หรือ `text` ลอย ๆ เดาไม่ออกว่าเป็นอะไร

เปลี่ยน 580 จุด คือชุด 130 เฟรม section 130 หัวข้อ 130 บรรทัดนับ 130 และชื่อแถว 60 กฎเข้า CLAUDE.md แล้ว

### เรียงคอลัมน์และแถวใหม่

user ทักว่าลำดับของตระกูลอื่นผิด ตรวจแล้วพบว่าผมเรียงลูกด้วยพิกัดแนวตั้งก่อนแนวนอน แต่ผังเดิมวางแท็กชิดขอบล่าง ตัวใหญ่จึงเริ่มสูงกว่าตัวเล็ก การเรียงตามแนวตั้งเลยพลิกลำดับขนาดกลับหัวทั้งแถว

แก้คอลัมน์ที่กลับด้าน 117 ชุด และลำดับแถวที่สลับ 44 ชุด ยึด `filled-tag` ของ brand เป็นแบบ

### ผูกตัวแปรและทำความสะอาด

ผูกตัวแปรขนาดให้ 7 ตระกูลที่เหลือ 17,220 จุด ครบทั้ง 2,625 แบบ ไม่มีค่าดิบเหลือ

ปรับระยะขอบชุด filled ของ brand เป็น 40 ลบ Slice ที่ตกค้าง ลบคุณสมบัติ `default-gray` ที่ไม่ทำงานออกจาก `text-tag` ของ Neutral เปลี่ยนชื่อเลเยอร์ `Dot` `_Dot` และกรอบ `number` ที่ค้างมาผิด รวม 900 จุด

### เอกสารครบ 5 ชนิด 14 เฟรม

สร้าง `21 Tags Documentation` `Tags Token` `Tags Guide` และ `Tags Space` เพิ่มจาก Component Previews 10 ตระกูลที่มีอยู่ เรียงซ้ายไปขวาจาก x เท่ากับ 0 ระยะห่าง 200

## 2. ตัดสินเรื่องระยะขอบข้อความของปุ่มลิงก์

### ข้อตัดสิน

**ระยะขอบของ `link-button` เป็น 0 ถาวร** ด้วยเหตุผลที่วัดได้ 2 ข้อ คือใส่ซ้ายขวาแล้วตัวอักษรตัวแรกเยื้องออกจากขอบเนื้อหาที่ปุ่มวางต่อท้าย และใส่บนล่างแล้วกล่องสูงเกินบรรทัดไปดันบรรทัดอื่นในย่อหน้าเดียวกัน

### เจอบั๊กที่ซ่อนอยู่ 4 จุด

1. **กรอบไอคอนขนาด lg ของ Neutral กับ Error เป็น 24x22 ไม่ใช่ 22x22** 24 กรอบ ทำให้ปุ่ม lg ของ 2 ตระกูลนี้กว้าง 67 แทน 65 ไอคอนข้างในถูกต้องอยู่แล้ว กรอบแค่กว้างเกิน จึงมองด้วยตาไม่ออก
2. **ต้นเหตุคือกรอบ 108 ตัวหลุดการล็อกสัดส่วน** จาก 300 กรอบ มี 192 กรอบล็อกสัดส่วน 1 ต่อ 1 อยู่ ที่เหลือไม่ล็อก และตรงกับจุดที่เพี้ยนพอดี Figma ยอมให้ผูกตัวแปรได้มิติเดียวเมื่อล็อกสัดส่วน
3. **การผูกระยะขอบพันช่องพันขนาด** ตัวปุ่มทุกขนาดผูกกับ `xs` หมด และช่องขวาไปผูก `padding/left/xs` ซ้ำ ส่วนกรอบข้อความของ Brand ผูกช่องบนล่างไปที่ซ้ายขวา ทุกค่าเป็น 0 จึงไม่มีใครเห็น
4. **ตัวแปร 25 ตัวไม่มีใครใช้เลย** คือ `title-padding` 20 ตัว กับ `size` 5 ตัว สแกน 97,063 node ทุกตัวแปรทุก style ยืนยันแล้ว

### ที่แก้

ล็อกสัดส่วน 1 ต่อ 1 ทุกกรอบ 300 กรอบ แล้วผูกเฉพาะความสูง ให้ความกว้างวิ่งตามเอง ผูกระยะขอบใหม่ให้ตรงช่องตรงขนาด 800 จุด ตั้งช่องไฟ `link-icon-button` เป็น 0 ทั้ง 100 แบบ เพราะมีลูกตัวเดียว ช่องไฟไม่มีผล ลบตัวแปร 25 ตัว เหลือ 30 และใส่คำอธิบายล็อกระยะขอบ 20 ตัวว่าห้ามเปลี่ยนจาก 0

### โค้ดไม่ตรงกับ Figma

ระหว่างตรวจว่าใครใช้ชื่อ token เดิม เจอว่า `components/LinkButton/LinkButton.module.css` ใส่ระยะขอบข้อความ 4px ซ้ายขวาจาก token `title-padding` **ปุ่มลิงก์ที่ออกจากโค้ดจึงกว้างกว่าใน Figma 8 พิกเซลมาตลอด** ไม่มีใครเห็นเพราะไม่เคยเอามาวางเทียบกัน

### สร้างระบบสเกลและย้ายโค้ด

สร้าง `tokens/scale/link-button.mjs` บันทึกว่าความสูงไม่มีสูตรโดยตั้งใจ ตัวคุมจริงคือ text style ต่อขนาด และระยะขอบของไอคอนล้วนคงที่ 3 เป็นค่าที่ derive จาก (ความสูง ลบ ไอคอน) หารสอง

ย้ายโค้ดไปใช้ชื่อใหม่ `--ntg-space-link-button-*` แก้ `LinkButton.module.css` 60 จุด และ `prototype/buttons.html` 18 จุด ตัดระยะขอบข้อความ 4px ออกให้ตรงกับที่ออกแบบ ลบราก token เดิมออกจาก `component.json` แล้ว build ใหม่

ตรวจแล้วชื่อเก่าเหลือ 0 ตัวแปรที่โค้ดเรียกแล้วไม่มีจริง 0 ค่าตรงกับ Figma ทุกขนาด
