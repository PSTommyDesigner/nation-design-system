# W2 ศุกร์ 18 กันยายน 2569

## งานค้าง

- โค้ดแท็กฝั่ง React ยังอ้างตัวแปร 47 ตัวที่ไม่มีแล้ว ค้างจากเมื่อวาน ยังไม่ได้ตัดสินว่าจะเขียนสไตล์แยกตามทรงหรือให้ตัวสร้างปล่อยชื่อกลาง
- ไฟล์สูตรฝั่งโค้ดของแท็กยังไม่ได้อัปเดตเลย ตอนนี้ค่าในไฟล์ออกแบบเปลี่ยนไปเกือบทั้งหมด ทั้งบันไดความสูง ระยะขอบ ไอคอน มุมโค้งรายขนาด และมีกลุ่มใหม่เพิ่มอีกหลายกลุ่ม
- เอกสารของหน้าแท็กทั้งในไฟล์ออกแบบและในเครื่อง ยังเป็นชื่อตัวแปรและตัวเลขชุดเก่าทั้งหมด
- หน้า 22 Badge ยังไม่ได้เริ่ม หัวหน้าสั่งให้ปรับตามแท็กหลังจากแท็กนิ่ง
- ตระกูลสีเทา ชุดที่มีของนำหน้าทั้งแปดชนิดยังมีแกนโทนเทาอยู่ ต่างจากชุดฐานที่ถอดออกไปแล้ว ต้องตัดสินว่าจะถอดให้เหมือนกันไหม
- ความหนาเส้นขอบของแท็ก 360 จุดยังเป็นค่าตรง ตัดสินแล้วว่าไม่สร้างตัวแปร
- ตัวแปรความสูงของทรงแคปซูลยังค้างอยู่ที่ค่าเก่าและไม่มีใครใช้ ต้องตัดสินว่าจะลบเหมือนของทรงมุมมนไหม
- หน้า 13 Input ยังค้าง 4 ข้อรอตัดสิน เรื่องขนาดแท็กในช่อง ค่าที่ค้าง ระยะขอบ และสีดิบกับมุมโค้งบนกรอบกล่องรวมชุด
- เอกสารประจำหน้า ยังไม่เริ่ม 19 หน้า และหน้า 03 Typography ที่ทำครึ่งทาง

## งานที่ทำวันนี้

- ทำหน้าปุ่มตัวเลือกจบทั้งหน้าในวันเดียว ตั้งแต่สูตรขนาด ตัวแปร ชิ้นงาน ไปจนถึงเอกสารครบห้าชนิด
- เขียนไฟล์สูตรของปุ่มตัวเลือกโดยลอกโครงสองชั้นจากช่องติ๊ก ได้ตัวแปร 24 ตัว พร้อมด่านตรวจสี่ชั้นที่ทดสอบแล้วว่าจับได้จริง
- ขยายปุ่มตัวเลือกจากสองขนาดเป็นห้าขนาด ได้ชุดละ 40 แบบ และทำให้ความสูงตรงกับช่องติ๊กทุกขนาด จึงสลับกันในฟอร์มเดียวกันได้จริง
- ผูกตัวแปรและ text style ให้ปุ่มตัวเลือกครบทุกจุด จากเดิมที่ข้อความไม่ผูกสไตล์เลยสักตัว
- ทำเอกสารของหน้าปุ่มตัวเลือกครบเจ็ดเฟรม และเขียนไฟล์เอกสารในเครื่องพร้อมอัปเดตดัชนี
- รื้อระบบตัวแปรของหน้าแท็กทั้งหน้าตามที่หัวหน้าปรับงานออกแบบมาใหม่
- ปรับบันไดความสูงของแท็กทุกชุดให้เป็นชุดเดียวกัน โดยแก้ระยะขอบบนล่างให้เป็นค่าที่คำนวณจากความสูงเป้าหมายลบความสูงบรรทัด
- เปลี่ยนชุดทรงแคปซูลของตระกูลต้นแบบจากความสูงตายตัวเป็นหดตามเนื้อหา ทำให้ความสูงขยับตามตัวแปรได้จริง
- คัดลอกค่าตัวแปรจากทรงมุมมนมาทรงแคปซูลให้ตรงกัน ยกเว้นมุมโค้งซึ่งเป็นตัวตนของแต่ละทรง
- สร้างตัวแปรกลุ่มใหม่ให้ของนำหน้าทุกชนิด ทั้งขนาดและระยะขอบข้างใน จากเดิมที่เป็นค่าตรงไม่ผูกอะไรเลย
- ตรวจตระกูลต้นแบบครบทั้งสิบเอ็ดชุด แล้วไล่แก้จนไม่เหลือค่าตรง ค่าที่ผูกค้าง และการผูกผิดหมวด
- ตัดสินและทำกลุ่มตัวแปรของแท็กแบบลิงก์ ทั้งความสูงที่ยึดความสูงบรรทัด กลุ่มตัวแปรของตัวเอง และถอดมุมโค้งที่มองไม่เห็นออก
- โรลออกงานออกแบบจากตระกูลต้นแบบไปครบอีกสิบตระกูล
- สร้างแท็กแบบลิงก์ให้สิบตระกูลโดยก๊อปจากระดับล่างสุดเดิม ทำให้สีของแต่ละตระกูลติดมาเองไม่ต้องเดา
- ลบระดับล่างสุดออกจากชุดฐานทั้งสองทรงทุกตระกูล หลังตรวจแล้วว่าไม่มีชิ้นงานไหนอ้างถึงเลย
- จัดกลุ่มชิ้นงานใหม่ ให้แท็กแบบลิงก์มีแถวของตัวเองพร้อมหัวข้อและคำอธิบายที่ถูกต้อง เหมือนกันทุกตระกูล
- แก้บรรทัดนับจำนวนแบบของทุกชุดที่ตกยุคไปหมดแล้ว

## ผลลัพธ์

- หน้าปุ่มตัวเลือก ขนาดตรงสูตรครบ 80 แบบ สีตรง 0 เงาตรง 0 ขีดยาว 0 และเอกสารครบทุกชนิด
- หน้าแท็ก ชิ้นงาน 4,215 แบบ ความสูงผิดบันได 0 สีตรง 0 และการผูกค้าง 0 จากเดิมที่มีถึงพันกว่าจุด
- ทุกตระกูลมีครบสิบเอ็ดชุด ไม่มีชุดซ้ำ ไม่มีชุดขาด และลำดับแถวเหมือนกันหมด
- ลองสองวิธีในการแยกชุดออกมา วิธีย้ายแบบออกมาแล้วรวมใหม่ใช้ไม่ได้เพราะคุณสมบัติของแต่ละตัวได้รหัสใหม่คนละตัวแล้วชนกัน ส่วนวิธีก๊อปทั้งชุดแล้วลบส่วนเกินใช้ได้ เพราะคุณสมบัติถูกก๊อปมาเป็นชุดเดียวกัน
- ตอนวิธีแรกล้มเหลว Figma ย้อนกลับให้ทั้งหมดอัตโนมัติ ไฟล์ไม่เสียหาย บทเรียนคือลองวิธีเสี่ยงกับของจริงได้ถ้ารู้ว่าระบบย้อนกลับให้เมื่อพัง

## ติดปัญหา

- ผูกขนาดสองด้านแล้วติดแค่ด้านเดียว เพราะโหนดล็อกสัดส่วนไว้ พอผูกด้านหนึ่งอีกด้านหลุดทันที ผมรายงานไปแล้วว่าสำเร็จทั้งที่ติดครึ่งเดียว จับได้ตอนสแกนซ้ำแล้วตัวเลขไม่ลง บทเรียนคือต้องปลดล็อกก่อนผูก และห้ามเชื่อตัวเลขที่ฟังก์ชันคืนมา ต้องสแกนซ้ำเสมอ
- ด่านตรวจของผมเช็คแค่ว่ามีการผูกไหม ไม่ได้เช็คว่าตัวที่ผูกยังมีอยู่จริง พอหัวหน้าเปลี่ยนโครงชื่อตัวแปร ของเดิมถูกลบ ทุกจุดที่ผูกไว้เลยชี้ไปที่ของที่ไม่มีอยู่ ค่าค้างไว้เฉย ๆ กว่าพันจุด และผมรายงานว่าสะอาดมาตลอด หัวหน้าเป็นคนทักเอง
- เขียนสคริปต์แก้บรรทัดนับจำนวนโดยใช้คำสั่งค้นหาที่ไล่ลึกทั้งกิ่ง ทำให้ไปเจอข้อความข้างในชิ้นงานก่อน แล้วเขียนทับไป 121 จุด จับได้ทันทีจากตัวอย่างที่รายงานกลับมาแล้วกู้คืนครบ บทเรียนคือหาของที่เป็นพี่น้องกัน ต้องดูลูกตรงเท่านั้น
- รายงานเรื่องความสูงของแท็กว่าปกติดี ทั้งที่หลุดบันไดไปแล้ว เพราะอ่านแต่ค่าตัวแปรไม่ได้วัดของจริง ซึ่งผิดกฎที่เขียนไว้เองว่าต้องอ่านค่าจริงเสมอ
- เกือบแก้ระยะขอบซ้ายขวาของแท็กแคปซูลให้เท่ากัน ทั้งที่หัวหน้าตั้งใจให้ซ้ายกว้างกว่าเพื่อถ่วงสายตากับมุมโค้ง จับได้เพราะถามก่อนลงมือ แก้แล้วโดยเขียนเหตุผลลงคำอธิบายตัวแปรกำกับไว้ว่าห้ามปรับให้เท่ากัน
