## 4. user ตรวจแล้วตีกลับ แก้ 3 เรื่อง

รอบแรกผมสรุปว่าเสร็จ แต่ user ตรวจแล้วพบว่ายังไม่เสร็จจริง สาเหตุคือตอนสแกนผมไล่แต่ข้อใน CLAUDE.md ไม่ได้เปิดเช็คลิสต์ในไฟล์มาตรฐานมาไล่ทีละข้อ ทั้งที่ pre-flight สั่งให้อ่านทุกครั้ง

### 4.1 ชุด component ลอยอยู่บนแคนวาส

ตรวจหน้า 12 Buttons แล้วพบว่าไม่มี COMPONENT_SET ลอยเลยสักตัว ทุกชุดอยู่ในเฟรม Component Previews ย้ายชุด toggle เข้าเอกสารแล้ว จัดเป็นตารางแบบ wrap ตอนนี้หน้า 14 มีแต่เฟรมเอกสาร 7 อัน ไม่มีอะไรลอย

### 4.2 ขยายเป็น 5 ขนาด

user สั่งให้เปิดครบ xs ถึง xl เท่าปุ่ม สูตรรองรับอยู่แล้วจึงไม่ต้องแก้สูตร แค่เปิดชุดขนาด ผลคือตัวแปร Figma 13 เป็น 28 ตัว token 16 เป็น 34 ตัว และ variant 16 เป็น 40 แบบ

**เจอปัญหาระหว่างทาง** ตัวอักษรที่สวิตช์ใช้อยู่คือ Text/sm medium ซึ่งเป็นสไตล์จากไลบรารีอื่น ไม่อยู่ในรายการ preset ที่ระบบประกาศ และไม่มีขนาด xs lg xl ให้ใช้ จึงขยายไม่ได้ user เลือกให้จับคู่ตามชื่อ ย้ายไปใช้ label กับ body ที่ประกาศไว้จริง ผลคือตัวอักษรของ sm กับ md เล็กลงหนึ่งขั้น

**เจอข้อความที่กลายเป็นเท็จ** ตอนมีสองขนาด ความสูงรางห่างจากความสูงแถวเท่ากันพอดีที่ 12 ทั้งคู่ ผมเขียนกำกับไว้ว่าเป็นความบังเอิญห้ามผูกกัน พอเปิดครบ 5 ขนาดระยะห่างกลายเป็น 8, 12, 16, 20, 24 ไม่คงที่เลย เพราะสองสเกลใช้ step ต่างกัน แก้ข้อความทั้ง 3 ที่แล้ว และกลายเป็นหลักฐานที่ดีกว่าเดิมว่าไม่ควรผูกกัน

### 4.3 Page Documentation เขียนแบบมักง่าย

ของเดิมเป็นตัวหนังสือล้วน 0 instance ทั้งที่หน้า 12 มี instance จริงเกือบทุก section เขียนใหม่ทั้งหมด overview มีตัวอย่างหน้าตั้งค่าจริง 3 แถว anatomy มีสวิตช์ xl คู่รายการส่วนประกอบ variants แสดงสองรูปแบบ sizes แสดง 5 ขนาดมีป้ายกำกับ states แสดง 8 แบบ และ **usage มี Do กับ Don't 2 คู่เป็นภาพจริง** ซึ่งเป็นข้อที่เช็คลิสต์บังคับแล้วผมไม่ได้ทำ ส่วน accessibility, design tokens, specs, related เขียนเป็นรายการละเอียดแทนย่อหน้าลอย

## 5. user ตรวจรอบสอง ตีกลับอีก แก้ 3 เรื่อง

### 5.1 component ต้นฉบับต้องอยู่ในเฟรมของตัวเอง

ผมเอาชุดต้นฉบับไปใส่เป็น section หนึ่งในเฟรมที่โชว์ตัวอย่าง ซึ่งไม่ตรงแบบ ไปดูหน้า 12 แล้วพบว่าเฟรมอย่าง Brand Button เป็นเฟรมแยกที่มีแต่ชุดต้นฉบับ ไม่ปนกับอะไร สร้างเฟรม Toggle ขึ้นมาใหม่ตามแบบนั้น

ลบเฟรม Toggle Component Previews ทิ้งตามที่ user สั่ง เพราะสองsection ที่เหลือซ้ำกับ Page Documentation อยู่แล้ว และหน้า 12 ก็ไม่มีเฟรมแบบนี้

### 5.2 เรียง component ให้เป็นระเบียบ

ของเดิมเป็น wrap ที่ไหลตามความกว้างของแต่ละตัว ขนาดคละกันมั่ว จัดใหม่เป็นตาราง 8 คอลัมน์ คูณ 5 แถว แถวละหนึ่งขนาดเรียง xs ถึง xl คอลัมน์เรียง 4 สถานะ คูณ เปิดปิด ทำโดยตรึงความกว้างชุดให้พอดี 8 คอลัมน์ ไม่ต้องวางตำแหน่งเอง

### 5.3 ค่าเริ่มต้นเป็นสวิตช์พร้อมข้อความ

เปลี่ยน default ของคุณสมบัติหัวข้อกับคำอธิบายเป็นเปิด เหตุผลคือเป็นรูปแบบที่ใช้บ่อยกว่า และบังคับให้คนออกแบบคิดเรื่องป้ายกำกับตั้งแต่ลากมาวาง

### 5.4 เจอบั๊กใหญ่ตอนแก้ข้อ 5.3

พอเปลี่ยนค่าเริ่มต้นแล้วสั่งปิดข้อความที่ instance ปรากฏว่า xs lg xl ไม่ยอมปิด ตรวจแล้วพบว่า **variant 24 ตัวที่ clone มาสร้างขนาดใหม่มี componentPropertyReferences ว่างเปล่า** Figma ไม่ก๊อปการผูกคุณสมบัติมาให้ตอน clone แปลว่าคุณสมบัติเปิดปิดข้อความและช่องข้อความทั้งสี่ตัว **ใช้ไม่ได้เลยกับ 24 จาก 40 แบบ** ตั้งแต่ตอนสร้าง และไม่มีอะไรฟ้อง

ผูกกลับครบ 40 แล้ว และเพิ่มเป็นข้อ 13 ใน Constraints ของ docs/14-toggles.md ว่าต้องตรวจทุกครั้งหลัง clone variant

ไล่ตั้งค่า instance ใหม่ทั้งหมด หน้า 14 มี 15 ตัวเป็นสวิตช์ล้วน 8 ตัวมีข้อความ หน้า 27 มี 3 ตัวเป็นสวิตช์ล้วน 4 ตัวมีข้อความ

## 7. แก้ชื่อ variant และ text style ของ component หน้า 05 Effect

### รายงานผิดแล้วแก้

ตอนเปิดการ์ดเขียนว่าคุณสมบัติ Size และ Type ไม่มี node ผูก ไม่จริง ทั้งสองเป็นแกน variant ซึ่งไม่ต้องมี node ผูกอยู่แล้ว สคริปต์ตรวจกรองคำว่า size กับ state ตัวเล็กออกไว้ แต่หน้านี้เป็นตัวใหญ่จึงหลุดตัวกรองแล้วถูกนับเป็นของพัง แก้คำในการ์ดและเปลี่ยนชื่อการ์ดให้ตรงกับปัญหาจริงแล้ว

### ที่ทำจริง

เปลี่ยนชื่อแกนและค่าของ variant เป็นตัวเล็ก 25 ตัว จาก Size เป็น size ทั้ง 4 ชุด และ Type เป็น type ในชุด focus-ring พร้อมเปลี่ยนค่าทั้ง 5 ค่าเป็นตัวเล็ก ขนาด component ไม่เปลี่ยนสักตัว
