### เติม brown และแก้ขอบให้ตรงไฟล์ออกแบบ ตามที่หัวหน้าตัดสิน

- เติมตระกูล brown ให้ BadgeFamily ฝั่งโค้ด ทั้ง Badge.tsx และ Badge.module.css ตัวแปรสี u-brown ทุกขั้นมีครบอยู่แล้วจึงเติมได้ทันที พร้อมแก้จำนวนตระกูลในคอมเมนต์หัวไฟล์และ README จาก 10 เป็น 11 และแก้ตัวเลขจำนวนชุดกับจำนวนแบบที่ค้างผิดมาตั้งแต่ก่อนงานวันนี้ จาก 40 ชุด 800 แบบ เป็น 11 ตระกูล 55 ชุด 715 แบบ ตามที่นับจริงจากไฟล์ออกแบบ
- สาเหตุของช่องว่างความสูง 2 หาเจอแล้ว ทั้ง Badge กับ Tag ใช้ border ของ CSS วาดเส้นขอบ แม้ตอนไม่มีเส้นขอบก็ยังตั้ง border 1px solid transparent ไว้เสมอ ซึ่งถึงจะโปร่งใสก็ยังกินพื้นที่ในกล่องแบบ border-box บวกกับ padding บวกกับความสูงบรรทัดของข้อความ รวมกันเกิน min-height ที่ตั้งไว้ กล่องจึงขยายตามเนื้อหาแทนที่จะหยุดที่ min-height ไฟล์ออกแบบใช้เส้นขอบแบบ INSIDE ซึ่งไม่กินพื้นที่กรอบ เพราะทับซ้อนกับ padding ไม่ใช่บวกเพิ่ม
- แก้โดยเปลี่ยนจาก border เป็น box-shadow แบบ inset ซึ่งไม่มีผลต่อกล่องเลย (เหมือนที่ Avatar ใช้วาดวงแหวนอยู่แล้ว) คำนวณด้วยมือยืนยันก่อนแก้ว่า padding-top บวก padding-bottom บวกความสูงบรรทัดของ preset เท่ากับ token size พอดีทุกขนาดของทั้ง Badge และ Tag แปลว่าพอไม่มี border กินพื้นที่แล้ว กล่องจะหยุดที่ min-height ตรงตามไฟล์ออกแบบเป๊ะ ไม่ใช่การเดา
- Tag มี hover กับ focus-visible ที่ใช้ border-color กับ box-shadow อยู่แล้ว (วงแหวนโฟกัสล้นนอกกล่อง) ต้องรวมเส้นขอบใหม่กับวงแหวนโฟกัสไว้ในค่าเดียวกัน เพราะ box-shadow เป็น property เดียว ตั้งซ้ำแล้วทับไม่ใช่ซ้อน เพิ่มกฎสำหรับตอนเมาส์ชี้ค้างพร้อมโฟกัสด้วยคีย์บอร์ดพร้อมกันด้วย เพื่อให้พฤติกรรมเดิมไม่หาย
- ตรวจหลังแก้ ด่านทั้งห้าผ่านหมด สแกนว่า class ที่ TSX เรียกมีใน CSS ครบทั้งสองไฟล์ สีดิบ 0 em-dash 0 ไม่มีตัวอักษรแตกส่วน
- ⚠️ ยังไม่ได้ยืนยันด้วยเบราว์เซอร์จริง เพราะเครื่องไม่มี browser headless ติดตั้งไว้ ยืนยันด้วยการคำนวณค่าด้วยมือจากสูตร box model แทน ควรเปิดดูจริงอีกรอบเมื่อมีโอกาส

### ติดปัญหา push ขึ้น GitHub พิมพ์ username password ไม่ได้เลย

- push ครั้งแรกพังด้วย error เดียวกันซ้ำ ๆ ไม่ว่าจะลองกี่รอบ ไล่เช็คทีละชั้น พบว่าไม่ใช่ token ผิด ไม่ใช่ credential ค้างใน Keychain (ค้นทั้ง login และ Local Items ไม่เจออะไรเลย) และไม่ใช่ VS Code แอบเด้งกล่องถามแยกจากเทอร์มินัล
- ทดสอบปิด credential helper ชั่วคราวด้วย -c credential.helper= แล้วยัง error ทันทีเหมือนเดิมไม่มีพรอมต์ขึ้นเลย สรุปได้ว่า VS Code integrated terminal ของเครื่องนี้ไม่ยอมให้ git ถาม username password แบบ interactive ได้เลย เหมือนปัญหาเดียวกับที่ผมเจอเองตอนลอง push จากฝั่งเครื่องมือผม ซึ่งขึ้น error Device not configured ตรง ๆ
- ทางแก้คือข้ามการถามของ git ไปเลย ใช้ git credential approve เก็บ username กับ token เข้า Keychain โดยตรงผ่าน stdin แทนการรอ git ถาม พอมีอยู่ใน Keychain แล้ว git push จะหยิบไปใช้เองโดยไม่ต้องถามอีก
- ระหว่างทางเจอผู้ใช้พิมพ์ข้อความแทนที่ token ไม่ครบ 2 รอบ เพราะคำสั่งแบบพิมพ์หลายบรรทัดทีละบรรทัดสับสนง่าย และคำสั่งแบบ heredoc ถ้าไม่ได้แก้ placeholder ก่อนรันจะเก็บคำว่า placeholder เป็นรหัสผ่านจริงไปเงียบ ๆ แก้โดยเปลี่ยนเป็นคำสั่งบรรทัดเดียวที่ดับเบิลคลิกเลือกคำ placeholder ในเทอร์มินัลแล้ววางทับได้ตรง ๆ ก่อนกด Enter ได้ผลในที่สุด

## ติดปัญหา

- ตอนเขียนด่านหาตัวแปรข้ามตระกูลรอบแรก ผมตั้งเงื่อนไขผิดเอง ไปนับ u-gray ว่าเป็นสีข้ามตระกูลด้วย จึงขึ้น 700 จุด ทั้งที่แกน default-gray เท่ากับ true ตั้งใจให้ทุกตระกูลใช้สีเทาอยู่แล้ว แก้เงื่อนไขแล้วได้ 0 ตามจริง
- ภาพของชุด link-icon-tag แถวที่เป็นแกนสีเทาดูออกน้ำเงินเข้ม ตรวจค่าจริงแล้วเป็น color/text/general/text ที่ไล่ไปจบที่ gray-light 600 ค่า 475467 ซึ่งเป็นสีข้อความกลางของระบบที่อมน้ำเงินในตัว ไม่ใช่สีหลุด
- แก้ขอบ Badge กับ Tag จาก border เป็น box-shadow ยังไม่ได้ยืนยันด้วยเบราว์เซอร์จริง เพราะเครื่องไม่มี browser headless ติดตั้งไว้ ยืนยันด้วยการคำนวณค่าด้วยมือจากสูตร box model แทน ควรเปิดดูจริงอีกรอบเมื่อมีโอกาส
