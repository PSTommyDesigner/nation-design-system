# Worklog 2026-08-07
> Task: [04 Grid]-[Document] อัปเดต variable จัดหน้าเอกสาร

## งานค้าง
- **หน้าการ์ดยังไม่มีเอกสาร** มีแต่ชิ้นส่วนลอย
- **ปุ่มยังไม่มีโค้ดจริง** ทั้งที่ค่าพร้อมครบแล้ว หัวหน้าให้พักไว้ก่อน
- **งานใหม่ 3 โปรเจกต์** โปรไฟล์พนักงาน · ฟีเจอร์อนุมัติงานฝ่ายบุคคล · รายงานผลการขาย
- (คิวเดิม) หนี้เทคนิคฝั่งโค้ด

## งานที่ทำวันนี้
- **จัดโครงเอกสารทั้งระบบให้ตรงแบบใหม่** ไล่แก้ครบ 6 หน้า ทุกหัวข้อใช้ชุดเดียวกันหมด
- **เอากรอบพื้นเทาออก** หลังหัวหน้าชี้ว่าเป็นเพียงตัวอย่างในแบบ ไม่ใช่สไตล์ที่ต้องใช้จริง
- **ทำหน้ากริดให้ครบวงจร** เพิ่มตารางค่า ดึงค่าเข้าโค้ด และเขียนคู่มือประจำหน้า
- **อัปเดตไอคอนทั้งชุด** ให้ตรงกับที่หัวหน้าทำใหม่ พร้อมแก้ให้เปลี่ยนสีตามระบบได้
- **ตามค่าสีปุ่มที่หัวหน้าแก้** ตรวจเทียบทีละตัว เจอที่ต่าง 1 จุด และเพิ่มค่ามุมโค้งของปุ่มทรงใหม่
- **แก้ค่าสีที่อ้างข้ามชั้นผิดหลัก** ให้ชี้ชั้นความหมายกลางโดยตรง ตรวจแล้วสีไม่เปลี่ยนสักตัว

## ผลลัพธ์
- เอกสารทุกหน้าหน้าตาเป็นระบบเดียวกัน ไม่มีหัวข้อขนาดแปลกปนอีก
- หน้ากริดมีเอกสารครบและค่าพร้อมใช้ทั้งฝั่งออกแบบและฝั่งโค้ด
- ไอคอนและค่าสีปุ่มในโค้ดตรงกับไฟล์ออกแบบ

## ติดปัญหา
- **ทำชิ้นส่วนต้นฉบับเสียรูป** ตอนไล่แก้เป็นชุดโดยไม่ดูว่าชิ้นไหนเป็นต้นฉบับ กู้คืนครบและเพิ่มข้อห้ามกันซ้ำ
- **เสนอเกินคำสั่ง** เสนอให้ลบค่าชั้นกลางทั้งที่ไม่ได้ผิดกติกาและมีของใช้อยู่จำนวนมาก
- กุญแจเข้าระบบไฟล์ออกแบบหมดอายุกลางทาง หัวหน้าออกให้ใหม่ งานจึงเดินต่อได้
