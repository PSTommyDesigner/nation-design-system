- **สองฝั่งตรงกันหมดทุกค่า** ขนาด ระยะขอบ ขนาดไอคอน มุมโค้ง และระยะห่างภายใน ตรวจจากค่าที่ไล่จนสุดสาย ไม่ได้ดูจากชื่อ
- **ปิดช่องที่จะทำให้โค้ดพังในอนาคต** ถ้าไม่แก้ค่ากลาง 25 ตัวนี้ วันไหนมีคนดึงค่าจากไฟล์ออกแบบมาทับ ค่าเก่าจะไหลเข้าโค้ดทันที
- ค่ากลางที่ไม่มีใครใช้หายไป 20 ตัว ไฟล์ผลลัพธ์ฝั่งโค้ดลดลง 40 บรรทัด เป็นการลบล้วน ไม่มีค่าอื่นขยับ

- **ระยะห่างมีชุดค่ากลางครั้งแรก** จากเดิมที่ตัวเลขบนหน้าเอกสารไม่ได้ผูกกับอะไรเลย ตอนนี้สองฝั่งตรงกันทุกค่า ตรวจด้วยการอ่านค่ากลับมาเทียบทีละตัว ไม่ได้ดูแค่ว่าสั่งสำเร็จ
- **หน้าเอกสารระยะห่างครบชนิดตามมาตรฐานแล้ว** จากเดิมที่ขาดทั้งสารบัญของหน้าและตารางจับคู่ชื่อ
- **สแกนก่อนบอกเสร็จ** สีดิบ 0 เส้นดิบ 0 ขีดยาว 0 และไม่มีข้อความแม่แบบค้างสักจุดจาก 558 ชิ้นบนหน้า
- ตัดชุดค่าที่ไม่มีใครใช้ออก 12 ขั้น เหลือเฉพาะที่ใช้จริงกับเพดานอีกหนึ่งขั้น
- **ขอบเขตของชุดค่ากลางชัดแล้ว** แยกชัดว่าอะไรเป็นของการจัดหน้า อะไรเป็นของชิ้นงาน ทั้งในไฟล์ออกแบบและฝั่งโค้ดพูดตรงกันทุกจุด สแกนหาคำอธิบายเก่าที่ค้างแล้วเหลือ 0
- **หน้าเอกสารแน่นขึ้นและอ่านง่ายขึ้น** บรรทัดว่างซ้อนเหลือ 0 จุดคั่นคำนอกรายการเหลือ 0 ทั้งในไฟล์ออกแบบและเอกสารในเครื่อง
- **ชุดค่ากลางเป็นของเดิมที่ทีมออกแบบไว้ครบ 26 ค่า** สองฝั่งตรงกันทุกค่า ตรวจด้วยการอ่านค่ากลับมาเทียบทีละตัว
- **สแกนปิดงานอีกรอบหลังเปลี่ยน** สีดิบ 0 เส้นดิบ 0 ขีดยาว 0 จุดคั่นนอกรายการ 0 บรรทัดว่างซ้อน 0 และไม่มีข้อความชุดเก่าค้าง
- **มาตรฐานเอกสารมีชนิดใหม่แล้ว** พร้อมแม่แบบและตัวอย่างจริงหนึ่งหน้า ให้หน้าอื่นลอกไปทำต่อได้ทันที
- **มีตัวเลขบอกลำดับงานที่เหลือ** ว่าหน้าไหนหนักหน้าไหนเบา ใช้ตัดสินว่าจะหยิบหน้าไหนทำก่อน
- **มีเอกสารระยะห่างแล้ว 2 หน้า** หน้าปุ่มกับหน้าตาราง ทั้งคู่ค่าอ่านจากของจริง ไม่ได้พิมพ์จากความจำ
- **เจอของที่ต้องตัดสินเพิ่ม** ระยะขอบซ้ายขวาของเซลตารางคือ 14 ซึ่งไม่มีในชุดค่ากลาง ต้องเลือกว่าจะคงไว้หรือปรับก่อนถึงจะสร้างค่ากลางของตารางได้
- **เซลตารางไม่มีค่าที่หลุดชุดค่ากลางแล้ว** จากเดิมมีหนึ่งค่า พร้อมผูกทันทีเมื่อสร้างตัวแปรของตาราง

## ติดปัญหา
- **รายงานตัวเลขผิดเพราะอ่านไม่ครบทุกด้าน** บอกว่ามุมโค้งผูกผิด 24 จุด ของจริง 224 เพราะอ่านแค่มุมเดียวจากสี่มุม บทเรียนคือของที่มีหลายด้าน ต้องอ่านให้ครบทุกด้านก่อนรายงานตัวเลข
- **ผูกขนาดไอคอนไปทับกันเองโดยไม่รู้ตัว** เพราะไอคอนถูกล็อกสัดส่วนไว้ ระบบจึงเก็บการผูกได้ด้านเดียว ผูกด้านที่สองไปลบด้านแรกเงียบ ๆ ทั้งที่รายงานว่าสำเร็จ จับได้เพราะอ่านค่ากลับมาตรวจหลังผูก บทเรียนคือจำนวนครั้งที่สั่งสำเร็จ ไม่เท่ากับผลลัพธ์ที่ได้จริง
- **เกือบลบค่ากลางทิ้งโดยไม่ได้ดูปลายทางให้ครบ** รอดเพราะสแกนทั้ง 51 หน้าก่อน แล้วพบว่ามีเอกสารอีกหน้าหนึ่งยืมค่านั้นไปใช้เป็นตัวอย่าง ซึ่งถ้าลบไปเฉย ๆ เอกสารจะชี้ไปหาของที่ไม่มีอยู่

- **เกือบเลือกชุดค่าที่สั้นกว่าเพราะดูดีบนกระดาษ** รอดเพราะเอาไปเทียบกับของจริงในไฟล์ก่อน แล้วพบว่ามันไม่มีสองค่าที่โครงเอกสารของเราใช้อยู่ทุกหน้า บทเรียนคือข้อเสนอที่มาจากงานวิจัยล้วนต้องผ่านการเทียบกับของจริงเสมอ
- **ระบบนัดหมายงานไม่ยอมให้ใส่วันเริ่มโดยไม่ใส่วันเสร็จ** ทำให้วงจรวันที่ที่ตั้งไว้ใช้ไม่ได้ตรง ๆ ต้องไปใส่พร้อมกันตอนปิดงานแทน
- **หลงไดเรกทอรีตอนสั่งงานเป็นชุด** ทำให้คำสั่งเขียนไฟล์ล้มเหลวหนึ่งรอบ จับได้ทันทีเพราะอ่านผลลัพธ์ทุกครั้ง ไม่มีไฟล์แปลกปลอมเกิดขึ้น
- **เขียนขอบเขตกว้างเกินตั้งแต่แรก** ทำเอกสารโดยยกตัวอย่างเป็นระยะห่างภายในปุ่มและแท็ก ซึ่งไม่ใช่หน้าที่ของชุดค่ากลาง หัวหน้าทักถึงรู้ · บทเรียนคือก่อนลงมือควรถามให้ชัดว่าของกลางชิ้นนี้ครอบคลุมถึงไหน ไม่ใช่เดาจากชื่อหน้า
- **จัดหน้าโดยใช้บรรทัดว่างแทนระบบระยะห่าง** ซึ่งขัดกับงานที่กำลังทำอยู่เอง บทเรียนคือเอกสารที่อธิบายระบบต้องใช้ระบบนั้นจริง ไม่ใช่จัดด้วยมือ
- **บรรทัดขยายความในเซลตารางหายไปตอนสั่งซ่อน** ระบบตัดชิ้นนั้นออกจากสำเนาเลย พอสั่งให้แสดงใหม่จึงไม่มีอะไรกลับมา ต้องคืนค่าสำเนาก่อนแล้วค่อยใส่ใหม่ จับได้เพราะดูภาพจริงหลังแก้ ไม่ได้เชื่อว่าสั่งแล้วสำเร็จ
- **ลบตัวแปรพลาดไปหนึ่งตัว** เงื่อนไขที่เขียนไว้กวาดตัวใหม่ที่ชื่อคล้ายกันไปด้วย จับได้ทันทีเพราะนับจำนวนหลังลบแล้วไม่ตรง สร้างคืนแล้วตรวจครบ 26 บทเรียนคือเวลาลบเป็นชุด ต้องนับผลลัพธ์เทียบกับที่ตั้งใจทุกครั้ง
- **เสนอชุดค่าใหม่โดยไม่ได้ถามก่อนว่าของเดิมมีที่มาอย่างไร** ของเดิมเป็นระบบที่หัวหน้าออกแบบไว้แล้ว ผมไปสรุปว่าควรตัดทิ้งเพราะดูจากสถิติการใช้อย่างเดียว บทเรียนคือของที่มีอยู่ก่อนต้องถามที่มาก่อนเสนอให้เปลี่ยน
- **สั่งสร้างสำเนาเอกสารไม่ผ่านสองรอบเพราะฟอนต์ยังไม่ถูกโหลด** รอบแรกโหลดจากข้อความในต้นแบบ แต่ข้อความที่ถูกซ่อนอยู่ระบบมองไม่เห็น จึงตกหล่น แก้โดยโหลดจากรายการรูปแบบตัวอักษรทั้งไฟล์แทน บทเรียนคือการไล่เก็บจากของที่มองเห็น ไม่ครอบคลุมของที่ซ่อนอยู่
- **รายงานจำนวนหน้าที่ต้องทำผิด** บอกว่าเหลือ 17 หน้า ทั้งที่นับจากชุดที่สแกนไว้เท่านั้น พอไปสแกนหน้าที่ยังไม่เคยดูก็เจอเพิ่มอีก 4 หน้า บทเรียนคือตัวเลขที่มาจากข้อมูลบางส่วน ต้องบอกด้วยว่าครอบคลุมแค่ไหน
