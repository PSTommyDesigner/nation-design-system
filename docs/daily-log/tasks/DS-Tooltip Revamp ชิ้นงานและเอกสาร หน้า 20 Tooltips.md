# [DS]-[Tooltip] Revamp ชิ้นงานและเอกสาร หน้า 20 Tooltips

## รายละเอียดงาน

**Problem ปัญหาคืออะไร ? :** หน้า 20 Tooltips ยังไม่เคยถูกทำตามมาตรฐาน มี 4 ชุด รวม 78 แบบ แต่ไม่มีเอกสารสักชนิด ไม่มีตัวแปร ไม่มีไฟล์สูตรขนาด และไม่มีโค้ด ปัญหาเชิงโครงคือ ทำโหมดมืดเป็นแกนของชุดซึ่งขัดกับสถาปัตยกรรม token ของระบบ ชื่อตำแหน่งกลับทางกับทั้งตลาดเพราะเรียกตามทิศที่ลูกศรชี้แทนที่จะเรียกตามที่ที่กล่องไปอยู่ ชุด Help icon เป็นภาพสาธิตไม่ใช่ชิ้นงาน ชุด Avartar สะกดผิดและไม่ใช่ tooltip ชื่อชุดไม่ลงท้ายด้วยชนิด ตัวอักษรใช้สไตล์ที่ไม่มีอยู่ในชุดสำเร็จรูปของระบบ มุมโค้งและระยะห่างเป็นค่าดิบ และไอคอนตัวกระตุ้นยังเป็นชุด Material เก่า**Goal ทำเพื่ออะไร ? :** ยุบ 4 ชุดเหลือชุดเดียวที่มีแกนตรงกับตลาด ให้โหมดมืดมาจากโหมดของตัวแปร มีระบบสเกลที่คุมด้วยสูตรเหมือนหน้าอื่น มีเอกสารครบชนิด และมีโค้ดที่ทำเรื่องการเข้าถึงครบตามเกณฑ์ข้อ 1.4.13**Requirements ขอบเขตงาน**
1. วิจัย tooltip ของ DS เจ้าใหญ่ 15 เจ้า เรื่องเส้นแบ่งกับ popover จังหวะการกระตุ้น ตำแหน่งและการพลิก รูปร่าง และการเข้าถึง (เสร็จแล้ว)
2. ยุบเหลือชุดเดียวชื่อ tooltip แกน supporting-text คูณ placement คูณ size และแยกลูกศรเป็นชิ้นเดี่ยว
3. ถอดแกนโหมดมืดออก ให้สีมาจากโหมดของตัวแปรในชั้น semantics
4. เปลี่ยนชื่อตำแหน่งให้หมายถึงที่ที่กล่องไปอยู่ ไม่ใช่ทิศที่ลูกศรชี้
5. สร้างไฟล์สูตร tokens/scale/tooltip.mjs แล้วสร้างตัวแปรและผูกให้ครบ
6. ย้ายตัวอักษรไปใช้ชุดสำเร็จรูปที่ประกาศไว้ในระบบ และขยายลูกศรเป็น 12 คูณ 6
7. ลบชุด Help icon และ Avartar ที่ไม่ใช่ชิ้นงานของหน้านี้
8. ทำเอกสารครบทุกชนิดบนหน้า Figma และไฟล์ docs/20-tooltips.md ในเครื่อง
9. ทำโค้ดที่ครบเกณฑ์ 1.4.13 ทั้ง 3 ข้อย่อย ซ่อนบนจอสัมผัส และปิดด้วย Escape
10. สแกนปิดงานให้สีดิบ มุมโค้งไม่ผูก ระยะห่างไม่ผูก และขีดยาว เป็น 0
