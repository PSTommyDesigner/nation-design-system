# [DS]-[Pagination] Revamp ชิ้นงานและเอกสาร หน้า 24 Pagination

## รายละเอียดงาน

#### Problem

- หน้า 24 มีชิ้นงาน 7 ชุด 100 แบบ แต่ 66 แบบเป็นแคโรเซล ไม่ใช่ตัวแบ่งหน้า
- แกน Breakpoint เอาการตอบสนองต่อขนาดจอมาทำเป็นแบบ และตรึงความกว้างไว้ที่ 1440 กับ 375
- แกน Type มี 9 ค่าที่ปนกัน 3 เรื่อง คือ บริบท รูปแบบ และการจัดชิด แล้วเมทริกซ์ยังไม่ครบ มี 22 จาก 36
- คุณสมบัติ No.8 No.9 No.10 และ Range of number เอาข้อมูลมาทำเป็นแบบ
- ปุ่มเลขหน้าสูง 40 แต่ปุ่มก่อนหน้าถัดไปสูง 38 ทั้งที่อยู่แถวเดียวกัน
- จุดไข่ปลาใช้ instance เดียวกับปุ่มเลข จึงดูกดได้ทั้งที่กดไม่ได้
- ตัวอักษรทั้งหน้า 120 จุดใช้ชุดจากไลบรารีภายนอก ไม่ใช่ preset ของระบบ
- มุมโค้งไม่ผูกตัวแปร 289 จุด

#### Goal

- ยุบตัวแบ่งหน้าจาก 3 ชุด 34 แบบ เหลือ 12 แบบ
- ให้ความกว้างยืดตามกรอบแม่ และมีแกนขนาด 5 ขั้นเหมือนหน้าอื่น
- ย้ายตัวอักษรมาใช้ preset ของระบบให้ครบ
- รองรับทั้งหลังบ้านและหน้าอ่านข่าว

#### Requirements

- ถอดแกน Breakpoint Type และคุณสมบัติที่เป็นข้อมูลออก
- แยกจุดไข่ปลาออกจากปุ่มเลขหน้า
- ปุ่มก่อนหน้าถัดไปใช้ชุด button ที่มีอยู่แล้วหน้า 12
- ทำไฟล์สูตรขนาดพร้อมด่านตรวจ แล้ว build token
- สลับที่ใช้งานจริง 1 จุดบนหน้า 36 Templates
- ทำเอกสารในไฟล์ออกแบบครบ 5 ชนิด เอกสารประจำหน้าในเครื่อง และโค้ด
- แคโรเซล 4 ชุด 66 แบบ ไม่อยู่ในขอบเขตรอบนี้

### 2026-10-12 Tommyy_PS

#### **worklog 1**

- สำรวจของเดิมแล้วพบปัญหาเชิงโครง 8 เรื่อง ที่หนักที่สุดคือเอาขนาดจอมาทำเป็นแกนของชุด และตรึงความกว้างไว้ที่ 1440 กับ 375
- พบว่าแกน Type มี 9 ค่าที่ปนกัน 3 เรื่อง คือบริบท รูปแบบ และการจัดชิด แล้วเมทริกซ์ยังไม่ครบ มี 22 จาก 36
- วัดของจริงแล้วพบว่าปุ่มเลขหน้าสูง 40 แต่ปุ่มก่อนหน้าถัดไปสูง 38 ทั้งที่อยู่ในแถวเดียวกัน และระยะขอบที่เก็บไว้เป็นค่าหลอกเพราะเฟรมตรึงขนาด
- พบว่าตัวอักษรทั้งหน้า 120 จุดใช้ชุดจากไลบรารีภายนอก ไม่ใช่ preset 48 ตัวของไฟล์นี้
- ส่งงานวิจัยเทียบ 12 เจ้า โดยแบ่งเป็น 4 ใบขนานกันหลังจากล่มสองรอบตอนสั่งทีเดียว 15 เจ้า
- ไล่ดูก่อนตั้งสูตรว่าในระบบมีของชนิดเดียวกันอยู่แล้วไหม แล้วพบว่าความสูงปุ่มกับมุมโค้งของเดิมตรงกับของกลางของระบบพอดี จึงยืมมาใช้พร้อมด่านตรวจ แทนที่จะตั้งชุดใหม่
- สร้างตัวแปร 30 ตัว และประกอบชิ้นงานใหม่ 40 แบบ จาก 3 ชุด
- แยกจุดไข่ปลาออกเป็นชุดของตัวเอง กดไม่ได้ และแยกสถานะหน้าปัจจุบันออกจากสถานะชี้ให้เห็นชัด
- สลับที่ใช้งานจริง 1 จุดบนหน้า 36 แล้วห่อกรอบระยะขอบให้ เพราะระยะขอบเดิมฝังอยู่ในตัวชิ้นงานซึ่งเป็นที่ผิด
- ลบของเดิม 3 ชุด 34 แบบ โดยลบเรียงลำดับเพราะชิ้นส่วนฐานถูกใช้อยู่ 115 จุดข้างในชุดใหญ่
- ทำเอกสารในไฟล์ออกแบบครบ 7 ใบ เขียนเอกสารประจำหน้าในเครื่อง และแปลงเป็นโค้ด
- ย้ายแคโรเซล 4 ชุด 66 แบบที่นั่งผิดหน้าไปหน้า 26 Image And Carousel
- เติมบล็อกตัวอย่างจริงและการ์ดควรไม่ควรใน Page Doc หลังหัวหน้าทักว่าเป็นตัวหนังสือล้วน

#### **ผลตรวจ**

- ของที่คนต้องเลือกลดจาก 22 แบบ เหลือ 5 ส่วนจำนวนชิ้นรวมเท่าเดิมเพราะเพิ่มแกนขนาดครบห้าขั้น
- ปุ่มเลขหน้ากับปุ่มก่อนหน้าถัดไปสูงเท่ากันทุกขนาดแล้ว
- ตัวอักษรที่ใช้ชุดจากไลบรารีภายนอก ลดจาก 120 จุด เหลือ 0
- สแกนปิดงานทั้งหน้า 1,145 ชิ้น ได้ สีดิบ 0 เส้นดิบ 0 ขีดยาว 0 มุมโค้งไม่ผูก 0 และของลอย 0 ชุด
- ด่านตรวจว่าไฟล์ออกแบบกับโค้ดตรงกัน ขึ้นว่าต้องดู 0 กลุ่ม และตัวตรวจชนิดข้อมูล 0 ข้อผิดพลาด
- โค้ดอ้างตัวแปร 70 ตัว ตรวจทีละตัวแล้วมีจริงครบ
- ตรวจสูตรเลือกเลขหน้าด้วยมือเองนอกโปรเจกต์ ครบ 1 ถึง 60 หน้า ทุกหน้าปัจจุบัน ได้ข้อผิดพลาด 0

#### **ที่ไม่ได้ทำตามที่เขียนไว้**

- ให้ตัวเลขจำนวนแบบผิดตั้งแต่ตอนเสนอ บอกว่ายุบเหลือ 12 ทั้งที่ลืมคูณแกนขนาด ของจริงคือ 40 ต้องกลับไปแก้ตัวเลขกับหัวหน้าสองรอบ
- ฝั่งโค้ดใช้ปุ่มกลางของระบบไม่ได้ เพราะ Button render เป็นปุ่มอย่างเดียว เปลี่ยนเป็นลิงก์ไม่ได้ สองฝั่งจึงหลุดจากกันได้ ควรเพิ่ม prop ให้ Button เปลี่ยนชนิด element แล้วกลับมาใช้ของกลาง
- ปุ่มโหลดเพิ่มสำหรับหน้าอ่านข่าวยังไม่มี เปิดการ์ดแยกไว้แล้ว
- ยังไม่ได้ผูก Code Connect
