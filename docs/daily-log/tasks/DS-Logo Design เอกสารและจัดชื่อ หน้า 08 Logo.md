# [DS]-[Logo] Design เอกสารและจัดชื่อ หน้า 08 Logo

## รายละเอียดงาน

**Problem ปัญหาคืออะไร ? :**
หน้า 08 Logo ไม่มีเอกสารสักชนิดจาก 5 ชนิดที่มาตรฐานกำหนด คนที่มาหยิบโลโก้ไปใช้ไม่มีที่อ่านว่าตัวไหนใช้เมื่อไหร่ ใช้เล็กสุดได้เท่าไหร่ และห้ามทำอะไรกับโลโก้ นอกจากนี้ชื่อ component ทั้ง 545 ตัวไม่ตรงกติกาการตั้งชื่อ มีตัวใหญ่ทั้งหมด มีเว้นวรรค 302 ตัว และสะกดผิดคำว่า height เป็น hight อีก 13 ตัว

**Goal ทำเพื่ออะไร ? :**
หน้า 08 Logo มีเอกสารประจำหน้าและมีที่เก็บโลโก้จริงแยกตามชนิด คนหยิบไปใช้เห็นครบว่ามีอะไรบ้างและใช้อย่างไร พร้อมชื่อที่ตรงกติกาเดียวกับทั้งไฟล์

**Requirements ขอบเขตงาน**

1. แก้ชื่อ component ให้ตรงกติกาการตั้งชื่อ ตัวเล็กทั้งหมด ใช้ขีดแทนเว้นวรรค คง / ไว้สำหรับแบ่งกลุ่ม และแก้คำสะกดผิด
2. ทำ Component Previews เก็บโลโก้ในเครือแยกตามชนิด โลโก้เต็ม favicon และรุ่นความสูงคงที่
3. ทำ Page Documentation เป็นสารบัญของหน้า พร้อมเอกสารประจำหน้าฝั่งโค้ดที่ docs/08-logo.md
4. ไม่ทำในรอบนี้ Information Document และ Space Document
5. ไม่ทำในรอบนี้ โลโก้บริษัทนอกและธงประเทศในกลุ่ม Other 505 ตัว ไม่ใช่อัตลักษณ์ของเครือ
6. ห้ามแตะสีของโลโก้ หน้านี้ได้รับการยกเว้นถาวรเรื่องสีดิบ 5,958 จุด เพราะเป็นสีอัตลักษณ์แบรนด์ที่ต้องตายตัว

## บันทึกงาน

### 2026-08-27 Tommyy_PS

#### **สรุปงานการ์ดนี้ 1**

- สำรวจก่อนลงมือ พบว่าหน้าโลโก้ไม่มีเอกสารสักชนิดจาก 5 ชนิดที่มาตรฐานกำหนด และมีของสองชนิดปนกันอยู่ คือโลโก้ในเครือ 40 ตัว กับโลโก้บริษัทนอกและธงประเทศอีก 505 ตัวที่ติดมากับไฟล์
- แก้ชื่อต้นฉบับให้ตรงกติกาทั้งหน้า 545 ตัว เดิมเป็นตัวใหญ่ทั้งหมด มีเว้นวรรค 302 ตัว และสะกดคำว่าความสูงผิด 13 ตัว
- จัดโลโก้ในเครือ 40 ตัวเข้าที่เก็บใหม่ แยก 3 ชนิด ทรงจัตุรัส โลโก้เต็มความสูง และไอคอนเว็บ
- ทำเอกสารประจำหน้าทั้งในไฟล์ออกแบบและฝั่งโค้ด พร้อมเอกสารอธิบายของร่าง 19 ชิ้นว่าแต่ละอันคืออะไรและควรทำอย่างไรต่อ
- เพิ่มรหัสแบรนด์ให้ทีนิวส์ซึ่งเดิมมีโลโก้ครบแต่ไม่มีรหัส ทำให้รายชื่อรหัสครบ 13 แบรนด์
- แยกโลโก้นอกเครือ 505 ตัวไปหน้าใหม่ตามที่หัวหน้าเลือก แล้วเลื่อนเลขหน้าทั้งไฟล์ 27 หน้า พร้อมไล่แก้ที่อ้างเลขเก่าให้ครบทั้งเอกสาร ไฟล์ออกแบบ และชื่อไฟล์
- ทำเอกสารประจำหน้าและที่เก็บต้นฉบับให้หน้าใหม่ 505 การ์ด แบ่ง 13 กลุ่ม
- จัดหน้าที่เก็บโลโก้ให้ตรงสไตล์หน้าไอคอน ตามที่หัวหน้าปรับแม่แบบไว้
- ล้างขีดยาวทั้งโปรเจกต์ 358 จุดใน 66 ไฟล์ และแก้ต้นตอที่ทำให้มันงอกกลับมาทุกวัน

**ผลลัพธ์**

- หน้าโลโก้เหลือเฉพาะอัตลักษณ์ของเครือ จาก 545 ตัวเหลือ 40 ตัว
- ขนาดต้นฉบับไม่เปลี่ยนสักตัวจาก 545 ตัว เทียบก่อนและหลังทุกครั้งที่ย้าย
- เลขหน้าและชื่อไฟล์เอกสารตรงกันทั้งระบบ ไม่มีที่ไหนอ้างเลขเก่าค้าง ยกเว้นบันทึกย้อนหลังที่ตั้งใจไม่แตะ
- สแกนปิดงาน สีดิบ 0 ขีดยาว 0 จุดคั่นนอกรายการ 0 ข้อความแม่แบบค้าง 0

**ติดปัญหาและบทเรียน**

- ตอนย้ายต้นฉบับเข้ากล่อง ระบบยืดขนาดตามกล่องแล้วคำสั่งล็อกขนาดไปล็อกขนาดที่ยืดแล้ว ทำให้ต้นฉบับ 123 ตัวเพี้ยนจาก 32 เป็น 120 จับได้เพราะเทียบขนาดก่อนและหลังทุกตัว ซ่อมคืนครบและเปลี่ยนวิธีทำก่อนทำกลุ่มที่เหลือ
- เกือบทำเอกสารให้ของที่ไม่ใช่ของเรา ถ้าไม่ได้ถามขอบเขตก่อนจะเสียเวลาทำให้โลโก้บริษัทนอก 505 ตัว
- การเลื่อนเลขหน้ามีค่าใช้จ่ายแฝงมากกว่าที่คิด ลามไปถึงชื่อไฟล์เอกสาร ข้อความในไฟล์ออกแบบ และบันทึกความจำ รวมเกือบ 80 จุด
- กฎห้ามใช้ขีดยาวไม่เคยถูกบังคับจริง ปล่อยสะสมมา 359 จุด บทเรียนคือกฎที่ไม่มีตัวตรวจ จะกลายเป็นกฎที่ไม่มีอยู่จริง
