# [DS]-[Tags] Design เอกสารและผูกตัวแปร หน้า 21 Tags

## รายละเอียดงาน

**Problem**

- หน้า 21 Tags **ไม่มีเอกสารสักชนิดจาก 5 ชนิดที่มาตรฐานกำหนด**
- **ไอคอนกากบาทของแท็กชี้ต้นฉบับที่ถูกลบออกจากแคนวาสไปแล้ว 750 จุด** เป็นชุดสำเร็จรูปเก่า ไม่ใช่ Nation UI Icons
- **ข้อความในแท็กไม่ผูกชุดตัวอักษรเลย 2,250 จุด** ขัดกฎ preset only ที่ห้ามประกอบขนาดตัวอักษรเอง
- **ความสูงแท็กเรียงไม่เป็นขั้นเท่ากัน** คือ 18, 20, 22, 26, 28 ห่างกัน 2, 2, 4, 2
- สีพื้นกับเส้นขอบของกล่องรวม 20 จุดยังไม่ผูกตัวแปร และชื่อคุณสมบัติยังเป็นตัวใหญ่

**Goal**

- ไอคอนเป็นชุดของเครือทั้งหมด ข้อความผูก preset ครบ สีผูกตัวแปรครบ ชื่อตรงกติกา
- ความสูงแท็กเรียงเป็นขั้นเท่ากัน เพื่อให้ component อื่นที่หยิบแท็กไปใช้คำนวณเป็นสูตรได้
- มีเอกสารครบ 5 ชนิด และเอกสารฝั่งโค้ดที่ docs/21-tags.md

**Requirements**

- **ทำไมต้องทำก่อน** หน้า 13 Input ที่เพิ่งปิดไปหยิบแท็กจากหน้านี้ไปใช้ 120 จุด ปัญหาทั้งสามข้อจึงไหลเข้าไปในหน้า 13 ด้วย และแก้จากหน้า 13 ไม่ได้เพราะต้นตออยู่ที่นี่
- **ผลกระทบที่ชัดที่สุด** ความสูงแท็กที่ขั้นไม่เท่ากัน ทำให้ระยะขอบของช่องแท็กในหน้า 13 ต้องเขียนเป็นตารางค่า ทำเป็นสูตรไม่ได้ ซึ่งขัดกับระบบสเกลที่ใช้ทั้งโปรเจกต์
- ขอบเขตรอบนี้คือ **ไล่แก้ให้ครบทั้ง 130 ชุด 2,625 แบบ แต่ยังไม่รื้อโครง** การยุบทรงกับตระกูลสีให้เป็นคุณสมบัติเก็บไว้รอบถัดไป
- ทำทีละตระกูลสี ตรวจผลระหว่างทาง และเทียบขนาดต้นฉบับก่อนหลังทุกครั้ง
- ก่อนบอกเสร็จต้องสแกนตาม Definition of Done ให้ครบ

**Figma File**
