# [AI Chat]-[Suggestion] ดีไซน์หน้าหัวข้อและคำถามอัตโนมัติ(App)

## รายละเอียดงาน

**Problem ปัญหาคืออะไร ? :** ต้องการให้มี Suggestion หัวข้อและคำถามให้ผู้ใช้
**Goal ทำเพื่ออะไร ? :** Suggestion หัวข้อและคำถามให้ผู้ใช้ถ้าหากคำถามตรงจะได้ไม่ต้องพิมพ์ให้เสียเวลา
**Requirements **ขอบเขตงาน **: **

1. หัวข้อ
2. คำถามอย่างน้อย 2 คำถาม
3. กลุ่มแท็กคำถามต่อเนื่องจากคำถาม Suggestion
4. ย้ายเมนูเดิมไปไว้ข้างซ้ายช่องกรอกข้อมูล
