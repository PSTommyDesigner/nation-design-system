# [DS]-[Tags] Fix สีไอคอนปิดและคุณสมบัติที่ไม่ได้ใช้ หน้า 21 Tags

## รายละเอียดงาน

**Problem ปัญหาคืออะไร ? :**
- ผู้ใช้เจอข้อผิดพลาดตอนเรียกใช้ component แท็กจริง
- ไอคอนปิดของ 8 จาก 10 ตระกูลสีไม่มีสีอยู่เลย คือมองไม่เห็น ได้แก่ Pink Purple Bamboo Blue Cyan Yellow Green และ Red รวม 2,400 จุด
- อีก 2 ตระกูลคือ Brand และ Neutral มีสีแต่ผูกกับสีเทากลางตัวเดียวกันหมด ไม่เปลี่ยนตามชนิดและไม่เปลี่ยนตามพื้นหลัง ทำให้ไอคอนเทาอยู่บนพื้นเข้มจนอ่านไม่ออก รวม 450 จุด
- ในขณะที่ข้อความในแท็กเดียวกันผูกสีถูกต้องครบทุกตระกูลและทุกสถานะ
- คุณสมบัติของ component ที่ประกาศไว้แต่ไม่มีชิ้นงานผูก 264 จุด อยู่ใน 8 ชนิดคือ number image checkbox indicator และคู่ pill ของแต่ละตัว เป็นคุณสมบัติไอคอนซ้ายขวาที่กดแล้วไม่มีอะไรเกิดขึ้น
**Goal ทำเพื่ออะไร ? :**
- ไอคอนปิดมองเห็นได้ทุกตระกูล และมีความต่างจากพื้นหลังเท่ากับข้อความที่อยู่ข้าง ๆ
- คุณสมบัติที่เห็นในแผงต้องใช้งานได้จริงทุกตัว ไม่มีตัวไหนกดแล้วเงียบ
**Requirements ขอบเขตงาน**
1. ผูกสีไอคอนปิดให้ตรงกับสีข้อความในแท็กตัวเดียวกัน โดยอ่านค่าจากข้อความในแต่ละ variant ไม่พิมพ์ตารางสีเอง เพื่อไม่ให้จับคู่ผิด
2. ครอบคลุม 5 ชนิดคือ filled-tag pill-filled-tag border-tag pill-border-tag และ text-tag ครบทั้ง 10 ตระกูล
3. ต้องได้ถูกต้องทุกสถานะ ทั้ง default hover และ disabled เพราะสีข้อความเปลี่ยนตามสถานะ
4. ตรวจคุณสมบัติไอคอนซ้ายขวาใน 8 ชนิดที่เหลือ ดูตระกูลที่ผูกถูกก่อน แล้วตัดสินว่าจะผูกกลับให้ครบหรือลบทิ้ง ห้ามลบทันทีเพราะอาจเป็นของที่ควรมี
5. เทียบขนาด component ก่อนหลังว่าไม่เปลี่ยน และตรวจว่า instance ที่ใช้อยู่ไม่พัง
6. ไม่ทำในรอบนี้ การเพิ่มสถานะกดให้แท็ก อยู่ในการ์ด 1218146975973583

- เปิดไอคอนปิดเป็นค่าเริ่มต้นให้ครบทุกตระกูล เดิมเปิดแค่ 2 จาก 10 ทำให้คนหยิบใช้เจอพฤติกรรมต่างกันแล้วแต่ตระกูล
- ลบคุณสมบัติไอคอนซ้ายขวาที่ประกาศไว้แต่ไม่มีชิ้นงานผูก ซึ่งเป็นสาเหตุที่กดแล้วไม่มีอะไรเกิดขึ้น
- ก่อนลบตรวจครบ 3 ข้อ คือไม่มีชุดไหนผูกไว้ ไม่มีชิ้นงานรอผูก และไม่มีที่ไหนในไฟล์ตั้งค่าไว้

#### **ผลตรวจ**

- ไอคอนปิด 1,425 จุด สีตรงกับข้อความ 1,425 จาก 1,425 ไม่เหลือสีเทากลางสักจุด
- ไอคอนแสดงครบ 10 ตระกูล จากเดิม 225 จุดใน 2 ตระกูล
- สีเปลี่ยนตามสถานะถูกต้อง ทั้งปกติ ชี้ และปิดใช้งาน
- ลบคุณสมบัติที่ไม่ได้ใช้ 264 จุด จาก 66 ชุด
- ทั้งหน้า 130 ชุด ไม่เหลือคุณสมบัติที่ไม่มีชิ้นงานผูกแม้แต่ตัวเดียว
- ขนาด component เทียบก่อนหลังแล้วไม่เปลี่ยนสักตัว

#### **ที่เจอระหว่างทาง ไม่ได้แก้**

- แท็กรูปภาพทั้งสองแบบมีลูกชื่อ number ไม่ใช่ image น่าจะค้างจากตอนคัดลอกมาจากแท็กตัวเลข เป็นคนละเรื่องกับการ์ดนี้
