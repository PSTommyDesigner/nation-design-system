# [DS]-[Token] Fix หนี้เทคนิคระบบ token ขนาดปุ่มและชื่อที่ชนกัน

## รายละเอียดงาน

#### **ปัญหาที่ตรวจพบ**

**1. ขนาดปุ่มไม่ได้ใช้ระบบสเกลที่วางไว้**
มีระบบสเกลอยู่แล้ว (ฐาน 28 ขยับทีละ 8) แต่ค่าขนาดจริงของปุ่มทั้ง 3 ตระกูลพิมพ์ค่าตายไว้ ไม่ได้อ้างสเกล

- ปุ่มข้อความ ขนาด xs = 24
- ปุ่มไอคอน ขนาด xs = 28
- ปุ่มลิงก์ ขนาด xs = 22

ผลคือแก้ค่าที่ระบบสเกลแล้วไม่มีผลกับปุ่มเลย และตัวเลขฐานไม่ตรงกับที่สเกลกำหนด
**2. ชื่อ token ชนกันตอน build**
ตัวสร้างไฟล์รายงานชื่อชนกัน **972 จุดในโหมดสว่าง และ 996 จุดในโหมดมืด** เกิดจากชื่อใบซ้ำกันมาก เช่น hover 63 ครั้ง disabled 61 ครั้ง default 59 ครั้ง เมื่อแปลงเป็นชื่อตัวแปรจึงได้ชื่อเดียวกัน ตัวหลังทับตัวหน้า

#### **ความเสี่ยง**
ค่าที่ออกมาอาจไม่ใช่ค่าที่ตั้งใจ และแก้ token ตัวหนึ่งอาจไปกระทบอีกตัวโดยไม่รู้ตัว

#### **สิ่งที่ต้องทำ**

- เปิดรายละเอียดชื่อที่ชนกันทั้งหมด แล้วไล่ดูว่าคู่ไหนกระทบค่าจริง
- ปรับโครงชื่อหรือวิธีแปลงชื่อให้ไม่ชนกัน
- ทำให้ขนาดปุ่มทั้ง 3 ตระกูลอ้างระบบสเกลแทนการพิมพ์ค่าตาย
- ตรวจว่าหน้าตาก่อนและหลังไม่เปลี่ยน

#### **งานที่ทำวันนี้**
- **แก้ขนาดปุ่มไอคอนที่ผิดทุกขนาด** ให้ตรงไฟล์ออกแบบ ปุ่มจะได้สูงเท่ากันเวลาวางคู่กัน

- **แก้ระยะขอบปุ่มไอคอนในไฟล์ออกแบบ** ค่าเดิมตกค้างจากสมัยปุ่มยังสูงกว่านี้ คำนวณใหม่จากของจริง
- **กู้ระบบปรับขนาดที่ถูกลบหายกลับมา** เดิมแก้ค่าฐานแล้วไม่มีผล ตอนนี้แก้ที่เดียวถึงปุ่มทุกตัวจริง
- **ล้างค่าซ้ำซ้อนที่ทำให้ค่าทับกันเงียบ ๆ** พร้อมสคริปต์ล้างอัตโนมัติ กันไม่ให้กลับมาอีก
- **ลบชิ้นงานทดลองที่พังทิ้ง** ไม่มีที่ไหนใช้ และระบบยังทำไม่ถึงส่วนนั้น

#### **ผลลัพธ์**

- ค่าปุ่มทุกกลุ่มตรงกับไฟล์ออกแบบ ตรวจถึงค่าสุดท้ายไม่ได้ดูแค่ชื่อ
- ไม่มีชิ้นงานไหนเรียกค่ากลางที่ไม่มีอยู่จริงแล้ว
