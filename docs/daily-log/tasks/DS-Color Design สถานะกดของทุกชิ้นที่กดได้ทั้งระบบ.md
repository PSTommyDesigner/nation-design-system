# [DS]-[Color] Design สถานะกดของทุกชิ้นที่กดได้ทั้งระบบ

## รายละเอียดงาน

**Problem ปัญหาคืออะไร ? :**
- ทั้ง Design System ไม่มีสถานะกดเลยสักชิ้น ไล่ตัวแปรสีในคอลเลกชัน component ทั้งหมดแล้วพบคำลงท้ายบอกสถานะอยู่คำเดียวคือ hover จำนวน 102 ตัว
- ปุ่มใช้ชุด default hover focused disabled ซึ่งไม่มีสถานะกด
- ผู้ใช้ของเราอยู่บนมือถือเกิน 70 เปอร์เซ็นต์ ซึ่ง hover แทบไม่เกิดเลย แต่สถานะกดเกิดทุกครั้งที่แตะ การมี hover แต่ไม่มีสถานะกดจึงเป็นการลงแรงผิดที่
- เจอตอนทำการ์ดหน้า 14 Toggles เมื่อ 3 กันยายน 2569 ตอนนั้นตัดสินว่าไม่ใส่ให้สวิตช์ตัวเดียว เพราะจะกลายเป็นชิ้นเดียวในระบบที่มี
**Goal ทำเพื่ออะไร ? :**
- ทุกชิ้นที่กดได้มีสถานะกดที่ใช้สีและกติกาชุดเดียวกันทั้งระบบ
- มีคำตอบเดียวว่าสถานะกดต่างจาก hover อย่างไร และใช้เมื่อไหร่
**Requirements ขอบเขตงาน**
1. ตัดสินคำลงท้ายที่จะใช้ ระหว่าง pressed กับ active ให้ตรงกันทั้งระบบ ตอนนี้มี color/background/general/active อยู่แล้วซึ่งอาจใช้ซ้ำได้
2. สร้างสีสถานะกดให้ครบทุกตระกูล อย่างน้อยฝั่ง brand solid ที่ยังมีแค่ solid กับ solid-hover
3. ไล่เพิ่มสถานะกดให้ปุ่ม สวิตช์ แท็ก และชิ้นอื่นที่กดได้ พร้อมกันทีเดียว
4. สำหรับสวิตช์ ให้เพิ่ม token ความกว้างปุ่มกลมตอนกดกลับเข้า tokens/scale/toggle.mjs สูตรที่เตรียมไว้แล้วคือ knob บวก inset คูณ 2 ซึ่งเท่ากับความสูงราง คือยืดแนวนอนอย่างเดียว ไม่ใช่โตทุกทิศ
5. เขียนกติกาลงเอกสารว่าสถานะกดใช้เมื่อไหร่ และต่างจาก hover อย่างไร

- ที่ต้องจดหลายที่เพราะงานวิจัยยังเสนอให้เปลี่ยนรูปทรงปุ่มกลมตอนกด ถ้าไม่จดไว้คนรุ่นหลังจะกลับไปทำตามงานวิจัย

#### **ผลตรวจ**

- ไม่มีตัวแปรหรือ token ที่ทำให้ปุ่มกลมขยายหลงเหลือ ทั้งในไฟล์ออกแบบและในไฟล์ที่ build ออกมา

#### **worklog 2**

- วัดขนาดงานก่อนลงมือ พบว่าถ้าแตกแบบให้ทุกชิ้นต้องเพิ่ม 1,255 แบบ และต้องแบกภาระเพิ่มหนึ่งในสี่ทุกครั้งที่แก้ชิ้นงานตลอดไป
- ตัดสินร่วมกันให้ทำเฉพาะชั้นสีกับเอกสาร ไม่แตกแบบทุกชิ้น เพราะสถานะกดเป็นเรื่องของชั้นโค้ดเป็นหลัก คนออกแบบไม่ได้วางภาพสถานะกดลงงานจริง
- ค้นพบว่าระบบมีกติกาสีอยู่แล้ว คือสถานะชี้เลื่อนไปหนึ่งขั้นในแรมป์สี จึงนิยามสถานะกดเป็นเลื่อนอีกหนึ่งขั้นในทิศเดียวกัน ถ้าชนขั้นสุดขอบให้กลับทิศ
- สร้างตัวแปรสีสถานะกดทั้งระบบจากสูตรเดียว ไม่ได้เลือกสีทีละตัว ทุกตัวมีคำอธิบายกำกับว่าเลื่อนไปขั้นไหน
- ทำเอกสาร Interaction States บนหน้า 01 Color อธิบายสถานะทั้งห้า สูตรของสี ตัวอย่างจริง และกติกาการใช้

#### **ผลตรวจ**

- ตัวแปรสีใหม่ 244 ตัว ทุกสถานะชี้มีคู่สถานะกดครบ ไม่มีขาดไม่มีเกิน
- ในนั้นเป็นของปุ่มโดยเฉพาะ 63 ตัว
- 10 ตัวใช้ค่าเดียวกับสถานะชี้ในโหมดมืดชั่วคราว เพราะตระกูลนั้นสีพื้นฐานกับสีตอนชี้อยู่คนละแรมป์ เลื่อนขั้นไม่ได้
- เอกสารมีตัวอย่างจริง 15 ชิ้น ดึงจากตัวแปรจริง สแกนสะอาดทุกข้อ

#### **ยกเลิกขอบเขต**
