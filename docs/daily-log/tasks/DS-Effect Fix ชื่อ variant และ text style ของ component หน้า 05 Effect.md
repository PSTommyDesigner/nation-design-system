# [DS]-[Effect] Fix ชื่อ variant และ text style ของ component หน้า 05 Effect

## รายละเอียดงาน

**Problem ปัญหาคืออะไร ? :**
- ชื่อแกน variant ของ component ทั้ง 5 ชุดเป็นตัวใหญ่ คือ Size และ Type ซึ่งผิดกฎการตั้งชื่อที่กำหนดให้ variant เป็นตัวเล็ก
- ค่าของแกนใน focus-ring เป็นตัวใหญ่ด้วย คือ Brand Default Error Warning Success
- ข้อความข้างในตัว component ไม่ได้ผูก text style เลย รวม 62 จุด เป็นป้ายชื่อสไตล์กับค่าเงาที่พิมพ์ไว้ในตัว component เช่น Shadows/Bottom/xs และ 0 1px 2px rgba(0,0,0,.05)
- ตัวเลขค่าเงาในป้ายเป็นค่าที่พิมพ์มือ ถ้าแก้ค่าเงาจริงแล้วลืมแก้ป้าย ป้ายจะบอกค่าที่ไม่ตรงกับของจริง
**Goal ทำเพื่ออะไร ? :**
- ชื่อแกนและค่าของ variant ตรงกับกฎการตั้งชื่อเหมือนหน้าอื่นในไฟล์
- ข้อความทุกจุดผูก text style ที่ประกาศไว้จริง
**Requirements ขอบเขตงาน**
1. เปลี่ยนชื่อแกน variant จาก Size เป็น size ทั้ง 4 ชุดของเงาและพื้นหลังเบลอ และจาก Type เป็น type ในชุด focus-ring
2. เปลี่ยนค่าของแกนใน focus-ring เป็นตัวเล็กทั้ง 5 ค่า
3. ผูก text style ให้ข้อความในตัว component ครบ 62 จุด โดยใช้ preset ที่ประกาศใน typography.json เท่านั้น
4. ตัดสินว่าจะเก็บป้ายค่าเงาที่พิมพ์มือไว้ในตัว component หรือย้ายไปอยู่ในเอกสารอย่างเดียว เพื่อไม่ให้ป้ายกับค่าจริงหลุดจากกัน
5. เทียบขนาด component ก่อนหลังทุกตัวว่าไม่เปลี่ยน และตรวจว่า instance ที่ใช้อยู่ไม่พัง
