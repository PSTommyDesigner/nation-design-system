# [05 Effect]-[Shadow] Revamp ระบบเงาและเอฟเฟค (Design System)

## รายละเอียดงาน

#### **โจทย์**
ทบทวนระบบเอฟเฟค (เงา เบลอ วงแหวนโฟกัส) ของ Design System ทั้งชุด หลังพบว่ามีสไตล์รุ่นเก่าค้างอยู่จำนวนมากและมีสไตล์ที่ไม่ได้ใช้งานเลย

#### **ขอบเขต**

- ศึกษาแนวทางของ Design System เจ้าใหญ่ (Material 3, Fluent 2, Carbon, Polaris, Atlassian) แล้วสรุปเป็นแนวทางของเรา
- เก็บกวาดจุดที่ยังผูกสไตล์รุ่นเก่า
- ล้างสไตล์ที่ไม่ได้ใช้งาน
- เติมคำอธิบายการใช้งานให้ทุกสไตล์ และซิงก์ลงโค้ด
- ตั้งกฎว่าเมื่อสร้าง component ใหม่ต้องกำหนดเอฟเฟคให้ด้วยเสมอ

#### **ข้อตกลง**

- ตั้งชื่อสไตล์ตามขนาดเหมือนเดิม แล้วใช้คำอธิบายบอกหน้าที่แทน เพราะ Figma ไม่มีระบบชื่อย่อสำหรับเอฟเฟค
- โหมดมืดยังไม่มีแผนทำเอฟเฟค
- เงา 2 ชั้น และ inset shadow ยังไม่ทำ
