# [Sale Report]-[Deal Management] อัปเดตดีไซน์ทำเป็น 2 มุมมอง Customer List และ Sales List (Desktop)

## รายละเอียดงาน

**Problem ปัญหาคืออะไร ? :** เดิมทีเราตั้งใจจะเปลี่ยนหน้า Customer List เป็น BU List ไปเลยแต่ User แจ้งว่ายังจำเป็นต้องดูข้อมูลในมุมมอง Customer List อยู่
**Goal ทำเพื่ออะไร ? :** เพื่อให้ User มีความยืดหยุ่นสามารถเลือกดูรายงานได้ทั้ง 2 มิติ Customer List หรือ BU List ตามสถานการณ์ที่ต้องการ
**Requirements ขอบเขตงาน**

1. เพิ่มปุ่มสลับมุมมองที่หัวตารางเพื่อให้กดสลับระหว่าง Customer List หรือ BU List ได้
2. BU List  ใช้ดีไซน์ใหม่ที่ทำเสร็จแล้ว Customer List คงดีไซน์เดิมไว้ (ปรับ UI เล็กน้อยให้ Theme ตรงกัน)
3. กำหนดให้หน้าแรกที่เข้ามาเป็นมุมมอง BU List
