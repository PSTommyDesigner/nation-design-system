# [DS]-[Tabs] Design ระบบสเกลและเอกสาร หน้า 18 Tabs

## รายละเอียดงาน

**Problem ปัญหาคืออะไร ? :** หน้า 18 Tabs ยังไม่เคยถูกทำตามมาตรฐาน มีชิ้นงาน 4 ชุด รวม 54 แบบ แต่ไม่มีเอกสารสักชนิดเดียวจากที่ต้องมี 5 ชนิด ไม่มีตัวแปรของแท็บสักตัว ไม่มีไฟล์สูตรขนาด ชุดฐาน 2 ชุดตั้งชื่อซ้ำกันว่า _Tab base จนแยกกันไม่ออกในแผง Assets และขีดล่างนำหน้าทำให้ไฟล์อื่นหยิบไปใช้ไม่ได้ ชื่อชุดและชื่อแกนยังเป็นตัวใหญ่มีเว้นวรรค และมีขนาดเดียวคือสูง 40 กับ 38 ต่างจากหน้าอื่นที่คุมด้วยสูตร 5 ขนาด
**Goal ทำเพื่ออะไร ? :** ให้แท็บมีโครงที่ตัดสินจากงานวิจัย มีระบบสเกล 5 ขนาดที่คุมด้วยสูตรเหมือนแถบเลื่อน ช่องติ๊ก และปุ่มตัวเลือก ชื่อทุกชุดแยกตามทรงและลงท้ายด้วยชนิดตามกติกา และมีเอกสารครบชนิดตามมาตรฐาน
**Requirements ขอบเขตงาน**
1. วิจัยแท็บของ DS เจ้าใหญ่ก่อน เรื่องทรง segmented กับ underline ขนาด พื้นที่แตะ วิธีจัดการแท็บล้นจอ สถานะ และคีย์บอร์ดตามรูปแบบ WAI-ARIA
2. ตัดสินโครงจากผลวิจัย ได้แก่ จำนวนขนาด คุณสมบัติไอคอน จุดสถานะ และกลไกบอกแท็บปัจจุบันของทรง underline
3. สร้างไฟล์สูตรสเกล tokens/scale/tabs.mjs อ่านค่าจริงจากไฟล์ออกแบบก่อนตั้งสูตร แล้วสร้างตัวแปรและผูกให้ครบ
4. เปลี่ยนชื่อชุดเป็น segmented-tab underline-tab segmented-tab-group และ underline-tab-group พร้อมแก้ชื่อแกนและค่าของแกนให้ตรงกติกา
5. ขยายเป็น 5 ขนาด xs ถึง xl ทั้งสองทรง
6. กำหนดวงแหวนโฟกัสให้ผูกกับ effect style และเติมชื่อ component ใน description ของ style นั้น
7. ทำเอกสารครบ 5 ชนิดบนหน้า Figma และไฟล์ docs/18-tabs.md ในเครื่อง
8. สแกนปิดงานให้สีดิบ มุมโค้งไม่ผูก ระยะห่างไม่ผูก และขีดยาว เป็น 0 แล้วส่งต่อฝั่งโค้ด

## บันทึกงาน

### 2026-10-02 Tommyy_PS

#### **worklog 1**

- วิจัยแท็บจาก DS 15 เจ้าก่อนลงมือ แล้วใช้ผลวิจัยตัดสินโครงทุกข้อ ไม่ได้เดาเอง
- วัดค่าจริงจากไฟล์ออกแบบทุกชุดก่อนตั้งสูตร พบของที่ผิดมาแต่เดิม 6 เรื่อง
- ตั้งชื่อชุดใหม่ทั้ง 4 ชุดแยกตามทรง จากเดิมที่ชุดฐานสองชุดชื่อซ้ำกันจนแยกไม่ออกในแผงชิ้นงาน
- ทำระบบสเกลขนาดไปพร้อมกับชิ้นงานตามกฎ ยึดขนาดกลางเป็นค่าเดิมทุกค่า ของเดิมจึงไม่ขยับ
- ขยายจากขนาดเดียวเป็น 5 ขนาดครบทั้ง 4 ชุด แล้วจัดเป็นตารางให้แถวเป็นขนาด
- แยกแกนแท็บปัจจุบันออกจากแกนสถานะ แก้ของเดิมที่เอาสถานะโฟกัสมาใช้แทนแท็บที่เปิดอยู่
- แยกความหนาขีดใต้แท็บปัจจุบันออกจากเส้นรางของแท็บอื่น เพื่อให้ปรับตัวหนึ่งโดยไม่กระทบอีกตัว
- เปลี่ยนจุดบนแท็บจากจุดบอกสถานะเป็นจุดแจ้งเตือน ให้ตรงกับความหมายจริงและตรงกับที่ตลาดใช้
- ทำวงแหวนโฟกัสเป็นเส้นทึบยิงเข้าด้านใน เพราะแท็บวางติดกันและอยู่ในแถบที่เลื่อนได้ วงแหวนที่ยิงออกนอกจะทับแท็บข้างเคียงและถูกกรอบตัด
- เปลี่ยนไอคอนทั้งหน้าเป็นชุดปัจจุบันของระบบ และบังคับให้ข้อความใช้ชุดตัวอักษรสำเร็จรูปแทนการผสมเอง
- ทำเอกสารครบทุกชนิดตามมาตรฐาน ทั้งในไฟล์ออกแบบและไฟล์ในเครื่อง
- ส่งต่อให้ทีมพัฒนาแปลงเป็นโค้ด แล้วตรวจผลเองทุกข้อแทนที่จะเชื่อรายงาน

#### **ผลตรวจ**

- ชิ้นงาน 350 แบบ คือทรงละ 160 แบบ และกล่องครอบทรงละ 15 แบบ ความสูงตรงสูตรทุกแถว
- ตัวแปร 53 ตัว สร้างครบทั้งสองฝั่ง ตรวจแล้วไม่หลุดกันสักกลุ่ม
- เอกสารในไฟล์ออกแบบ 6 ใบ เรียงตามมาตรฐาน ช่องไฟ 200 ทุกช่วง
- สแกนปิดงาน สีดิบ 0 เส้นดิบ 0 มุมโค้งไม่ผูก 0 เงาที่ไม่ผูกสไตล์ 0 ข้อความไม่ใช้ชุดสำเร็จรูป 0 ขีดยาว 0
- ตัวตรวจชนิดข้อมูลฝั่งโค้ด 0 ข้อผิดพลาด และโค้ดใช้ตัวแปรของหน้านี้ครบ 53 จาก 53 ตัว
- แก้ของที่พลาดระหว่างทาง 198 แบบ และลบชุดที่ซ้ำเกินมา 3 ชุด 480 แบบ ตรวจก่อนลบว่าไม่มีชิ้นงานไหนอ้างถึง
- ขนาดชิ้นงานไม่เปลี่ยนสักตัวตลอดงาน ทั้งตอนเปลี่ยนชื่อ ตอนจัดลำดับ และตอนย้ายเข้าเอกสาร

#### **ที่ไม่ได้ทำตามที่เขียนไว้**

- ระยะห่าง 36 จุดบนหน้านี้ยังไม่ผูกตัวแปร ทั้งหมดอยู่ในชิ้นงานที่ใช้ร่วมกันทั้งไฟล์ คือหัวเอกสารและการ์ดวิธีอ่านตาราง ต้นฉบับอยู่หน้า 00 แก้แล้วกระทบทุกหน้า จึงไม่แตะตามกฎทำทีละหน้า และบันทึกเป็นงานค้างไว้แล้ว
- วงแหวนโฟกัสของแท็บใช้คนละแบบกับชิ้นงานอื่นในระบบ คือเส้นทึบยิงเข้าในแทนเงาฟุ้งยิงออกนอก เป็นของที่ตัดสินใหม่ระหว่างทาง เขียนเหตุผลกำกับไว้ในเอกสารแล้ว

### 2026-10-02 Tommyy_PS

#### **worklog 2**

- หัวหน้าตรวจแล้วแก้ดีไซน์เองในไฟล์ออกแบบหลายรอบ ผมตามตรวจ ผูกตัวแปร และอัปเดตฝั่งโค้ดกับเอกสารให้ตรงกันทุกรอบ
- เปลี่ยนวิธีบอกสถานะโฟกัส จากวงแหวนเป็นพื้นหลังสีอ่อนคู่กับข้อความสีแบรนด์ ตามที่หัวหน้าแก้มา
- เปลี่ยนสถานะชี้ให้ใช้พื้นเทากับเส้นเทาทั้งสองทรง และให้แท็บที่เปิดอยู่มีพื้นของตัวเองที่เข้มขึ้นตอนถูกชี้ จะได้ยังแยกออกว่าแท็บไหนเปิดอยู่
- ตั้งกฎสีเส้นใหม่ตามที่หัวหน้าสั่ง คือเส้นปกติใช้สีขอบหลัก เส้นตอนปิดใช้งานใช้สีขอบปิดใช้งาน ใช้กับทั้งทรงกล่องและทรงขีดเส้นใต้
- แยกความหนาเส้นแบ่งระหว่างแท็บออกจากเส้นรางใต้แท็บ เป็นคนละ token เพราะคนละหน้าที่ ค่าเท่ากันตอนนี้แต่ต้องปรับแยกกันได้
- ทำมุมโค้งของกล่องครอบให้โตตามขนาด จากเดิมคงที่ทุกขนาดจนกล่องเล็กดูมนเกินตัว เพิ่มสูตรเข้าสเกลกลางเหมือนปุ่มและแท็ก
- ลากเส้นเชื่อมสถานะชี้ให้ชิ้นงานทั้งสองชุด เอาไปทำต้นแบบกดได้ทันทีโดยไม่ต้องลากเพิ่ม
- ลบวงแหวนโฟกัสที่สร้างไว้แล้วไม่ได้ใช้ ทั้งสไตล์ ค่ากลาง และตัวแปลงที่เพิ่มให้ตัวสร้างไฟล์
- ตั้งขอบเขตการใช้งานให้ตัวแปรของชิ้นงานทั้งชั้น จากเดิมที่เปิดหมดทุกคุณสมบัติจนช่องเลือกรก

#### **ผลตรวจ**

- ผูกตัวแปรที่หัวหน้าแก้ไว้ 139 จุด และแก้สีเส้นตามกฎใหม่อีก 100 จุด
- ลากเส้นเชื่อมสถานะชี้ 80 เส้น ตรวจแล้วไม่มีเส้นไหนชี้ผิดเป้า
- ตัวแปรที่เปิดทุกขอบเขตลดจาก 710 เหลือ 128 ตัว ซึ่งเป็นชุดสีอเนกประสงค์ที่หัวหน้าสั่งให้เปิดไว้
- ชุดชิ้นงานทั้ง 4 ชุด สีดิบ 0 เส้นดิบ 0 มุมโค้งไม่ผูก 0 ความหนาเส้นไม่ผูก 0
- ด่านตรวจผ่านทั้งสองตัว สองฝั่งไม่หลุดกันสักกลุ่ม และตัวตรวจชนิดข้อมูล 0 ข้อผิดพลาด
- ขนาดชิ้นงานไม่เปลี่ยนสักตัวตลอดการแก้ทั้งหมด

#### **แก้คำรายงานผิด**

- คอมเมนต์ใบที่ 1 รายงานว่าผูกตัวแปรครบและสแกนสีดิบได้ 0 ซึ่งจริงแต่ไม่ครบความ มี 74 จุดที่ผูกไปที่ชั้นความหมายแทนชั้นชิ้นงาน ผิดกฎที่ให้ผูกจากชั้นชิ้นงานเท่านั้น
- สาเหตุคือหาตัวแปรด้วยชื่ออย่างเดียว ทั้งที่มีชื่อซ้ำกันข้ามชั้นถึง 243 ชื่อ ด่านตรวจที่มีจับไม่ได้เพราะมันผูกตัวแปรจริงและค่าเท่ากันเป๊ะ หัวหน้าเห็นตอนเปิดแผงตัวแปรดู
- แก้ครบ 74 จุดแล้ว และบันทึกวิธีกันพลาดไว้ในความจำของทีม
