#### **โจทย์**
ออกแบบระบบ Employee Profile ของโปรเจกต์ Nation House โดยยึดรูปแบบจากเว็บ HRMS เวอร์ชัน Desktop เป็นต้นแบบ

#### **ขอบเขต 2 หน้า**

- หน้าบันทึกเวลาของพนักงาน (มุมมองรายบุคคล)
- หน้าบันทึกเวลาของทีม (มุมมองหัวหน้า เห็นทั้งทีม)

#### **อ้างอิง**
เว็บ HRMS (Desktop) ใช้เป็นต้นแบบโครงหน้าและการจัดวาง
