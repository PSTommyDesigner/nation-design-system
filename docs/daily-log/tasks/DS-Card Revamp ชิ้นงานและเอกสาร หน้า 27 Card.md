# [DS]-[Card] Revamp ชิ้นงานและเอกสาร หน้า 27 Card

## รายละเอียดงาน

**Problem ปัญหาคืออะไร ? :**
- หน้า 27 มี component 73 ชิ้น 12 ชุด แต่ไม่มีเอกสารสักใบ เป็น 1 ใน 2 หน้าสุดท้ายของชั้นโมเลกุลที่ยังไม่มีเอกสาร
- ชื่อชุดยังเป็นรูปแบบเก่าทั้ง 12 ชุด มีขีดทับ มีตัวใหญ่ มีเว้นวรรค เช่น Content card / HC / News และ _Base / Event Item
- เลขอันดับทำเป็น component แยก 20 ตัว (md 10 ตัว sm 10 ตัว) แทนที่จะเป็นชุดเดียวที่มีคุณสมบัติตัวเลข
- ตัวอักษร 144 จุด ใช้ preset ของไฟล์นี้แค่ 19 จุด ที่เหลือไม่ผูกสไตล์ 70 จุด และใช้ชุดจากไลบรารีภายนอก 55 จุด
- สีดิบ 14 จุด เป็นหน้าเอกสาร component หน้าเดียวในไฟล์ที่ยังไม่สะอาด หน้าอื่นเหลือ 0 หมดแล้ว
- มีหัวเอกสารลอยบนแคนวาส 3 อัน ซึ่งเป็นสัญญาณว่าหน้านี้ยังไม่เคยจัดเป็นเอกสาร
- ชุด _Table header อยู่ผิดหน้า หน้าที่จริงเป็นของหน้า 26 Table
- tokens/scale/card.mjs นิยามแค่มุมโค้ง ยังไม่มีสูตรระยะห่างและขนาด และยังไม่มี component ฝั่งโค้ด

**Goal ทำเพื่ออะไร ? :**
- ยกเครื่องหน้า 27 ให้ได้มาตรฐานเดียวกับหน้า 23 24 25 คือ ชื่อตรงกติกา ตัวอักษรใช้ preset ของไฟล์ สีดิบ 0 มีสูตรขนาดในไฟล์เดียว และมีเอกสารครบชนิด
- ปิดชั้นโมเลกุลให้เหลือหน้าเดียวคือ 28 Dividers

**Requirements ขอบเขตงาน**
1. สแกนหาผู้ใช้ของทุกชุดก่อนแตะ โดยเฉพาะ info-card / do / don’t / how-to-read ซึ่งเอกสารทุกหน้าในไฟล์ใช้อยู่ ห้ามทำพัง
2. ตั้งชื่อใหม่ทั้ง 12 ชุดตามกติกา ตัวเล็ก ใช้ขีดกลาง ลงท้ายด้วยชนิด และห้ามมีขีดทับ
3. ยุบเลขอันดับ 20 ตัวเป็นชุดเดียวที่มีแกนขนาดและคุณสมบัติตัวเลข
4. เปลี่ยนตัวอักษรทุกจุดให้ใช้ text style preset ของไฟล์นี้
5. ล้างสีดิบของหน้าให้เหลือ 0
6. เติมสูตรระยะห่างและขนาดลง tokens/scale/card.mjs แล้ว build และ verify ให้ขึ้น ต้องดู 0 กลุ่ม
7. ทำเอกสารครบชนิด Page Doc 1 Token 1 Information อย่างน้อย 1 Component Previews และ Space 1
8. ย้ายชุด _Table header ไปหน้า 26 Table
9. ไม่ทำฝั่งโค้ดในการ์ดใบนี้ แยกเป็นการ์ดต่างหากหลังไฟล์ออกแบบนิ่ง

**Figma File :** [หน้า 27 Card](https://www.figma.com/design/QgmoT5Uuvv3elB96F4nsTq/?node-id=7130-26)
**Reference ตัวอย่างงานที่ชอบ :** หน้า 25 Dropdowns และ 24 Pagination ที่เพิ่งทำเสร็จ ใช้โครงเอกสาร 7 ใบและระบบสูตรขนาดแบบเดียวกัน
