# [DS]-[Color] Scan สีดิบที่เหลือในทุกหน้าของไลบรารี

## รายละเอียดงาน

#### **โจทย์**
ล้างสีที่ไม่ได้ผูกตัวแปรให้เหลือศูนย์ทุกหน้า ไม่ใช่แค่หน้าที่กำลังทำอยู่

#### **สถานะปัจจุบัน**

- หน้า 05 Effect ล้างครบแล้ว เหลือ 0 จุด (ผูกไป 77 จุด)
- หน้าอื่นทั้งไลบรารียังไม่ได้สแกน ไม่รู้ยอดจริง

#### **สิ่งที่ต้องทำ**

- สแกนทุกหน้า นับจำนวนสีดิบและระบุว่าอยู่หน้าไหนบ้าง
- เรียงลำดับตามผลกระทบ แล้วทยอยผูกตัวแปรทีละหน้า
- ผูกจากชุดตัวแปรของ component เท่านั้น ตามกฎที่ตั้งไว้
- สรุปยอดก่อนและหลังไว้ในการ์ด

#### **หมายเหตุ**
ของที่อยู่ในชิ้นงานสำเร็จรูปอาจแก้จากปลายทางไม่ได้ ต้องแยกนับไว้ต่างหากเหมือนกรณี 56 จุดของเงา
