# [DS]-[Pagination] Design ปุ่มโหลดเพิ่มสำหรับหน้าอ่านข่าว

## รายละเอียดงาน

#### Problem

- สแกน HTML จริงของเว็บในเครือ 12 หน้าเมื่อ 2026-10-12 แล้วพบ aria-current 0 จุด และลิงก์ที่มีเลขหน้า 0 จุด ทั้งเครือไม่มีตัวแบ่งหน้าแบบเลขหน้าเลย
- bangkokbiznews กับ komchadluek ใช้ปุ่มโหลดเพิ่ม ส่วน nationtv thansettakij springnews posttoday ใช้เลื่อนไม่สิ้นสุดโดยไม่มีปุ่มให้กด
- ปุ่มโหลดเพิ่มที่มีอยู่ไม่ได้มาตรฐาน bangkokbiznews เป็นปุ่มเปล่าไม่มีแอตทริบิวต์ใด ส่วน komchadluek ใช้ title ซึ่งโปรแกรมอ่านหน้าจอหลายตัวไม่อ่านและมือถือไม่มีผล
- ทั้ง 6 เว็บไม่มี aria-live หรือ role status จึงไม่มีการประกาศเมื่อข่าวชุดใหม่โหลดเข้ามา
- ข่าวชุดที่ 2 ขึ้นไปไม่มี URL ของตัวเอง canonical ชี้หน้าแรกเสมอ แชร์ บุ๊กมาร์ก และให้บอตค้นหาเก็บไม่ได้
- ระบบออกแบบยังไม่มีปุ่มโหลดเพิ่มเป็นชิ้นงาน

#### Goal

- มีปุ่มโหลดเพิ่มเป็นชิ้นงานมาตรฐานของระบบ ใช้กับหน้ารายการข่าวทุกเว็บในเครือ
- ผ่านเกณฑ์การเข้าถึงข้อ 2.5.5 ระดับ AAA เพราะผู้ใช้มือถือเกิน 70 เปอร์เซ็นต์ และกลุ่มเป้าหมายถึงอายุ 55
- ประกาศให้โปรแกรมอ่านหน้าจอรู้เมื่อโหลดข่าวชุดใหม่เข้ามา

#### Requirements

- สถานะที่ต้องมี ปกติ กำลังโหลด โหลดครบแล้ว และโหลดไม่สำเร็จ
- ขนาดพื้นที่กด มือถือ 48 จอคอม 40
- ย้ายโฟกัสไปที่รายการแรกของชุดใหม่ ไม่ใช่หัวรายการ ซึ่งต่างจากตัวแบ่งหน้าแบบเลขหน้า
- ทำไฟล์สูตรขนาดใน tokens/scale พร้อมด่านตรวจ ไปพร้อมกับตัวชิ้นงาน
- คุยกับทีมเว็บเรื่องให้ URL ขยับตามชุดที่โหลด ซึ่งเป็นสิ่งที่ Guardian ทำได้

#### Figma File

- ยังไม่มี ต้องตัดสินก่อนว่าจะอยู่หน้า 24 Pagination หรือแยกหน้าใหม่
