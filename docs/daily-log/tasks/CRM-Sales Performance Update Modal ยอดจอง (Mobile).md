# [CRM]-[Sales Performance] Update Modal ยอดจอง (Mobile)

## รายละเอียดงาน

**Problem ปัญหาคืออะไร ? :** โมดัลยอดจองทั้งหมดกับยอดจองตามประเภทลูกค้าแสดงแค่ประเภทลูกค้ากับเลขใบเสนอราคา ผู้ใช้ไม่รู้ว่าแต่ละรายการเป็นของลูกค้าเจ้าไหน และกรองดูเฉพาะประเภทที่สนใจไม่ได้ ต้องไล่อ่านทั้งตาราง
**Goal ทำเพื่ออะไร ? :** เห็นชื่อลูกค้าได้ทันทีในรายการ และกรองตามประเภทลูกค้าได้ในโมดัลเลย ไม่ต้องออกไปหน้าอื่น
**Requirements ขอบเขตงาน**

1. เพิ่มชื่อลูกค้าในแต่ละแถว คู่กับประเภทลูกค้าและเลขใบเสนอราคา
2. เพิ่มแท็กตัวกรองประเภทลูกค้า (Agency · Corp 1 · Direct) ในโมดัลยอดจองทั้งหมด
3. โมดัลยอดจองตามประเภทลูกค้าแสดงประเภทที่เลือกไว้ที่หัวโมดัล
4. หัวโมดัลสรุปมูลค่ารวมและจำนวนรายการตามตัวกรองที่เลือก
5. คงแท็บเลือกเดือนเดิมไว้ทั้งสองโมดัล
