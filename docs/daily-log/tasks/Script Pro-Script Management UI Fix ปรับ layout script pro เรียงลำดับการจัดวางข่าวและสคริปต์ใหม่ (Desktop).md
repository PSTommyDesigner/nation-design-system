## รายละเอียดงาน

**Problem ปัญหาคืออะไร ? :**

1. จำนวนข่าวและสคริปต์จริงมีจำนวนมากทำให้ความสูงของหน้าจอเยอะ ผู้ใช้ต้อง Scroll เยอะเกินไป
2. Header ที่ทับซ้อนกันกินพื้นที่หน้าจอเกือบ 40%-50% ทำให้ไม่เห็น ข่าวและสคริปต์ที่เป็นเนื้อหาหลักของระบบนี้
**Goal ทำเพื่ออะไร ? :** ลดความสูงของ UI ทั้งหมด ลดความทับซ้อนของ Header
**Requirements ขอบเขตงาน**

1. หน้ารวมสคริปต์
2. หน้าสร้างและแก้ไขสคริปต์
