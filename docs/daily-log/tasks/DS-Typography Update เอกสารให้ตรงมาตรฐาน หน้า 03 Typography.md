# [DS]-[Typography] Update เอกสารให้ตรงมาตรฐาน หน้า 03 Typography

## รายละเอียดงาน

**Problem ปัญหาคืออะไร ? :** เอกสารหน้า 03 Typography เขียนไว้ตั้งแต่เดือนกรกฎาคมก่อนมีมาตรฐานเอกสาร เอกสารประจำหน้ามีตัวอย่างฟอนต์และตารางขนาดยัดอยู่ ซึ่งต้องแยกไปเป็นเอกสารหลักการ มีจุดคั่นกลางประโยค 156 จุดกับขีดยาว 1 จุด ชื่อ layer ของ section ไม่สื่อความหมาย 13 เฟรม และไฟล์เอกสารในเครื่องไม่ได้อัปเดตมาตั้งแต่ 24 กรกฎาคม
**Goal ทำเพื่ออะไร ? :** ให้เอกสารหน้า 03 ตรงมาตรฐานเดียวกับหน้าที่ทำแล้ว เอกสารประจำหน้าเหลือแค่สรุป ตัวอย่างอยู่ในเอกสารหลักการ และผ่านการสแกนปิดงานทุกข้อ
**Requirements ขอบเขตงาน**
1. ย้ายหัวข้อ Font families กับชุดขนาดพื้นฐานออกจากเอกสารประจำหน้า ไปเป็นเอกสารหลักการใหม่ชื่อ Type Scale โคลนจากแม่แบบหน้า 00
2. แก้จุดคั่นกลางประโยค 156 จุดและขีดยาว 1 จุด
3. ตั้งชื่อ section ใหม่ 13 เฟรมให้สื่อความหมาย
4. เปลี่ยนหัวเอกสารประจำหน้าเป็น 03 Typography
5. ตรวจไฟล์เอกสารในเครื่องกับค่าจริงแล้วอัปเดต
6. สแกนปิดงานให้ขีดยาว สีดิบ และข้อความไม่ผูก text style เป็น 0
