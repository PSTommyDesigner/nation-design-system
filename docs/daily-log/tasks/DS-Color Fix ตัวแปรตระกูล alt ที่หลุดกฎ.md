# [DS]-[Color] Fix ตัวแปรตระกูล alt ที่หลุดกฎ

## รายละเอียดงาน

**Problem ปัญหาคืออะไร ?**
- ตัวแปรตระกูล -alt มี 53 ตัว กฎคือโหมดสว่างเท่ากับตัวฐาน ส่วนโหมดมืดเปลี่ยนเป็นเทากลาง แต่มี 9 ตัวที่หลุดกฎ
- ที่ชัดเจน 4 ตัว คือ text ams secondary-alt โหมดสว่างไม่เท่าตัวฐาน background system error-solid-alt โหมดมืดชี้ไป gray-light ตัวเดียวในระบบ และ utility ขั้น 50 ของ ams กับ brand ชี้ไป 900 ชนกับขั้น 100
- ที่เป็นเสียงข้างน้อยอีก 5 ตัว คือ foreground secondary-alt ของ ams กับ brand ใช้เทาขั้น 300 ขณะที่พวกเดียวกันใช้ขั้น 100 และ background solid-alt ของ error success warning ใช้เทาเกือบดำ ทั้งที่โหมดสว่างเป็นสีเข้มทึบ ความหมายกลับด้าน
**Goal ทำเพื่ออะไร ?**
- ตัวแปร -alt ทั้ง 53 ตัวเดินตามกฎเดียวกันหมด ตรวจแล้วไม่เหลือตัวหลุดกฎ
- ค่าใน Figma กับไฟล์ token ในเครื่องตรงกัน และ build ผ่านโดยไม่มี collision
**Requirements ขอบเขตงาน**
1. แก้ 4 ตัวที่ชัดเจนตามที่ระบุใน Problem
2. แก้ 5 ตัวที่เป็นเสียงข้างน้อยให้ตรงกับพวกเดียวกัน
3. แก้ที่ Figma variables ก่อน เพราะเป็นต้นทาง แล้วอัปเดตไฟล์ tokens ในเครื่องให้ตรงกัน
4. รัน build แล้วตรวจว่า collision เป็น 0
5. ไม่แตะตัวแปร -alt ที่เหลือ 44 ตัวที่ถูกอยู่แล้ว

- กฎการสะท้อนขั้นสีของ utility ที่เหลือ ซึ่งทำถูกอยู่แล้ว ใช้เป็นแบบอ้างอิง

#### **worklog 1**

- แก้ตัวแปร 8 ตัวใน collection semantics ซึ่งครอบคลุมอาการ 9 อย่าง เพราะ background system error-solid-alt ผิดสองอย่างพร้อมกันในตัวเดียว คือชี้ไป gray-light และใช้เทาเกือบดำ
- แก้ที่ Figma ก่อนเพราะเป็นต้นทาง แล้วอัปเดตไฟล์ tokens ในเครื่องให้ตรงกัน แล้วจึง build
- ตัวแปรชื่อเดียวกันใน collection component เป็น alias ของ semantics จึงตามค่าใหม่เองโดยไม่ต้องแก้ซ้ำ
- ค่าที่แก้ คือ text ams secondary-alt โหมดสว่างกลับไปเท่าตัวฐาน background solid-alt ของ error success warning โหมดมืดใช้เทาขั้น 700 ให้ตรงกับ border solid-alt แทนเทาเกือบดำที่กลืนพื้นหลัง utility ขั้น 50 ของ ams กับ brand ใช้เทาขั้น 950 ให้สะท้อนขั้นถูกและเลิกชนกับขั้น 100 และ foreground secondary-alt ของ ams กับ brand ใช้เทาขั้น 100 ให้ตรงกับพวกเดียวกัน

#### **ผลตรวจ**

- ตัวแปรตระกูล -alt ทั้ง 53 ตัว โหมดสว่างเท่าตัวฐานครบ ตัวที่หลุดเหลือ 0
- โหมดมืดเป็นเทากลางครบทั้ง 53 ตัว ไม่มีตัวไหนชี้ไปตระกูลสีอื่น
- บทบาทเดียวกันได้ค่าโหมดมืดตรงกันหมด ไม่เหลือกลุ่มที่ค่าไม่ตรงกัน
- utility สะท้อนขั้นถูกครบ 20 ตัว ตัวที่ผิดเหลือ 0
- build ผ่าน ไม่มีการชนกันของชื่อ และค่าใน variables.css ตรงกับที่ตั้งใจทั้ง 8 ตัวทั้งสองโหมด
- ไม่มีเอกสารในไฟล์ออกแบบหรือไฟล์ในเครื่องที่อ้างค่าเก่า

#### **แก้ตัวเลขที่เคยแจ้งไว้**

- ที่เคยจดว่าไม่สอดคล้อง 10 ตัว ไล่จากข้อมูลจริงได้ 8 ตัว แยกเป็นชัดเจน 4 และเสียงข้างน้อย 4 ตัวที่เหลือ ตัวเลข 10 เดิมสร้างซ้ำจากข้อมูลไม่ได้
