**Requirements ขอบเขตงาน **

1. ออกใบแจ้งหนี้แล้ว รอเก็บเงิน
2. ยังไม่จองเทียบเป้าที่เหลือ
3. ยังไม่จองเทียบเป้าที่เหลือ
4. เงินเข้าจริงเดือนไหน
