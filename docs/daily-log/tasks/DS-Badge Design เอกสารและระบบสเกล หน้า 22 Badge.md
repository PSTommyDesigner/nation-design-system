# [DS]-[Badge] Design เอกสารและระบบสเกล หน้า 22 Badge

## รายละเอียดงาน

**Problem ปัญหาคืออะไร ?**
- หน้า 22 Badge มี 140 ชุด 700 แบบ แต่ไม่มี token สักตัว ขนาดทุกอย่างเป็นค่าดิบ และข้อความไม่ได้ผูก text style เลยสักชุด ผิดกฎ preset-only
- ความสูงเดิม 18 20 22 26 28 ขั้นห่าง 2 2 4 2 ไม่เท่ากัน ทำเป็นสูตรไม่ได้ ทั้งที่ Badge กับ Tag มีโครงชั้นเดียวกันและใช้ค่าอื่นตรงกันหมดอยู่แล้ว
- ชื่อไม่ตรงกฎ ไม่มีชุดไหนลงท้ายด้วย badge มีชื่อซ้ำ 3 คู่ในทุกตระกูลเพราะไอคอนล้วนแบบกลมกับแบบมุมมนใช้ชื่อเดียวกัน และมี icon-icon ที่คำซ้ำในชื่อเดียว
- หน้านี้ไม่มีเอกสารสักชนิดจาก 5 ชนิดที่มาตรฐานกำหนด และไม่เคยมีที่ไหนเขียนว่า Badge ต่างจาก Tag อย่างไร คนหยิบไปใช้จึงเดาเอง
**Goal ทำเพื่ออะไร ?**
- ขนาดทุกมิติมาจากสูตรในไฟล์เดียว และผูกตัวแปรครบ ไม่เหลือค่าดิบ
- ความสูงเท่ากับแท็กทุกขนาด เพราะเป็นของตระกูลเดียวกันและวางคู่กันได้
- ชื่อทุกชุดผ่านกติกา และไม่มีชื่อซ้ำในตระกูลเดียวกัน
- มีเอกสารครบ 5 ชนิด และมีที่อยู่ของกติกาเลือกใช้ระหว่าง Badge กับ Tag
**Requirements ขอบเขตงาน**
1. สร้างระบบสเกลใน tokens/scale/badge.mjs พร้อมด่านตรวจ แล้ว build
2. สร้างตัวแปรใน Figma แล้วผูกครบทุกมิติ ทั้งความสูง ระยะขอบ ช่องไฟ ขนาดไอคอน
3. เปลี่ยนความสูงเป็นชุดเดียวกับแท็ก คือ 16 20 24 28 32
4. ผูก text style ตระกูล label ให้ข้อความทุกชุด
5. ตั้งชื่อใหม่ทั้ง 140 ชุด และแก้ชื่อคุณสมบัติที่มีเว้นวรรค
6. ทำเอกสารครบ 5 ชนิด
7. ไม่เพิ่มแกน state เพราะตัดสินแล้วว่า Badge เป็นของนิ่ง

#### **ผลตรวจ**

- ป้ายเหลือ 4 ชุดต่อตระกูล รวม 40 ชุด จากเดิม 140 ชุด และชื่อขนานกับปุ่มพอดี
- แบบเพิ่มจาก 700 เป็น 800 เพราะเติมช่องที่เดิมขาด คือแบบข้อความล้วนของทรงแคปซูล และแบบไม่มีพื้นของไอคอนทรงมุมมน
- ความสูง 16 20 24 28 32 เท่ากับแท็กทุกขนาด วางคู่กันในแถวเดียวได้
- ระยะขอบที่ยังไม่ผูกตัวแปรเหลือ 0 ข้อความที่ยังไม่ผูก text style เหลือ 0 การผูกคุณสมบัติที่ขาดเหลือ 0
- ลบคุณสมบัติที่ประกาศไว้แต่ไม่มีชิ้นงานผูก 84 จุดจาก 42 ชุด หลังตรวจ 3 ข้อ
- เอกสาร 5 ชนิด คือ Page Documentation 12 section พร้อมตัวอย่างจริง 17 ตัว Token Document 9 แถว Guide 3 ตาราง Component Previews 10 ตระกูล และ Space Document 2 ตาราง
- สแกนทั้งหน้า 4,934 ชิ้น สีดิบ 0 ขีดยาว 0 จุดคั่นผิดที่ 0
- ยืนยันก่อนยุบว่าไม่มี instance ที่ไหนในไฟล์หยิบป้ายไปใช้ สแกน 51 หน้า 16,784 instance พบ 0 จึงยุบได้โดยไม่มีอะไรพัง

#### **ที่พลาดระหว่างทางและแก้แล้ว**

- ตั้งชื่อ variant ก่อนย้ายเข้าชุดใหม่ ทำให้ Figma ตีความกับแกนของชุดเดิม ชื่อเพี้ยน 15 ตัว แก้เป็นย้ายก่อนแล้วค่อยตั้งชื่อ
- การโคลนทำให้การผูกคุณสมบัติหลุด 10 แบบ ซึ่งเป็นกับดักเดิมที่เคยเจอ แก้ด้วยการผูกกลับแบบอิงบทบาทแทนอิงชื่อชั้น
- สคริปต์ล้ม 2 ครั้งแรก Figma ย้อนกลับให้ครบ ไม่มีอะไรค้างเสียหาย
