# [DS]-[Table] Fix เซลล์ table cell avatar ที่มีสวิตช์ล้นออกนอกกรอบ

## รายละเอียดงาน

**Problem ปัญหาคืออะไร ? :**
- component ชื่อ Table / Cell / Avatar เป็นเซลล์สูง 44px แต่ข้างในมี instance ของ Text Toggle สูง 66px ยัดอยู่ คือล้นออกนอกเซลล์ 22px
- ชื่อกับเนื้อหาขัดกันเอง เซลล์ชื่อ avatar แต่ของข้างในเป็นสวิตช์ ไม่ใช่อวาตาร์
- เจอตอนสำรวจ instance ของสวิตช์ทั้งไฟล์ระหว่างทำการ์ดหน้า 14 Toggles เมื่อ 3 กันยายน 2569 เป็นบั๊กที่มีอยู่ก่อนแล้ว ไม่ได้เกิดจากงานนั้น
**Goal ทำเพื่ออะไร ? :**
- เซลล์ตารางมีเนื้อหาที่ตรงกับชื่อ และไม่มีของล้นออกนอกกรอบ
**Requirements ขอบเขตงาน**
1. ตัดสินก่อนว่าเซลล์นี้ควรเป็นอะไร ระหว่างเซลล์อวาตาร์จริง หรือเซลล์สวิตช์ที่ตั้งชื่อผิด
2. ถ้าเป็นเซลล์อวาตาร์ ให้เอาสวิตช์ออกแล้วใส่อวาตาร์แทน
3. ถ้าเป็นเซลล์สวิตช์ ให้เปลี่ยนชื่อตามกฎการตั้งชื่อ และปรับความสูงเซลล์ให้รับเนื้อหาได้
4. ตรวจว่ามีเซลล์ตัวอื่นในหน้า 28 Table ที่มีอาการเดียวกันอีกไหม
**Figma File :**
- [หน้า 28 Table](https://www.figma.com/design/QgmoT5Uuvv3elB96F4nsTq/?node-id=9377-29760)
**Reference ตัวอย่างงานที่ชอบ :**
- ไม่มี เป็นการแก้ของที่ผิดอยู่แล้วให้ตรงกับระบบเดิม

## บันทึกงาน

### 2026-09-03 Tommyy_PS

#### **ปิดการ์ด 1**

- ปิดการ์ดนี้เพราะตั้งอยู่บนข้อมูลที่ผิด ไม่มีงานต้องทำ
- ตอนสำรวจ instance ของสวิตช์เมื่อ 3 กันยายน 2569 อ่านแค่ขนาดกับลำดับชั้น แล้วสรุปว่ามีสวิตช์พร้อมข้อความสูง 66 อยู่ในเซลล์สูง 44 จึงล้นออกนอกกรอบ
- ตรวจซ้ำแล้วพบว่าสวิตช์ตัวนั้นถูกซ่อนอยู่ เป็นตัวเลือกสำรองที่วางซ้อนไว้พร้อมกับช่องติ๊กและปุ่มตัวเลือกที่ซ่อนเหมือนกัน ส่วนที่แสดงจริงในเซลล์คือรูปอวาตาร์ ซึ่งตรงกับชื่อเซลล์อยู่แล้ว

#### **ผลตรวจ**

- ไม่มีอะไรล้น ไม่มีอะไรพัง และชื่อเซลล์ไม่ได้ขัดกับเนื้อหา
- บทเรียนคือสำรวจชิ้นงานต้องเช็คการมองเห็นด้วย ไม่ใช่อ่านแค่ขนาดกับลำดับชั้น
