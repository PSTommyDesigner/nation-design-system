# [DS]-[Space] Revamp หน้า 07 Space

## รายละเอียดงาน

**Problem ปัญหาคืออะไร ? :**
หน้า 07 Space เขียนสเกลระยะห่างไว้ 26 ขั้นเป็นตัวเลขลอย ไม่ผูกกับ token ใดเลย ฝั่งโค้ดไม่มีสเกลระยะห่างกลาง มีแต่ค่าเฉพาะของปุ่ม ตารางบนหน้าวาดเองไม่ได้ใช้ table-cell ของระบบ หัวคอลัมน์ยังเขียนว่า Shape Scale ที่ก๊อปมาจากหน้า 06 และหน้านี้ไม่มีเอกสารสักชนิดตามมาตรฐาน

**Goal ทำเพื่ออะไร ? :**
มีสเกลระยะห่างกลางที่เดียวในโค้ด ตัวแปรใน Figma ตรงกับโค้ดทุกค่า และหน้า 07 มีเอกสารครบตามมาตรฐาน ใครหยิบไปใช้ก็ได้ค่าเดียวกัน แก้ที่เดียวขยับทั้งระบบ

**Requirements ขอบเขตงาน**

1. สำรวจของจริงทั้งไฟล์ นับค่าระยะห่างที่ใช้จริงทุกหน้า และสแกนฝั่งโค้ด
2. หาข้อมูลระบบระยะห่างของ DS เจ้าใหญ่ เก็บเป็นเอกสารวิจัย
3. ตัดสินสเกลกลางแล้วนิยามในโค้ดที่ tokens/scale
4. สร้างและผูกตัวแปรระยะห่างใน Figma ให้ตรงกับโค้ด
5. ทำเอกสารหน้า 07 ใหม่ตามมาตรฐาน Page Document Information Document และ Token Document
6. เขียนเอกสารประจำหน้า docs/07-space.md
7. ไม่ทำในรอบนี้ ไล่ผูกระยะห่างของทุก component ทั้งไฟล์ จะทยอยทำตอนถึงคิวของแต่ละหน้า

### 2026-08-26 Tommyy_PS

#### **สรุปงานการ์ดนี้ 1**

- หาข้อมูลระบบระยะห่างของ 14 เจ้า อ่านจากไฟล์ค่ากลางต้นทางจริงไม่ใช่หน้าเว็บสรุป เก็บเป็นเอกสารวิจัยไว้ใช้อ้างอิงต่อ
- สำรวจของจริงในไฟล์ 27 หน้า 46,556 จุด พบว่าตัวเลขบนหน้าเดิมไม่ได้ผูกกับอะไรเลย และมี 7 ขั้นที่ไม่มีใครใช้
- ตั้งชุดค่ากลางของระยะห่างครั้งแรกของระบบ ลงทั้งฝั่งโค้ดและไฟล์ออกแบบให้ตรงกัน 26 ค่า แบ่ง 5 กลุ่ม กลุ่มละ 5 ขนาด ตามชุดเดิมที่หัวหน้าออกแบบไว้
- เก็บเป็นสูตรไม่ใช่ตัวเลขตาย แต่ละกลุ่มมีค่าเริ่มต้นกับระยะก้าวของตัวเอง แก้ทีเดียวขยับทั้งกลุ่ม
- กำหนดขอบเขตให้ชัดว่าชุดค่านี้ใช้กับการจัดเนื้อหาในหน้าและใน section ส่วนระยะห่างภายในชิ้นงานเป็นของชิ้นงานนั้นเอง
- รื้อหน้าเอกสารใหม่ทั้งหน้า จากเดิมมีกองเดียวที่ค่าผิดและตารางวาดเอง เป็นเอกสาร 4 ฉบับตามมาตรฐาน
- เลิกใช้จุดคั่นคำตามที่ตกลงใหม่ ไล่ล้างทั้งไฟล์ออกแบบและเอกสารในเครื่อง 1,755 จุดใน 36 ไฟล์ พร้อมแก้กฎที่เขียนไว้เดิม

**ผลลัพธ์**

- สองฝั่งตรงกันทุกค่า ตรวจด้วยการอ่านค่ากลับมาเทียบทีละตัว ไม่ได้ดูแค่ว่าสั่งสำเร็จ
- สแกนปิดงาน สีดิบ 0 เส้นดิบ 0 ขีดยาว 0 จุดคั่นนอกรายการ 0 และไม่มีข้อความชุดเก่าค้าง
- เผยแพร่ไลบรารีแล้ว ไฟล์อื่นเห็นตัวแปรชุดใหม่ 26 ตัว

**ติดปัญหาและบทเรียน**

- เสนอชุดค่าใหม่โดยดูจากสถิติการใช้อย่างเดียว โดยไม่ได้ถามที่มาของของเดิมก่อน สุดท้ายกลับไปใช้ชุดเดิม บทเรียนคือของที่มีอยู่ก่อนต้องถามที่มาก่อนเสนอให้เปลี่ยน
- ลบตัวแปรพลาดไปหนึ่งตัวตอนสลับชุด จับได้เพราะนับจำนวนหลังลบแล้วไม่ตรง สร้างคืนครบแล้ว
