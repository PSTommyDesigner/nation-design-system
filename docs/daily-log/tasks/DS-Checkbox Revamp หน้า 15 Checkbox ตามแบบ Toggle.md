# [DS]-[Checkbox] Revamp หน้า 15 Checkbox ตามแบบ Toggle

## รายละเอียดงาน

**Problem ปัญหาคืออะไร ? :**

- หน้า 15 Checkbox มีแต่ชุด component เปล่า ไม่มีเอกสารสักใบ ไม่มี token สักตัว ขนาดและมุมโค้งเป็นค่าดิบทั้งหมด
- แบ่งเป็นสองชุดที่ทับตำแหน่งกัน และแกน variant มีแกนที่มีค่าเดียว กับคู่ที่เป็นไปไม่ได้คือ ติ๊กแล้ว บวก กึ่งเลือก
- ข้อความช่วยของขนาด md เยื้องเกินไป 2 พิกเซล ทำให้ไม่ตรงแนวกับหัวข้อ และข้อความไม่ได้ผูก text style สักตัว

**Goal ทำเพื่ออะไร ? :**

- ให้หน้า 15 มีมาตรฐานเท่าหน้า 14 Toggles ทุกชั้น ทั้งสูตรขนาด ตัวแปร โครงชุด และเอกสาร
- ค่าทุกค่ามาจากสูตรที่ตรวจสอบได้ ไม่มีตัวเลขที่อธิบายที่มาไม่ได้

**Requirements ขอบเขตงาน**

1. เขียนสูตรขนาดแบบสองชั้นใน tokens/scale/checkbox.mjs พร้อมด่านตรวจในตัว
2. สร้างตัวแปรในไฟล์ออกแบบแล้วผูกครบทุกค่า
3. จัดแกน variant ให้เหลือ 3 แกน และขยายเป็น 5 ขนาด
4. ผูก text style ให้ข้อความ และแก้การเหลื่อมของข้อความช่วย
5. ทำเอกสารครบ 5 ชนิดในไฟล์ออกแบบ และเอกสารฝั่งโค้ด docs/15-checkbox.md
6. จัดเอกสารที่เก็บชุดจริงและชิ้นส่วนฐานให้เหมือนหน้า 14 Toggles (พบว่ายังต่างกัน ตรวจ 2026-09-14)

### 2026-09-14 Tommyy_PS

#### **worklog 1**

- เขียนสูตรขนาดแบบสองชั้นตามแบบของสวิตช์ ภาพช่องติ๊กมีสเกลของตัวเอง ส่วนแถวที่กดได้อ้างสเกลความสูงตัวควบคุมกลาง พร้อมด่านตรวจในตัว
- สร้างตัวแปรในไฟล์ออกแบบแล้วผูกครบทุกค่า ทั้งขนาด มุมโค้งรายมุม เส้นขอบ ระยะห่าง ระยะเยื้อง และขนาดเครื่องหมาย
- แก้สูตรมุมโค้งใหม่ เพราะของเดิมทำให้สัดส่วนต่อขนาดกล่องห่างกันมากจนขนาดเล็กสุดเป็นเหลี่ยมตรง ไม่เป็นตระกูลเดียวกัน
- ยุบแกนของชุดจากห้าแกนเหลือสามแกน ตัดแกนที่มีค่าเดียวทิ้ง และรวมสองแกนที่เคยสร้างคู่ที่เป็นไปไม่ได้ให้เหลือแกนเดียวสามค่า
- ขยายจากสองขนาดเป็นห้าขนาดทั้งสองชุด
- เปลี่ยนชื่อชุดใหม่ ให้กล่องเปล่าเป็นตัวควบคุมจริง และตัวที่มีข้อความแยกออกไป เพราะชื่อที่ขึ้นต้นด้วยขีดล่าง Figma จะไม่ส่งออกไปไฟล์อื่น
- ตัดคุณสมบัติเปิดปิดหัวข้อออก เพราะถ้าไม่ต้องการข้อความก็ใช้อีกชุดอยู่แล้ว การมีสองทางที่ให้ผลเหมือนกันเป็นต้นเหตุให้ไฟล์เละ
- ผูก text style ให้ข้อความทั้งสองชั้นที่เดิมไม่ได้ผูกเลย และแก้การเหลื่อมของข้อความช่วยที่เยื้องเกิน
- เปลี่ยนเครื่องหมายถูกและขีดกึ่งเลือกจากไลบรารีนอกไฟล์ มาเป็นไอคอนในเซ็ตของเรา
- ทำเอกสารในไฟล์ออกแบบครบทุกชนิดตามแบบหน้าสวิตช์ และเขียนเอกสารฝั่งโค้ดพร้อมข้อควรระวังที่บันทึกบทเรียนจากงานนี้

#### **ผลตรวจ**

- สองชุด ชุดละ 60 แบบ จากเดิมรวมกัน 48 แบบ
- ตัวแปรในไฟล์ออกแบบ 42 ตัว และค่าฝั่งโค้ด 43 ตัว
- ข้อความสองแถวตรงแนวกัน เหลื่อม 0 จาก 60 แบบ
- ชิ้นงานที่ใช้อยู่ 368 จุดไม่พัง ข้อความที่แก้ทับไว้กลับมาครบทุกตัว ตรวจ 3 หน้า ตรงกับก่อนแก้ทุกจำนวน
- สัดส่วนมุมโค้งต่อขนาดกล่อง ช่วงห่างลดจาก 28.6 จุด เหลือ 4.8 จุด
- ไอคอนนอกเซ็ตเหลือ 0 จากเดิม 80 จุดที่พึ่งไลบรารีนอกไฟล์
- เอกสารในไฟล์ออกแบบ 7 ใบ และเอกสารฝั่งโค้ด 1 ไฟล์ ข้อควรระวัง 13 ข้อ
- สีดิบ 0 ขีดยาว 0 ข้อความแม่แบบค้าง 0 ข้อความไม่ผูก text style 0
