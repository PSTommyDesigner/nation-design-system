#### **งานที่ทำวันนี้**
- **ไล่ตรวจเอกสารประจำหน้าทุกหน้า** (สี · ไอคอน · ตัวอักษร · ปุ่ม · ตาราง) เก็บข้อความที่ยังเป็นภาษาโปรแกรมมิ่งให้เป็นภาษาทั่วไป · หน้าตาราง (27) เขียนใหม่ทั้งหน้า · คงศัพท์โค้ดเฉพาะ "รายชื่อ token" ที่นักพัฒนาต้องใช้
- **แทนการ์ดที่วาดมือในเอกสารด้วยชิ้นสำเร็จรูป (component)** ครบทุกหน้า การ์ดคำแนะนำ (ควรทำ/ไม่ควรทำ) · การ์ดวิธีอ่าน · การ์ดอธิบายโครง → แก้ที่ต้นแบบทีเดียวเปลี่ยนทุกที่
- **แก้ความผิดพลาด:** เผลอแทนการ์ด "ตัวอย่างการใช้ปุ่ม" (ที่มีปุ่มตัวอย่างข้างใน) ด้วยการ์ดข้อความ ทำให้ปุ่มตัวอย่างหาย → **สร้างใหม่ครบ 8 ใบ** ด้วยปุ่มจริง (เลือกแบบให้ตรงบริบท ควร/ไม่ควร) + คำอธิบาย
- **วางระบบกันพลาดซ้ำ:** เพิ่มกฎ "ก่อนลบ/แทนของเป็นชุด ต้องตรวจเนื้อหาก่อน" เข้าคู่มือหลัก

#### **ผลลัพธ์**
- เอกสารประจำหน้าทุกหน้าอ่านเข้าใจง่ายสำหรับคนทั่วไป
- การ์ด/ตารางในเอกสารเป็นชิ้นสำเร็จรูป แก้ทีเดียวเปลี่ยนทั้งระบบ
- ตัวอย่างการใช้ปุ่มกลับมาแสดงปุ่มจริงถูกต้อง

#### **ติดปัญหา**
- พลาดแทนการ์ดตัวอย่างปุ่มโดยไม่ตรวจเนื้อหาก่อน ทำให้ปุ่มตัวอย่างหาย → กู้คืนด้วยการสร้างใหม่ + เพิ่มกฎกันซ้ำ
- ไอคอนแบรนด์ (LINE) วาดเองไม่ได้ ต้องใช้ไฟล์โลโก้ทางการ
