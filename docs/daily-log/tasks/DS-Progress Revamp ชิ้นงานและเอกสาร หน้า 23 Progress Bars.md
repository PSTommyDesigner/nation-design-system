# [DS]-[Progress] Revamp ชิ้นงานและเอกสาร หน้า 23 Progress Bars

## รายละเอียดงาน

**Problem ปัญหาคืออะไร ? :** หน้า 23 Progress Bars ยังไม่เคยถูกทำตามมาตรฐาน มี 3 ชุด รวม 91 แบบ แต่ไม่มีเอกสารสักชนิด ไม่มีตัวแปร ไม่มีไฟล์สูตรขนาด และไม่มีโค้ด ปัญหาเชิงโครงที่หนักที่สุดคือ เอาค่าข้อมูลมาทำเป็นแกนของชุด แถบแนวนอนมีแกนเปอร์เซ็นต์ 11 ค่าตั้งแต่ 0 ถึง 100 คูณกับตำแหน่งป้าย 5 ค่า กลายเป็น 55 แบบ ทั้งที่ความคืบหน้าเป็นข้อมูลที่เปลี่ยนตลอดเวลา ไม่ใช่สิ่งที่ควรวาดทีละค่า ส่วนทรงวงกลมกับครึ่งวงกลมมีแกนเปอร์เซ็นต์แค่ 3 ค่า คือ 0 50 และ 100 ซึ่งไม่ตรงกับแถบแนวนอนทั้งที่เป็นเรื่องเดียวกัน นอกจากนี้แถบแนวนอนไม่มีแกนขนาดเลย แต่ทรงวงกลมมี 6 ขนาดและมีขั้น 2xl ซึ่งอยู่นอกสเกล 5 ขั้นของระบบ ชื่อชุดไม่ลงท้ายด้วยชนิดและมีเว้นวรรค ชื่อแกนและค่าเป็นตัวใหญ่มีเว้นวรรค และแกนตำแหน่งป้ายมีค่า False ปนอยู่ ซึ่งควรเป็นคุณสมบัติเปิดปิด ไม่ใช่ค่าในแกน**Goal ทำเพื่ออะไร ? :** เอาค่าข้อมูลออกจากแกนของชุด ให้ความคืบหน้าเป็นค่าที่ส่งเข้ามา ไม่ใช่แบบที่ต้องวาด ทำให้สามทรงใช้แกนและสเกลเดียวกัน มีระบบสเกลที่คุมด้วยสูตรเหมือนหน้าอื่น มีเอกสารครบชนิด และมีโค้ดที่ทำเรื่องการเข้าถึงครบตามเกณฑ์**Requirements ขอบเขตงาน**
1. วิจัยแถบความคืบหน้าของ DS เจ้าใหญ่ก่อน เรื่องแบบรู้ค่ากับไม่รู้ค่า ทรงที่ควรมี แกนขนาด ตำแหน่งป้าย การแสดงเปอร์เซ็นต์ การเคลื่อนไหว และการเข้าถึง
2. ตัดสินโครงจากผลวิจัย โดยเฉพาะว่าจะเอาแกนเปอร์เซ็นต์ออกจากชุดอย่างไร และจะวาดกี่ค่าไว้เป็นตัวอย่าง
3. ทำให้สามทรงใช้แกนขนาดชุดเดียวกัน และตัดสินว่าจะเก็บขั้น 2xl ไว้หรือยุบเข้าสเกล 5 ขั้นของระบบ
4. เปลี่ยนตำแหน่งป้ายจากค่าในแกนที่มี False ปนอยู่ ให้เป็นคุณสมบัติเปิดปิดกับแกนตำแหน่งที่แยกจากกัน
5. สร้างไฟล์สูตร tokens/scale/progress.mjs แล้วสร้างตัวแปรและผูกให้ครบ
6. เปลี่ยนชื่อชุดให้ลงท้ายด้วยชนิด และแก้ชื่อแกนกับค่าให้ตรงกติกา
7. ทำเอกสารครบทุกชนิดบนหน้า Figma และไฟล์ docs/23-progress-bars.md ในเครื่อง
8. ทำโค้ดที่ทำเรื่องการเข้าถึงครบ ทั้งแบบรู้ค่าและไม่รู้ค่า และเคารพโหมดลดการเคลื่อนไหว
9. สแกนปิดงานให้สีดิบ มุมโค้งไม่ผูก ระยะห่างไม่ผูก และขีดยาว เป็น 0

### 2026-10-09 Tommyy_PS

#### **worklog 1**

- สำรวจของเดิมแล้วพบปัญหาเชิงโครงที่หนักที่สุดคือ เอาค่าเปอร์เซ็นต์ซึ่งเป็นข้อมูลมาทำเป็นแกนของชุด แถบแนวนอนจึงมี 55 แบบเพื่อแสดงค่า 11 ค่า
- ตรวจเองด้วยการวัดแล้วยืนยันของเสียเชิงโครง 3 เรื่อง คือ แบบที่ชื่อว่าครึ่งหนึ่งวาดไว้ที่ 57.5 เปอร์เซ็นต์ จุดเริ่มของตัวเติมห่างจากจุดเริ่มของราง 180 องศา และสัดส่วนความหนาวงแหวนไหลจาก 14.3 ลงมา 9.8 เปอร์เซ็นต์ ทำให้วงเล็กดูหนาเทอะทะและวงใหญ่ดูบาง
- ยุบของเดิม 3 ชุด 91 แบบ เหลือ 3 ชุด 20 แบบ โดยให้เฉพาะสิ่งที่เป็นรูปทรงเป็นแกน ส่วนสิ่งที่เปิดปิดได้ใช้คุณสมบัติแบบเปิดปิด
- ถอดขนาด 2xl ออก เพราะสำรวจตลาด 15 เจ้าแล้วไม่มีเจ้าไหนใช้เลย และขัดกับสเกลห้าขั้นของระบบ
- ทำไฟล์สูตรขนาดที่ทำให้กล่องวงแหวนและความสูงครึ่งวงเป็นค่าอนุพันธ์ พร้อมด่านตรวจและสมการปิด 3 สมการ ซึ่งแก้บั๊กที่ขนาดใหญ่สุดวงแหวนล้นออกนอกกล่อง 2
- สร้างตัวแปร 51 ตัว และเพิ่มกลไกในตัวสร้าง token ให้ไฟล์สูตรหนึ่งไฟล์ประกาศ component ได้หลายชื่อ เพราะสามชิ้นงานนี้ใช้ตัวเลขชุดเดียวกัน
- สลับที่ใช้งานจริงบนหน้า 36 Templates ครบ 20 จุด โดยเก็บความกว้างและโหมดยืดเดิมไว้ทุกจุด แล้วสแกนทั้งไฟล์ 52 หน้ายืนยันว่าไม่เหลือใครใช้ของเดิม จึงลบทิ้ง
- ทำเอกสารในไฟล์ออกแบบครบ 7 ใบ ตามโครง 5 ชนิด และประกอบตารางทั้งหมดจากชุด cell ของระบบ ไม่ได้วาดเอง
- เขียนเอกสารประจำหน้าในเครื่องที่ docs/23-progress-bars.md และแปลงเป็นโค้ดที่ components/Progress
- ตัดสินเรื่องเงาตามกฎว่าชิ้นงานใหม่ต้องกำหนดเงาเสมอ ผลคือไม่มีเงาโดยตั้งใจ เพราะเป็นของแบนที่ฝังในเนื้อหา เหมือนแท็กและป้าย ไม่ใช่ของลอย
- แก้ความหนาแถบให้ใช้สูตรเดียวกับรางของ slider ในหน้า 17 หลังหัวหน้าทักว่าสองหน้าไม่เท่ากัน แล้วเพิ่มด่านตรวจที่อ่านค่าจากอีกฝั่งมาเทียบตรง ๆ กันหลุดซ้ำ
- แยกช่องไฟของแถบตามทิศ ตามที่หัวหน้าแก้ไว้ในไฟล์ออกแบบ คือตอนป้ายอยู่ขวากับตอนป้ายอยู่ล่าง แล้ว sync เข้าฝั่งโค้ดครบทุกชั้น

#### **ผลตรวจ**

- ชิ้นงานลดจาก 91 แบบ เหลือ 20 แบบ คิดเป็นลดลง 78 เปอร์เซ็นต์
- สัดส่วนความหนาวงแหวนนิ่งขึ้นจากไหล 4.5 จุด เหลือไหล 1.5 จุด อยู่ในย่านที่ตลาด 4 เจ้าใช้
- คอนทราสต์ของคู่ที่สำคัญคือตัวเติมเทียบราง ดีขึ้นจาก 3.82 และ 4.76 เป็น 5.11 เท่ากันทั้งสามทรง เพราะรางทั้งสามทรงใช้สีเดียวกันแล้ว
- ความหนาแถบตรงกับรางของ slider ครบทั้งห้าขนาด และขนาด md เท่ากับ 8 ซึ่งตรงกับค่ากลางของตลาด
- ที่ใช้งานจริงบนหน้า 36 ทั้ง 20 จุด สลับครบ ขนาดชุดแม่ทั้ง 4 ชุดไม่ขยับเลย
- สแกนปิดงานทั้งหน้า 1,208 ชิ้น ได้ สีดิบ 0 เส้นดิบ 0 ขีดยาว 0 ข้อความแม่แบบตกค้าง 0 หัวเอกสารค่าเริ่มต้น 0
- ด่านตรวจว่าไฟล์ออกแบบกับโค้ดตรงกัน ขึ้นว่าต้องดู 0 กลุ่ม และตัวตรวจชนิดข้อมูล 0 ข้อผิดพลาด
- ฝั่งโค้ดอ้างตัวแปร 81 ตัว ตรวจทีละตัวแล้วมีจริงครบ 81 ตัว

#### **ที่ไม่ได้ทำตามที่เขียนไว้**

- แถวในเทมเพลตหน้า 36 สูงขึ้น 4 จาก 18 เป็น 22 เพราะระบบไม่มีชุดตัวอักษรสำเร็จรูปที่ความสูงบรรทัด 18 จึงทำให้เท่าเดิมไม่ได้ไม่ว่าจะเลือกขนาดไหน แจ้งหัวหน้าก่อนลงมือแล้วและเลือกขนาดที่ขยับน้อยที่สุด
- ยังไม่ได้ผูก Code Connect ระหว่างชุดในไฟล์ออกแบบกับ component ฝั่งโค้ด ยกไปทำพร้อมกันทีเดียวกับหน้า 19 และ 20
- ระบบยังไม่มีตัวหมุน ซึ่งเป็นตัวที่เอกสารหน้านี้ชี้ให้ไปใช้แทนในช่วงรอ 1 ถึง 3 วินาที ต้องเปิดการ์ดแยก
