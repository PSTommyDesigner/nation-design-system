#### **งานค้าง**
- **เอกสาร Grid ยังต้องเติม "ภาพ grid" (ทำต่อวันจันทร์)** ตอนนี้มีแต่ข้อความ+ตาราง เลยดูโบ๋/ไม่เสร็จ · ต้องเพิ่มภาพส่วนประกอบ grid (column/gutter/margin/container) + ภาพ grid ในแต่ละจอ (Full HD→Desktop→Tablet→Mobile) โดย clone ของที่มีในหน้า + ปิดช่องว่างที่โหว่
- Sync ค่า grid เข้าโค้ด (token) ทำต่อได้ถ้าต้องการ
- (คิวเดิม) Employee profile app · ไอคอน LINE รอไฟล์โลโก้ทางการ · หนี้เทคนิคฝั่งโค้ด

#### **งานที่ทำวันนี้**
- **ตรวจหน้า Grid** พบว่ามีระบบ grid 2 ชุด (เว็บทั่วไป 2022 · Nation Digital) แต่ยังไม่มีตัวแปร · ไม่มีเอกสารประจำหน้า · และค่าที่เขียนในเฟรมไม่ตรงกับ grid จริง 5 จุด
- **แก้เฉพาะ "ข้อความ" ให้ตรงค่า grid จริง** (ไม่แตะ grid เลย → ดีไซน์/งานเดิมไม่กระทบ)
- **สร้างตัวแปร grid ครบ 2 ระบบ** (50 ตัว: ความกว้างจอ · จำนวนคอลัมน์ · ระยะห่าง · ขอบ · พื้นที่เนื้อหา ต่อจอ)
- **ร่างเอกสารประจำหน้า Grid ภาษาเข้าใจง่าย เน้นเจตนา** (grid คืออะไร · แต่ละจอกี่คอลัมน์ · เมื่อไหร่ใช้ระบบไหน · วิธีใช้) พร้อมตารางค่าใช้ช่องสำเร็จรูป + การ์ดควรทำ/ไม่ควรทำ **เป็นฉบับร่าง ยังต้องเติมภาพให้ครบ**

#### **ผลลัพธ์**
- หน้า Grid มีตัวแปรครบ + มีโครงเอกสาร (เนื้อหา/ตาราง/ค่า) พร้อมแล้ว
- ค่าในเอกสารตรงกับ grid จริง (แก้จุดพิมพ์ผิดโดยไม่กระทบของเดิม)
- ยังขาด "ภาพ grid" ทำให้ดูไม่เสร็จ → ยกไปทำต่อวันจันทร์

#### **ติดปัญหา**
- เอกสารเน้นข้อความ+ตารางล้วน ไม่มีภาพ grid เลย เลยดูโบ๋ → แผนแก้ = clone ภาพ grid ที่มีในหน้ามาใส่ (วันจันทร์)

- **เอกสาร Token ของหน้า Grid** ยังไม่ได้ทำ · ต้องตัดสินก่อนว่าจะดึงค่า grid เข้าโค้ดไหม
- (คิวเดิม) Employee profile app · ไอคอน LINE รอไฟล์โลโก้ทางการ · หนี้เทคนิคฝั่งโค้ด

#### **งานที่ทำวันนี้**
- **เติมภาพ grid ให้เอกสารหน้า Grid ครบทุกขนาดจอทั้ง 2 ระบบ** พร้อมภาพอธิบายส่วนประกอบ (ขอบ ช่องไฟ คอลัมน์ พื้นที่เนื้อหา) ใช้ของสำเร็จรูปที่มีอยู่ ไม่วาดใหม่ ค่าทุกตัวอ่านจากตัวแปรจริง 50 ตัว
- **แยกเอกสารหน้า Grid เป็น 4 ชิ้นตามมาตรฐาน** หลังหัวหน้าทักว่าเอาทุกอย่างไปกองรวมในหน้าสรุป: หน้าสรุป · ภาพระบบเว็บทั่วไป · ภาพระบบ Nation Digital · ที่เก็บชิ้นส่วนต้นฉบับ
- **เก็บกวาดชิ้นส่วนต้นฉบับ 18 ชิ้น** ที่ลอยกระจายอยู่ในหน้า รวบเข้าที่เดียว แยกกลุ่มของที่หยิบไปใช้กับของภายใน
- **ปรับทุกหัวข้อในเอกสารให้ตรงแบบใหม่** ที่หัวหน้าจัดไว้ (หัวข้อ คำอธิบาย ระยะห่าง ขนาดตัวอักษร ชุดเดียวกันหมด) ทำครบทั้ง 8 หัวข้อของหน้าสรุป
- **ตรวจเอกสารหน้าอื่นเทียบแบบใหม่** พบว่ายังไม่ตรงเลยแม้แต่หัวข้อเดียว รวมอย่างน้อย 54 จุด ทำเป็นรายการงานไว้
- **วางระบบกันพลาดซ้ำ** เพิ่มขั้นตอนบังคับก่อนแตะเอกสารหน้าไหนก็ตาม (อ่านมาตรฐาน · ดูหน้าตัวอย่าง · บอกก่อนว่าจะทำเอกสารชนิดไหน) พร้อมตารางบอกว่าเนื้อหาแบบไหนควรอยู่เอกสารชนิดใด

#### **ผลลัพธ์**
- หน้า Grid มีเอกสารครบทุกชนิดตามมาตรฐาน หน้าสรุปเหลือเฉพาะภาพรวม ส่วนรายละเอียดแยกออกเป็นเอกสารลูก
- หน้าเป็นระเบียบขึ้นมาก จากของกระจัดกระจายเหลือ 4 ชิ้นชัดเจน
- กติกาที่เคยพลาดถูกเขียนลงคู่มือหลักที่ระบบอ่านทุกครั้ง ไม่ใช่แค่บันทึกช่วยจำ

#### **ติดปัญหา**
- **ทำเอกสารผิดที่** เอาภาพและรายละเอียดทั้งหมดยัดลงหน้าสรุป เพราะไม่ได้เปิดมาตรฐานที่มีอยู่แล้วอ่านก่อนลงมือ หัวหน้าต้องตามแก้ → แก้ที่ระบบด้วยขั้นตอนบังคับก่อนเริ่มงานทุกหน้า
- แบบสำเร็จรูปที่ใช้มีกรอบสูงคงที่และตัดเนื้อหาส่วนเกินทิ้ง ทำให้ภาพที่ย้ายเข้าไปหายไปตอนแรก ตรวจเจอจากภาพหน้าจอแล้วแก้ครบ

#### **งานที่ทำวันนี้**
- **จัดโครงเอกสารทั้งระบบให้ตรงแบบใหม่ที่หัวหน้าวางไว้** ไล่แก้ครบ **154 หัวข้อ 36 เอกสาร 6 หน้า** (สี · ไอคอน · ตัวอักษร · กริด · ปุ่ม · ตาราง) ทุกหัวข้อใช้ขนาดตัวอักษรและระยะห่างชุดเดียวกันหมด และแยกเอกสารรายการค่าที่เคยยัดรวมเป็นหัวข้อเดียว ออกเป็น 4 หัวข้อตามแบบ
- **เอากรอบพื้นเทาออก** หลังหัวหน้าชี้ว่าเป็นเพียงตัวอย่างในแบบสำเร็จรูป ไม่ใช่สไตล์ที่ต้องใช้จริง
- **ทำหน้า Grid ให้ครบวงจร** เพิ่มเอกสารรายการค่า (50 ค่า) · ดึงค่ากริดเข้าโค้ดให้นักพัฒนาเรียกใช้ได้จริง · เขียนคู่มือประจำหน้าเป็นไฟล์เอกสาร
- **อัปเดตไอคอนทั้งชุด 146 ตัว** ให้ตรงกับที่หัวหน้าทำใหม่ (รวมชุด social) ทั้งไฟล์ภาพ โค้ด และหน้าตัวอย่าง พร้อมแก้ให้เปลี่ยนสีตามระบบได้
- **ตามค่าสีปุ่มที่หัวหน้าแก้** ตรวจเทียบทีละตัว 217 ค่า เจอที่แก้ 1 จุด อัปเดตให้โค้ดตรงกัน และเพิ่มค่ามุมโค้งของปุ่มทรงใหม่ 2 แบบ (ปุ่มแคปซูล ปุ่มวงกลม)
- **แก้ค่าสีที่อ้างข้ามชั้นผิดหลัก 206 จุด** ให้ชี้ไปชั้นความหมายกลางโดยตรง ตรวจแล้วสีไม่เปลี่ยนแม้แต่ตัวเดียว

#### **ผลลัพธ์**
- เอกสารทุกหน้าหน้าตาเป็นระบบเดียวกัน ไม่มีหัวข้อขนาดแปลกปนอีก

- ไอคอนและค่าสีปุ่มในโค้ดตรงกับไฟล์ออกแบบ 100 เปอร์เซ็นต์
- โครงค่าสีสะอาดตามกติกาใหม่ ไม่มีค่าไหนอ้างค่าในกลุ่มเดียวกันอีก

- **เสนอเกินคำสั่ง** ไปเสนอให้ลบค่าชั้นกลางทิ้ง ทั้งที่ตรวจดูแล้วไม่ได้ผิดกติกาและมีของใช้งานอยู่กว่า 50,000 จุด สุดท้ายแก้เฉพาะจุดที่ผิดจริง บทเรียนคือสำรวจให้ครบก่อนเสนอทางที่กระทบใหญ่
- กุญแจเข้าระบบไฟล์ออกแบบหมดอายุกลางทาง หัวหน้าออกให้ใหม่ งานจึงเดินต่อได้
