# [DS]-[Radio] Design ระบบสเกลและเอกสาร หน้า 16 Radio

## รายละเอียดงาน

#### **Problem**

- หน้า 16 Radio มีชิ้นงานอยู่แล้ว 2 ชุด 32 แบบ แต่ไม่มีเอกสารสักชนิด มีแค่หัวเอกสาร คนที่หยิบไปใช้จึงไม่รู้ว่าใช้เมื่อไหร่และต่างจากช่องติ๊กยังไง
- ไม่มีตัวแปรสักตัว ทุกค่าจึงเป็นตัวเลขตายที่ไม่มีใครดูแล และเปลี่ยนทั้งระบบพร้อมกันไม่ได้
- ชื่อชุดยังเป็นตัวใหญ่และมีเว้นวรรค ไม่ลงท้ายด้วยชนิดตามกติกา ทำให้ในแผงชิ้นงานเดาไม่ออกว่าเป็นอะไร

#### **Goal**

- ให้ปุ่มตัวเลือกมีระบบสเกลของตัวเองที่คุมด้วยสูตร ตรวจสอบได้ตอนสร้างไฟล์ เหมือนที่ทำกับช่องติ๊กไปแล้ว
- ให้หน้านี้มีเอกสารครบชนิดตามมาตรฐาน และชื่อทุกชุดตรงกติกา

#### **Requirements**

- เปลี่ยนชื่อสองชุดให้ตรงกติกา ลงท้ายด้วยชนิดและไม่มีขีดล่างนำหน้าเพื่อให้ไฟล์อื่นหยิบไปใช้ได้
- สร้างไฟล์สูตรสเกลของปุ่มตัวเลือก โดยยึดโครงสองชั้นแบบเดียวกับช่องติ๊ก คือชั้นที่มองเห็นกับชั้นแถวสัมผัส
- อ่านค่าจริงจากไฟล์ออกแบบก่อนตั้งสูตร ห้ามเดาจากค่าที่เก็บไว้เดิม
- สร้างตัวแปรในไฟล์ออกแบบแล้วผูกให้ครบทุกแบบ
- ทำเอกสารครบ 4 ชนิด คือเอกสารประจำหน้า เอกสารหลักการ เอกสารตัวแปร และที่เก็บชุดจริง
- เขียนไฟล์เอกสารในเครื่องของหน้านี้
- กำหนดเงาให้ชิ้นงานตามกฎ และสแกนปิดงานให้สีดิบเป็น 0 กับมุมโค้งไม่ผูกเป็น 0
