# [DS]-[Divider] Revamp ชิ้นงานและเอกสาร หน้า 28 Dividers

## รายละเอียดงาน

**Problem ปัญหาคืออะไร ? :**
- หน้า 28 มีเส้นคั่น 2 ชุด 4 แบบ ถูกใช้ 72 จุดทั่วไฟล์ แต่ไม่มีเอกสารสักใบ เป็นหน้าสุดท้ายของชั้นโมเลกุลที่ยังไม่มีเอกสาร
- ความหนาเส้นเป็นค่าตายตัวที่ไม่ได้ผูกตัวแปร หน้านี้ไม่มี token ของตัวเองเลย
- ชื่อชุดยังไม่ตรงกติกา ไม่ได้ลงท้ายด้วยชนิดของตัวเอง
- เสี่ยงเข้าใจผิดว่าเส้นคั่นหน้านี้คือตัวเดียวกับ tab/divider ของหน้า 18 เพราะหนา 1 เท่ากัน ทั้งที่คนละหน้าที่
- ไม่มีที่ไหนเขียนไว้ว่าเส้นประใช้ระยะเท่าไหร่ ทำให้แต่ละคนวาดไม่เหมือนกัน

**Goal ทำเพื่ออะไร ? :**
- ยกเครื่องหน้า 28 ให้ได้มาตรฐานเดียวกับหน้า 23 24 25 และ 27 คือ ชื่อตรงกติกา ความหนาผูกตัวแปร สีดิบ 0 และมีเอกสารครบชนิด
- ปิดชั้นโมเลกุลให้มีเอกสารครบทุกหน้า ตั้งแต่ 10 ถึง 28

**Requirements ขอบเขตงาน**
1. ตั้งชื่อชุดใหม่ตามกติกา ตัวเล็ก ใช้ขีดกลาง ลงท้ายด้วยชนิด และไม่มีขีดทับ
2. สร้างตัวแปรความหนาเป็นของหน้านี้เอง ห้ามไปใช้ tab/divider ร่วมกัน เพราะคนละหน้าที่
3. เขียนสูตรลง tokens/scale/divider.mjs ลงทะเบียนใน index แล้ว build และ verify ให้ขึ้น ต้องดู 0 กลุ่ม
4. ผูกความหนากับตัวแปรให้ครบทั้ง 4 แบบ ทั้งแนวนอนแนวตั้ง ทั้งเส้นทึบเส้นประ
5. ล้างสีดิบของหน้าให้เหลือ 0
6. ทำเอกสารครบชนิด Page Doc 1 Token 1 Information อย่างน้อย 1 Component Previews และ Space 1
7. Page Doc ต้องมีตัวอย่างจริง ห้ามเป็นตัวหนังสือล้วน
8. เขียนเอกสารประจำหน้าในเครื่องที่ docs/28-dividers.md พร้อมบันทึกเหตุผลที่แยก token จาก tab/divider
9. ไม่ทำฝั่งโค้ด components/Divider ในการ์ดใบนี้ แยกเป็นการ์ดต่างหากหลังหลังไฟล์ออกแบบนิ่ง

**Figma File :** [หน้า 28 Dividers](https://www.figma.com/design/QgmoT5Uuvv3elB96F4nsTq/?node-id=7130-30)
**Reference ตัวอย่างงานที่ชอบ :** หน้า 27 Card ที่เพิ่งทำเสร็จ ใช้โครงเอกสารและระบบสูตรขนาดแบบเดียวกัน และ tokens/scale/tabs.mjs ที่เขียนเหตุผลกำกับไว้ว่าทำไมถึงแยก tab/divider ออกจาก tab/rail ทั้งที่ค่าเท่ากัน

#### **ผลตรวจ**

- สแกนปิดงานทั้งหน้า 67 ชิ้น ได้ สีดิบ 0 ผูกผิด collection 0 ขีดยาว 0 ตัวอักษรที่ไม่ใช้ preset 0 และกรอบพื้นเทา 0

#### **ที่ไม่ได้ทำตามที่เขียนไว้**

- รอบแรกเสนอให้เส้นคั่นหน้านี้ใช้ token ร่วมกับ `tab/divider` ของหน้า 18 เพราะหนา 1 เท่ากัน หัวหน้าทักว่าผิด เพราะ `tab/divider` คือขอบที่อยู่ข้างในชิ้นงานแท็บ ส่วนหน้านี้คือเส้นที่วางเองระหว่าง section ตรวจไฟล์สูตรแท็บแล้วพบว่าระบบเขียนเหตุผลกำกับไว้เองอยู่แล้วว่าแยก `tab/divider` ออกจาก `tab/rail` เพราะคนละหน้าที่ ถึงค่าจะเท่ากัน จึงทำตัวแปรของหน้านี้แยกออกมา และไล่แก้เอกสาร 4 ใบที่เขียนตามความเข้าใจผิดเดิม
- ตอนวางขอบเขตงานคิดว่าหน้านี้ไม่มี token จึงวางไว้แค่ 4 เอกสาร พอตัดสินให้สร้างตัวแปรความหนา จึงต้องเพิ่ม Token Document ตามมาตรฐาน รวมเป็น 5 ใบ
- การ์ดใบนี้เปิดย้อนหลังหลังทำงานเสร็จแล้ว เพราะตอนเริ่มทำยังไม่ได้เปิดการ์ดไว้
