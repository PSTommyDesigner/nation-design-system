# [DS]-[Document] Fix Page Documentation 8 หน้าให้ได้มาตรฐาน

## รายละเอียดงาน

**Problem ปัญหาคืออะไร ? :**
- Page Documentation ของ 8 หน้าเขียนเป็นตัวหนังสือล้วน สแกนแล้วพบว่า instance เท่ากับ 0 ทุก section ทุกหน้า ทั้งที่มาตรฐานเขียนไว้ว่าต้องใช้ instance ของ component จริง
- โครง section ไม่ตรงมาตรฐานสักหน้า มาตรฐานกำหนด 12 section โดย 8 ข้อแรกเป็นข้อบังคับ แต่ของจริงมีตั้งแต่ 5 ถึง 9 section และหลายหน้าตั้งชื่อ section เอง เช่น parts, groups, usage-status, structure, scale
- ไม่มีหน้าไหนมีตัวอย่าง Do และ Don't ซึ่งเช็คลิสต์ในมาตรฐานบังคับไว้อย่างน้อย 1 คู่
- เจอตอน user ตรวจงานหน้า 14 Toggles เมื่อ 4 กันยายน 2569 แล้วชี้ว่าเขียนแบบมักง่ายทั้งที่หน้า 12 Buttons ทำไว้ดีแล้วเป็นตัวอย่าง
**Goal ทำเพื่ออะไร ? :**
- ทุกหน้ามี Page Documentation ที่ครบ 12 section ตามมาตรฐาน และมีของจริงให้ดู ไม่ใช่อ่านคำบรรยายอย่างเดียว
- คนที่เปิดหน้าไหนก็เจอโครงเดียวกัน ไม่ต้องเดาว่าหน้านี้เขียนแบบไหน
**Requirements ขอบเขตงาน**
1. แก้ 8 หน้า คือ 05 Effect, 06 Shape, 07 Space, 08 Logo, 09 Third-party Logos, 10 Frame, 11 Avatar, 13 Input
2. ทุกหน้าต้องมีครบ 12 section ตามมาตรฐาน section ที่ไม่เกี่ยวกับหน้านั้นให้คงไว้แล้วเขียนอธิบายว่าทำไมไม่มี ไม่ใช่ลบทิ้ง (user ตัดสิน 4 กันยายน 2569)
3. ทุก section ที่ควรมีของให้ดู ต้องมี instance ของจริงหรือตัวอย่างจริง ห้ามเป็นตัวหนังสือล้วน
4. ทุกหน้าต้องมี Do และ Don't อย่างน้อย 1 คู่ เป็นภาพจริง
5. ใช้หน้า 12 Buttons และหน้า 14 Toggles เป็นแบบอ้างอิง
6. ทุกหน้าต้องผ่านการสแกน สีดิบ 0 เส้นดิบ 0 em-dash 0 จุดกลางนอกบรรทัดรายการ 0 และ text ต้องผูก text style ครบ
7. อัปเดตตาราง Coverage ในไฟล์มาตรฐานหลังแก้เสร็จแต่ละหน้า
8. ไม่ทำในรอบนี้ หน้าที่ยังไม่มีเอกสารเลย 22 หน้า เป็นคนละงานกัน
