# [DS]-[Cleanup] Fix ของค้างจากหน้าที่ทำมาแล้ว

## รายละเอียดงาน

**Problem ปัญหาคืออะไร ? :**

- หน้าที่ทำไปแล้วยังมีของค้าง ทั้งเอกสารที่เขียนสถานะเก่า คำอธิบายตัวแปรที่อ้างเลขหน้าผิด สีดิบที่ยังไม่ผูก และชื่อ component ที่ยังผิดกฎ
- ถ้าปล่อยไว้แล้วไปทำหน้าใหม่ ของค้างจะพอกขึ้นเรื่อย ๆ และเอกสารจะชี้ไปหาของที่ไม่มีอยู่จริง

**Goal ทำเพื่ออะไร ? :**

- หน้าที่ทำไปแล้วสะอาดครบทุกข้อตามเกณฑ์ก่อนบอกเสร็จ แล้วค่อยไปหน้าใหม่

**Requirements ขอบเขตงาน**

1. แก้เอกสารในไฟล์ออกแบบที่เขียนสถานะเก่าไว้
2. แก้คำอธิบายตัวแปรที่อ้างเลขหน้าผิด
3. ผูกสีที่ยังดิบของหน้าที่ทำไปแล้ว
4. เปลี่ยนชื่อ component ที่ยังมีขีดทับให้ลงท้ายด้วยชนิดตามกฎ พร้อมไล่แก้ที่อ้างชื่อเก่าทุกที่

#### **worklog 1**

- แก้เอกสารระยะห่างของหน้าตารางที่ยังเขียนว่าเซลยังไม่ผูกตัวแปร ทั้งหัวข้อสรุปและหัวข้อกติกา ให้ตรงกับสถานะจริง
- แก้คำอธิบายตัวแปรมุมโค้งของตารางที่อ้างเลขหน้าเก่า
- ผูกสีขอบของกล่องรวมชุดและข้อความหัวข้อที่ค้างเป็นสีดำ ซึ่งเป็นของเดิมที่ไม่เคยผูก
- เปลี่ยนชื่อ component ของหน้าตารางที่ยังมีขีดทับ ให้ลงท้ายด้วยชนิดตามกฎ แบบเดียวกับปุ่มและแท็ก
- ไล่แก้ที่อ้างชื่อเก่าให้ครบ ทั้งข้อความในเอกสาร กติกาหลักของโปรเจกต์ มาตรฐานเอกสาร รายชื่อหน้า เอกสารหน้าสี และบันทึกความจำ
