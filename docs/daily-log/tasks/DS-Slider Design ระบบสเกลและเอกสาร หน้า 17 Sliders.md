# [DS]-[Slider] Design ระบบสเกลและเอกสาร หน้า 17 Sliders

## รายละเอียดงาน

**Problem ปัญหาคืออะไร ? :** หน้า 17 Sliders ยังไม่เคยถูกทำตามมาตรฐาน มีชิ้นงาน 2 ชุด 52 แบบแต่ไม่มีเอกสารสักชนิด ไม่มีตัวแปรสักตัว มุมโค้งไม่ผูก 86 จุด ชื่อชุดและชื่อแกนผิดกติกาทั้งหมด มีขนาดเดียว ไม่มีสถานะ disabled มีแต่แบบสองปุ่มจับ ปุ่มจับ 24 เล็กกว่าพื้นที่แตะมาตรฐาน และตำแหน่งปุ่มจับทำเป็น variant 40 แบบ
**Goal ทำเพื่ออะไร ? :** ให้แถบเลื่อนมีโครงที่ตัดสินจากงานวิจัย มีระบบสเกลของตัวเองที่คุมด้วยสูตรเหมือนช่องติ๊กและปุ่มตัวเลือก ชื่อทุกชุดตรงกติกา และมีเอกสารครบชนิดตามมาตรฐาน
**Requirements ขอบเขตงาน**
1. วิจัยแถบเลื่อนของ DS เจ้าใหญ่ก่อน เรื่องแบบค่าเดียวกับแบบช่วง ขนาด พื้นที่แตะ การแสดงค่า สถานะ คีย์บอร์ด และวิธีทำใน Figma
2. ตัดสินโครงจากผลวิจัย ได้แก่ ขนาด แบบค่าเดียว สถานะ disabled โครงสองชั้น และวิธีทำตำแหน่งปุ่มจับ
3. สร้างไฟล์สูตรสเกล อ่านค่าจริงจากไฟล์ออกแบบก่อนตั้งสูตร แล้วสร้างตัวแปรและผูกให้ครบ
4. เปลี่ยนชื่อชุด แกน และค่าของแกนให้ตรงกติกา
5. กำหนดเงาและวงแหวนโฟกัสให้ผูกกับ effect style
6. ทำเอกสารครบ 5 ชนิดและไฟล์เอกสารในเครื่อง
7. สแกนปิดงานให้สีดิบ มุมโค้งไม่ผูก ระยะห่างไม่ผูก และขีดยาว เป็น 0

**Reference ตัวอย่างงานที่ชอบ :** หน้า 15 Checkbox และหน้า 16 Radio ทั้งโครงสองชั้น ไฟล์สูตร และการจัดเอกสาร งานวิจัยจะอยู่ที่ docs/research/slider-component.md

## บันทึกงาน

### 2026-09-24 Tommyy_PS

#### **worklog 1**

- วิจัยแถบเลื่อนของ DS เจ้าใหญ่ก่อนลงมือ ครอบคลุมแบบค่าเดียวกับแบบช่วง ขนาด พื้นที่แตะ การแสดงค่า สถานะ แป้นพิมพ์ และวิธีทำในไฟล์ออกแบบ
- ตัดสินโครงจากผลวิจัย 9 ข้อ ที่สำคัญคือทำเป็น 5 ขนาดให้เท่าสวิตช์ ช่องติ๊ก และปุ่ม ใช้โครงสองชั้นแยกชั้นภาพกับชั้นแถวที่กดได้ เพิ่มแบบค่าเดียวและสถานะปิดใช้งาน และเลิกทำตำแหน่งปุ่มจับเป็นตัวเลือก
- สร้างไฟล์สูตรขนาด อ่านค่าจริงจากไฟล์ออกแบบก่อนตั้งสูตร ขนาดกลางคงค่าเดิมทุกค่าจึงไม่กระทบของที่ใช้อยู่
- สร้างตัวแปรในไฟล์ออกแบบและผูกให้ครบทุกจุดของชุด
- เปลี่ยนชื่อชุด ชื่อแกน และค่าของแกนให้ตรงกติกา ทุกชื่อลงท้ายด้วยชนิดของมันและไม่มีขีดทับ
- ปุ่มจับแยกเป็นชุดของตัวเองเพราะสองชุดแรกใช้ร่วมกัน จึงเป็น component เต็มตัว ไม่ใช่ชิ้นส่วนฐาน และไม่มีขีดล่างนำหน้าเพื่อให้ไฟล์อื่นหยิบไปใช้ได้
- กำหนดวงแหวนโฟกัสให้ผูกกับ effect style ครบทุกขนาด
- ทำเอกสารบนหน้าครบทุกชนิด 8 ใบ และไฟล์เอกสารประจำหน้าในเครื่อง
- ทำโค้ดฝั่ง React ตัวเดียวที่ทำได้ทั้งสองแบบโดยดูจากรูปของค่า พร้อมแป้นพิมพ์ตามมาตรฐาน WAI-ARIA
- แก้ที่หลุดหลังส่งมอบ 4 เรื่อง คือ ความหนารางไม่ตรงกับแถบเติม ปุ่มจับแบบช่วงโดนแถบเติมทับ ชุดปุ่มจับเรียงไม่เป็นระเบียบ และตัวอย่างการใช้งานไปวางผิดชนิดเอกสาร

#### **ผลตรวจ**

- ชิ้นงาน 45 แบบ แบ่งเป็นแบบค่าเดียว 10 แบบช่วง 10 และปุ่มจับ 25 ลดจากของเดิม 52 แบบที่มีขนาดเดียว
- ตัวแปรในไฟล์ออกแบบ 36 ตัว และค่าฝั่งโค้ด 36 ตัว ชื่อตรงกันทุกตัว
- วัดพิกัดจริงทั้ง 20 แบบ ปุ่มจับอยู่กึ่งกลางแนวตั้งเยื้อง 0 และตรงรอยต่อแนวนอนพอดีทุกตัว
- สีดิบ 0 เส้นดิบ 0 เงาดิบ 0 ขีดยาว 0 ข้อความที่ไม่ผูกแบบอักษรมาตรฐาน 0
- มุมโค้งและระยะห่างที่ไม่ผูกตัวแปร ภายในชุดแถบเลื่อนเอง 0 จุด
- เอกสารบนหน้า 8 ใบ ครบทุกชนิด เรียงและเว้นระยะ 200 เท่ากันทุกช่วง
- ขนาดชิ้นงานทั้ง 45 แบบ เทียบก่อนและหลังทุกครั้งที่แก้ ไม่เปลี่ยนสักตัว
- ตัวตรวจชนิดข้อมูลฝั่งโค้ดรันผ่าน 0 ข้อผิดพลาด

#### **ที่ไม่ได้ทำตามที่เขียนไว้**

- มุมโค้งและระยะห่างที่ยังไม่ผูก นอกชุดแถบเลื่อน เหลือ 3 กลุ่ม คือ กรอบกล่องรวมชุดที่ Figma ใส่ค่าให้เอง 28 จุด เฟรมจัดหน้าเอกสาร 43 จุด และชิ้นงานกลางที่ต้นฉบับอยู่หน้าอื่น 138 จุด
- ทั้งสามกลุ่มเป็นแบบเดียวกับหน้า 15 Checkbox และหน้า 16 Radio ที่การ์ดนี้อ้างเป็นตัวอย่าง ซึ่งปล่อยไว้เหมือนกัน จึงไม่แก้เฉพาะหน้านี้ให้ต่างจากที่อื่น
- กลุ่มใหญ่สุดคือมุมโค้งของป้ายค่า 120 จุด ต้นฉบับอยู่หน้าอื่น ต้องแก้ที่ต้นฉบับตอนหยิบหน้านั้นมาทำ จึงจะไม่หลุดกันอีก
