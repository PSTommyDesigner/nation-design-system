# [DS]-[Dropdown] Revamp ชิ้นงานและเอกสาร หน้า 25 Dropdowns

## รายละเอียดงาน

#### Problem

- หน้า 25 มีชิ้นงานแค่ 2 ชุด 9 แบบ ซึ่งน้อยที่สุดในชั้นโมเลกุล และไม่มีเอกสารสักใบ
- ชุด Default style ตั้งชื่อไม่ตรงกติกาทุกจุด มีตัวใหญ่ มีเว้นวรรค มีเครื่องหมายคำถาม และสะกดผิดเป็น Lebel แทน Label
- แกน State มีแค่ 3 ค่า คือ Default Hover และ Open ขาดสถานะโฟกัส ปิดใช้งาน และผิดพลาด ซึ่งช่องกรอกในหน้า 13 มีครบ
- ไม่มีแกนขนาดเลย ต่างจากหน้า 13 Input ที่มี 3 ขั้น และต่างจากหน้าอื่นในชั้นโมเลกุลที่ทำ 5 ขั้นไปแล้ว
- ตัวอักษร 36 จุดใช้ชุดจากไลบรารีภายนอก ไม่ใช่ preset ของไฟล์นี้ อาการเดียวกับหน้า 24 ที่เพิ่งแก้
- มุมโค้งไม่ผูกตัวแปร 31 จุด
- มีหัวเอกสารลอย 2 อัน
- ยังไม่มีไฟล์สูตรขนาดที่ tokens/scale และยังไม่มี component ฝั่งโค้ด

#### Goal

- ยกเครื่องให้ได้มาตรฐานเดียวกับหน้า 19 20 23 และ 24
- มีแกนขนาด 5 ขั้น และสถานะครบเท่าช่องกรอก
- ย้ายตัวอักษรมาใช้ preset ของระบบให้ครบ และผูกมุมโค้งทุกจุด

#### Requirements

- ส่งงานวิจัยก่อน โดยแบ่งเป็นหลายใบขนานกัน ใบละไม่กี่เจ้า เพราะสั่งทีเดียว 15 เจ้าเคยล่มสองรอบ
- ตรวจก่อนตั้งสูตรว่าในระบบมีของชนิดเดียวกันอยู่แล้วไหม โดยเฉพาะความสูงและมุมโค้งที่ควรยืมจากช่องกรอกหรือจากของกลาง
- ทำไฟล์สูตรขนาดพร้อมด่านตรวจไปพร้อมกับตัวชิ้นงาน
- ตั้งชื่อใหม่ทั้งหมดตามกติกา และแก้คำสะกดผิด
- ตัดสินว่า _Scroll bar ควรอยู่หน้านี้หรือยกไปที่อื่น
- ทำเอกสารครบ 5 ชนิด และ Page Doc ต้องมีบล็อกตัวอย่างจริงอย่างน้อย 5 หัวข้อ ตามข้อ 8.5 ของ checklist
- เขียนเอกสารประจำหน้าในเครื่อง และแปลงเป็นโค้ด

- หน้า 13 Input คือของที่ใกล้เคียงที่สุด ต้องเทียบความสูงและสถานะให้ตรงกัน
