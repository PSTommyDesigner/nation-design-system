# [DS]-[Icon] Fix ไอคอนนอกเซ็ตและการอ้างคุณสมบัติที่หลุด

## รายละเอียดงาน

**Problem ปัญหาคืออะไร ? :**

- หน้า 15 Checkbox ใช้ไอคอนจากไลบรารีนอกไฟล์ 80 จุด ถ้าไลบรารีนั้นถูกถอดไอคอนจะหายทั้งหน้า
- หน้า 28 Table ใช้ไอคอนปนกัน 3 แหล่ง ทั้งเซ็ตของเรา ชุด Material เก่าในไฟล์ และไลบรารีนอกไฟล์
- ปุ่มลิงก์ไอคอนตระกูล Error ไม่มีคุณสมบัติสลับไอคอน ต่างจากอีกสองตระกูลที่มี
- ชุดบนหน้า 12 Buttons มีคุณสมบัติที่ประกาศไว้แต่ไม่ได้ผูกกับเลเยอร์ ทำให้เปลี่ยนข้อความหรือไอคอนแล้วพอเข้าสถานะโฟกัสจะเด้งกลับ

**Goal ทำเพื่ออะไร ? :**

- ไอคอนทุกจุดในหน้าที่ทำมาแล้วมาจากเซ็ต Nation UI Icons ไม่พึ่งไลบรารีนอกไฟล์
- คุณสมบัติของปุ่มทุกชุดทำงานจริงทุกสถานะ ไม่ใช่แค่มีให้เห็นในแผง

**Requirements ขอบเขตงาน**

1. ตรวจว่าหน้าที่ทำมาแล้วใช้ไอคอนจากเซ็ตไหน และใช้คุณสมบัติสลับ instance หรือไม่
2. เปลี่ยนไอคอนที่ไม่ได้มาจากเซ็ต Nation UI Icons ให้ครบ
3. เปลี่ยนปุ่มลิงก์รุ่นเก่าที่มาจากนอกไฟล์ ให้เป็นปุ่มลิงก์ไอคอนปัจจุบัน
4. เพิ่มคุณสมบัติสลับไอคอนให้ตระกูลที่ขาด และผูกคุณสมบัติที่หลุดให้ครบทุกชุด
5. ไม่ทำในการ์ดนี้ คือดาวให้คะแนนในตาราง เพราะเป็นชุดที่มีแกนเปอร์เซ็นต์ 11 ขั้น ซึ่งเซ็ตเราไม่มีของแทน ตัดสินแล้วว่ายกเว้น

### 2026-09-14 Tommyy_PS

#### **worklog 1**

- ตรวจไอคอนของหน้าที่ทำมาแล้ว พบว่าหน้าช่องติ๊กใช้ไอคอนจากไลบรารีนอกไฟล์ทั้งหมด ส่วนหน้าตารางใช้ปนกันสามแหล่ง
- เปลี่ยนเครื่องหมายของช่องติ๊กเป็นไอคอนในเซ็ตของเรา พร้อมผูกขนาดและสีกลับครบ
- เปลี่ยนปุ่มลิงก์รุ่นเก่าที่มาจากนอกไฟล์ในเซลล์ตารางชนิดไอคอน ให้เป็นปุ่มลิงก์ไอคอนตัวปัจจุบัน แล้วตั้งไอคอนผ่านคุณสมบัติสลับแทนการเจาะเข้าไปเปลี่ยนเอง
- เพิ่มคุณสมบัติสลับไอคอนให้ปุ่มลิงก์ไอคอนตระกูลที่ยังไม่มี ให้เท่ากับอีกสองตระกูล
- สแกนต่อแล้วพบว่าการอ้างคุณสมบัติหลุดกระจายทั้งหน้าปุ่ม จึงไล่ผูกให้ครบ ทั้งคุณสมบัติสลับไอคอน คุณสมบัติเปิดปิดไอคอน และช่องข้อความหัวข้อ
- สแกนหน้าอื่นเพิ่มเพื่อดูว่ามีอาการเดียวกันไหม

#### **ผลตรวจ**

- หน้าช่องติ๊ก เปลี่ยนไอคอน 80 จุด ไอคอนนอกเซ็ตเหลือ 0
- เซลล์ตารางชนิดไอคอน เปลี่ยนปุ่มลิงก์ 4 ตัว และตั้งไอคอนใหม่ครบ 5 ปุ่ม
- ผูกคุณสมบัติที่หลุดรวม 550 จุด ใน 19 ชุด แบ่งเป็นคุณสมบัติสลับไอคอน 266 จุด และคุณสมบัติเปิดปิดไอคอนกับช่องข้อความ 284 จุด
- ตรวจก่อนผูกทุกจุดว่าค่าปัจจุบันตรงกับค่าเริ่มต้น ได้ 550 จาก 550 จึงไม่มีอะไรเปลี่ยนหน้าตา
- ทดสอบจริงด้วยชิ้นงานชั่วคราว เปลี่ยนข้อความ เปิดไอคอน เปลี่ยนไอคอน แล้วสลับไปสถานะโฟกัส ผ่าน 4 จาก 4 ชุดที่ทดสอบ
- สแกนหน้าช่องกรอก หน้าแท็ก และหน้าป้ายเพิ่ม รวม 143 ชุด ไม่พบอาการเดียวกันสักจุด

#### **ที่ไม่ได้ทำตามที่เขียนไว้**

- ดาวให้คะแนนในตาราง 10 จุด ไม่ย้าย เพราะเป็นชุดที่มีแกนเปอร์เซ็นต์ 11 ขั้นสำหรับดาวเติมบางส่วน ซึ่งเซ็ตของเราไม่มีของแทน ข้อนี้เขียนไว้ในขอบเขตตั้งแต่แรกแล้ว
