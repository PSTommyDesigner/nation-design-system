# [Employee Eval]-[Job description] Design หน้าตำแหน่งทั้งหมด หน้าองค์กรณ์ทั้งหมด (Desktop)

## รายละเอียดงาน

**Problem ปัญหาคืออะไร ? :** ไม่มี Job Description Template ของแต่ละตำแหน่ง
**Goal ทำเพื่ออะไร ? :** สร้าง Job Description Template เพื่อเป็นมาตรฐานกลางให้แต่ละบริษัท
**Requirements ขอบเขตงาน**

1. หน้า Job Description List และหน้าเพิ่ม ลบ แก้ไข Job Description (ใช้งานได้เฉพาะ HR)
2. ส่วน Job Description Detail (บริษัท, องค์กร)
3. หน้าประเมินผล Job Description
