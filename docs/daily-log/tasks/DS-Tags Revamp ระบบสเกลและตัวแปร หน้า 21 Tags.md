# [DS]-[Tags] Revamp ระบบสเกลและตัวแปร หน้า 21 Tags

## รายละเอียดงาน

#### **Problem**

- แท็กไม่มีสูตรความสูง ความสูงจึงงอกมาจากระยะขอบบวกความสูงบรรทัด ทำให้บันไดขนาดของแท็กไปทับบันไดของปุ่ม แท็กบางขนาดสูงเท่าปุ่มพอดีทั้งที่ชื่อขนาดคนละขั้น
- หัวหน้าแยกตัวแปรใหม่เป็นรายทรงรายชนิด แต่ทุกชุดยังผูกกับกลุ่มฐานร่วมกันหมด และมีมุมโค้งรายชนิดซ้ำซ้อนที่ไม่มีใครใช้

#### **Goal**

- ให้แท็กมีบันไดความสูงของตัวเองที่คุมด้วยสูตร ไม่ทับบันไดของปุ่ม
- ให้ตัวแปรผูกถูกหมวดตามทรงและชนิด และมีด่านตรวจจับได้ตอนสร้างไฟล์ถ้าค่าหลุดกัน

#### **Requirements**

- ผูกตัวแปรรายชนิดให้ครบทั้ง 110 ชุด
- ยุบมุมโค้งรายชนิดเข้าหมวดทรง แล้วลบตัวที่ไม่ได้ใช้
- เขียนสูตรใหม่ให้ความสูงเป็นตัวตั้ง ระยะขอบเป็นค่าที่คำนวณได้
- ตั้งชื่อตัวแปรฝั่งโค้ดให้ยึดตามไฟล์ออกแบบ
- ไล่แก้ไฟล์ออกแบบให้ตรงกับสูตร
- ใส่ด่านตรวจตอนสร้างไฟล์

### 2026-09-17 Tommyy_PS

#### **worklog 1**

- ผูกตัวแปรที่หัวหน้าแยกใหม่รายทรงรายชนิดให้ครบทั้ง 110 ชุด จากเดิมที่ทุกชุดไปผูกกับกลุ่มฐานร่วมกันหมด
- ลบมุมโค้งที่ไม่มีใครใช้ 10 ตัว ให้ทรงมุมมนเหลือค่ารายมุมล้วน และทรงแคปซูลเหลือค่าเต็มวงล้วน
- ยุบมุมโค้งรายชนิดเข้าหมวดทรงตามที่สั่ง ย้ายจุดผูกโดยค่าเท่าเดิมทุกจุด แล้วลบตัวแปรรายชนิดออกอีกชุด เหลือมุมโค้งของแท็กแค่ 5 ตัว
- ตรวจพบว่าสเกลแท็กไปทับสเกลปุ่ม เพราะแท็กไม่มีสูตรความสูง ความสูงจึงงอกมาจากระยะขอบ ทำให้แท็กบางขนาดสูงเท่าปุ่มพอดีทั้งที่ชื่อขนาดคนละขั้น
- เขียนสูตรใหม่ทั้งไฟล์ ให้ความสูงเป็นตัวตั้งด้วยบันไดค่าเริ่ม 16 เพิ่มขั้นละ 4 แล้วให้ระยะขอบบนล่างเป็นค่าที่คำนวณจากความสูงลบความสูงบรรทัดของตัวอักษร ไม่ใช่ค่าที่พิมพ์เอง
- ตั้งชื่อตัวแปรฝั่งโค้ดให้ยึดตามไฟล์ออกแบบ ชุดฐานอยู่ใต้ทรงตรง ๆ ไม่มีชั้นคั่น และชื่อชนิดใช้เต็ม
- ใส่ด่านตรวจตอนสร้างไฟล์ 4 ชั้น ทั้งสมการปิดของความสูง ระยะขอบต้องเป็นจำนวนเต็มบวก กรอบข้อความต้องแคบกว่าขอบกล่อง และไอคอนต้องไม่ล้นความสูง
- ไล่แก้ไฟล์ออกแบบให้ตรงกับสูตร ทั้งระยะขอบของกล่อง ระยะขอบของกรอบข้อความ และตัวอักษรที่ใช้ผิดขนาด
- สร้างตัวแปรความสูงของแท็กสองทรง ทรงละ 5 ขนาด ซึ่งเดิมไม่มีเลย
- เจอว่าชนิดที่มีของนำหน้าไม่ได้คุมความสูงด้วยกล่องนอก เพราะกล่องนอกชนขอบ ตัวที่คุมจริงคือกรอบข้อความ จึงต้องแก้ทั้งสองชั้น

#### **ผลตรวจ**

- ชิ้นงาน 4,530 แบบใน 110 ชุด เข้าบันไดความสูง 16 20 24 28 32 ครบ ไม่ตรงบันได 0 แบบ
- ย้ายจุดผูกมุมโค้ง 5,280 จุด ค่าตรงกันทุกจุด ไม่มีอะไรเปลี่ยนหน้าตา และลบตัวแปรทิ้งรวม 20 ตัว
- แก้ตัวแปรระยะขอบ 140 ตัว และตัวอักษรที่ใช้ผิดขนาด 48 จุด
- สร้างตัวแปรความสูงใหม่ 10 ตัว
- สแกนปิดงานหน้า 21 ได้สีดิบ 0 จุด มุมโค้งไม่ผูก 0 จุด ตัวแปรของแท็กมีคำอธิบายครบทุกตัว ขีดยาว 0
- สร้างไฟล์ผ่าน ได้ตัวแปรฝั่งโค้ด 401 ตัว และทดสอบด่านตรวจด้วยการจงใจใส่ค่าผิด ยืนยันว่าสร้างไฟล์ไม่ผ่านจริง

#### **ที่ไม่ได้ทำตามที่เขียนไว้**

- เอกสารของหน้านี้ทั้งในไฟล์ออกแบบสองอันและในเครื่องหนึ่งอัน ยังเป็นชื่อตัวแปรชุดเก่า ยังไม่ได้แก้เพราะหัวหน้าขอปรับตัวแปรอีกนิดหน่อยก่อน
- โค้ดแท็กฝั่ง React อ้างตัวแปร 47 ตัวที่ไม่มีอยู่แล้ว เพราะเปลี่ยนโครงชื่อ ยังรอตัดสินว่าจะเขียนสไตล์แยกตามทรง หรือให้ตัวสร้างปล่อยชื่อกลางเพิ่ม
