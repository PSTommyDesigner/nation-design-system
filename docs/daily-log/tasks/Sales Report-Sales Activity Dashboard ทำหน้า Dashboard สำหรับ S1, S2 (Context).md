# [Sales Report]-[Sales Activity Dashboard] ทำหน้า Dashboard สำหรับ S1, S2 (Context)

## รายละเอียดงาน

**Problem ปัญหาคืออะไร ? :** ระบบเดิม(Sales Report)ข้อมูลรายงานการขายส่วนใหญ่ที่คีย์นำมาวัดผลหรือประเมิณอะไรไม่ได้
**Goal ทำเพื่ออะไร ? :** แสดงภาพรวมการทำงาน การคีย์ข้อมูลรายงานการขาย
**Requirements ขอบเขตงาน**

1. การคีย์ข้อมูลของ Sales S1
2. ข้อมูลดีลทั้งหมดตั้งแต่ยื่นข้อเสนอไปจนถึงปิดการขาย
3. ข้อมูลการขายแบบทั้งปี
