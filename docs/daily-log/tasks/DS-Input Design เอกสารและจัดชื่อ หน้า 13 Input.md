# [DS]-[Input] Design เอกสารและจัดชื่อ หน้า 13 Input

## รายละเอียดงาน

**Problem**

- หน้า 13 Input **ไม่มีเอกสารสักชนิดจาก 5 ชนิดที่มาตรฐานกำหนด** มีแต่หัวเอกสารลอยบนแคนวาส 2 อัน
- ชื่อชั้นและชื่อคุณสมบัติผิดกติกาเกือบทั้งหน้า ยังเป็นตัวใหญ่ มีเว้นวรรครอบขีดทับ และสะกดคำว่า Label ผิดเป็น Lebel ทั้ง 3 ชุด
- สถานะถูกทำเป็นตัวเปิดปิดแยกกัน 3 ตัว คือ Hover, Focused, Disabled แทนที่จะเป็นคุณสมบัติเดียวชื่อ state ทำให้ชุดหนึ่งบวมเป็น 63 แบบ และเปิดพร้อมกันได้ทั้งที่ไม่ควรเป็นไปได้
- มีสีที่ยังไม่ผูกตัวแปร 90 จุด
- ไอคอนข้างในยังเป็นชุดสำเร็จรูปเก่า ไม่ใช่ Nation UI Icons
- ยังไม่มีสูตรขนาดและระยะห่างใน tokens/scale ทำให้ค่าทั้งหมดเป็นเลขที่พิมพ์มือ

**Goal**

- หน้า 13 Input มีเอกสารครบตามมาตรฐาน เรียงตามลำดับที่ตกลงกันไว้ และมีเอกสารฝั่งโค้ดที่ docs/13-input.md
- ชื่อทุกชั้นและทุกคุณสมบัติตรงกติกา สีผูกตัวแปรครบ ไม่มีสีดิบเหลือ
- มีสูตรขนาดและระยะห่างของช่องกรอกอยู่ใน tokens/scale/input.mjs พร้อมตัวแปรใน Figma

**Requirements**

- สำรวจของจริงทั้งหน้าก่อน แล้วแจกแจงขอบเขตให้อนุมัติก่อนลงมือ ตามกฎ ask first
- 3 ชุดที่มีอยู่ Text field / Default 63 แบบ, Text field / Under line 63 แบบ, Text area 18 แบบ รวม 144 แบบ
- ตัดสินเรื่องโครงสถานะว่าจะยุบ 3 ตัวเปิดปิดเป็นคุณสมบัติเดียวหรือคงไว้ เพราะกระทบจำนวนแบบทั้งหมด
- เอกสารที่ต้องมี Page Documentation 1 อัน, Information Document, Component Previews, Space Document และ Token Document ถ้าหน้ามีตัวแปร
- ผูกสี 90 จุดจาก collection component และเปลี่ยนไอคอนเป็น Nation UI Icons
- ก่อนบอกเสร็จต้องสแกนตาม Definition of Done ให้ครบ สีดิบเป็นศูนย์ ขีดยาวเป็นศูนย์ ขนาดต้นฉบับไม่เพี้ยน
- ลบหัวเอกสารลอย 2 อันหลังทำเอกสารจริงเสร็จแล้วเท่านั้น

#### **งานค้าง**
- **ความสูงแท็ก ไอคอนกากบาท และ preset ตัวอักษรในแท็ก** อยู่ในต้นฉบับของหน้า 21 Tags แก้จากหน้า 13 ไม่ได้
- **ตัวนับตัวอักษร คำนำหน้าที่เป็นข้อความ และสถานะเตือนกับสำเร็จ** ยังไม่ทำ โครงเผื่อที่ไว้แล้ว
- **จุดคั่นผิดกติกาในแม่แบบเอกสารหน้า 00** แก้ในหน้า 13 แล้ว ต้นทางยังไม่ได้แก้

#### **งานที่ทำวันนี้**
- **สั่งวิจัยช่องกรอกของเจ้าใหญ่ 13 เจ้า** เพื่อเทียบกับของเราก่อนลงมือหน้าถัดไป ได้ข้อสรุปว่าเราตามหลัง 12 ข้อ เท่ากัน 3 ข้อ นำหน้า 1 ข้อ
- **หัวหน้าเคาะ 5 เรื่องที่แก้ทีหลังแพง** รับ 3 ขนาดที่ใช้สูตรความสูงร่วมกับปุ่ม ยุบสถานะเป็นคุณสมบัติเดียว 7 ค่า ยกเลิกทรงขีดล่าง แยกแท็กกับช่องบัตรออกไป และใช้ดอกจันฝั่งบังคับกรอก
- **ปิดการ์ดอวาตาร์และเปิดการ์ดช่องกรอก** พร้อมสร้างการ์ดสรุปเดือนกันยายนกับหัวข้อย่อยสองอัน แล้วยกงานค้างจากเดือนสิงหาคมมาให้ครบ
- **สั่งวิจัยช่องกรอกก่อนลงมือ แล้วหัวหน้าเคาะ 5 เรื่องที่แก้ทีหลังแพง** รับ 3 ขนาดที่ใช้สูตรความสูงร่วมกับปุ่ม ยุบสถานะเป็นคุณสมบัติเดียว ยกเลิกทรงขีดล่าง แยกแท็กกับช่องบัตรออกไป และใช้ดอกจันฝั่งบังคับกรอก
- **ย้ายสูตรความสูงขึ้นเป็นค่ากลางที่ปุ่มกับช่องกรอกใช้ร่วมกัน** ตรวจแล้วปุ่มไม่กระทบ ค่าเท่าเดิมทุกขนาด
- **เขียนสูตรของช่องกรอกให้จบทุกมิติ** จากเดิมที่มีแต่มุมโค้ง แล้วสร้างตัวแปรในไฟล์ออกแบบ 35 ตัว
- **ใส่ค่า base ผิดครั้งหนึ่ง** เพราะลืมว่าดัชนีของขนาดเล็กสุดที่ช่องกรอกเปิดใช้ไม่ใช่ศูนย์ จับได้ตอนอ่านค่าที่ build ออกมา แล้วเขียนกำกับไว้ในไฟล์กันคนถัดไปพลาดซ้ำ
- **รื้อชุดช่องกรอกจาก 144 แบบเหลือ 96 แบบ** โดยแก้ที่ชุดเดิมในที่ ไม่สร้างใหม่จากศูนย์ เพราะสีทุกสถานะกับระบบคุณสมบัติผูกไว้ครบแล้ว ถ้าสร้างใหม่ต้องต่อสายเองทั้งหมด
- **ยกช่องเสียบหน้าหลังมาจากของเดิมก่อนลบ** จะได้ไม่ต้องวาดใหม่ และของยังเป็นชิ้นเดียวกับที่เคยใช้
- **แยกช่องแท็กกับช่องบัตรออกเป็นชุดของตัวเอง** แล้วทำให้มีขนาดกับสถานะเท่าชุดอื่น เพื่อไม่ให้ชุดพี่น้องมีแกนไม่เหมือนกัน
- **เจอสำเนาที่หน้าอื่นหลุดเพราะต้นฉบับที่มันชี้ถูกลบ** ย้ายมาชี้ตัวใหม่พร้อมเปิดช่องเสียบให้เหมือนเดิม
- **ลบตัวแปรมุมโค้งรุ่นเก่าที่ไม่มีขนาด** ย้าย 340 จุดที่ผูกอยู่ไปใช้ตัวใหม่ก่อน แล้วตรวจว่าไม่เหลือใครใช้จึงลบ
- **ผูกชุดตัวอักษรให้ครบ 336 จุด** พบว่าข้อความช่วยเดิมผูกกับชุดที่ไม่มีอยู่ในไฟล์เราแล้ว น่าจะมาจากไลบรารีอื่นหรือถูกลบไป
- **ทำเอกสารครบทั้ง 5 ชนิดเป็นหน้าแรกของโปรเจกต์** จากเดิมที่หน้านี้ไม่มีเอกสารสักชนิด
- **ใส่ค่าลงผิดคอลัมน์ในตารางสูตร** เพราะแม่แบบมี 5 ขนาดแต่ช่องกรอกมี 3 จับได้เพราะอ่านค่ากลับมาดู ไม่ได้เชื่อว่าสั่งแล้วถูก แก้โดยตัดคอลัมน์ที่ไม่ใช้ออก
- **ลืมผูกสีตอนสร้างข้อความใหม่** จับได้ตอนสแกนก่อนปิดงาน
- **เจอจุดคั่นผิดกติกาที่ติดมากับแม่แบบเอง** แก้ในหน้านี้แล้ว แต่ตัวแม่แบบยังมีอยู่ ต้องแก้ที่ต้นทางอีกที
- **สีที่ไม่ได้ผูกตัวแปร 120 จุดเป็นข้อยกเว้น** ทุกจุดเป็นสำเนาโลโก้ผู้ให้บริการบัตรจากหน้าโลโก้ภายนอก เป็นสีอัตลักษณ์ของแบรนด์อื่นที่ต้องคงค่าไว้ เข้าเกณฑ์เดียวกับหน้าโลโก้ในเครือ
- **หัวหน้าตรวจงานแล้วเจอ 4 จุดที่ผมพลาด** กล่องพื้นเทาที่ไม่ควรมี ช่องบัตรที่ซ้ำซ้อน ช่องแท็กที่ไม่แสดงแท็ก และการจัดตำแหน่งข้อความในช่อง
- **แกะกล่องพื้นเทาออก 11 จุด** เป็นกรอบตัวอย่างในแม่แบบที่กฎเขียนไว้ว่าเอกสารจริงไม่ต้องมี ผมลอกมาทั้งกรอบโดยไม่ได้แกะ
- **ช่องแท็กไม่แสดงแท็กเพราะถูกซ่อนไว้ทั้งหมด** เปิดให้เห็น 2 อันเป็นค่าเริ่มต้น แล้วแก้ชื่อคุณสมบัติกับคำสะกดผิดที่ยังค้างในชุดนี้
- **เจอบั๊กต่อเนื่องในช่องแท็ก 3 ชั้น** ข้อความตกลงไปใต้แท็กแล้วล้นกรอบเพราะผมตรึงความสูงทั้งที่ต้องสูงตามจำนวนแท็ก แล้วเส้นคั่นค้างความสูงเก่าดันกล่องผิด แล้วสุดท้ายช่องจะสูงเกินไป 2px ซึ่งจะกลับไปเป็นปัญหาที่เพิ่งแก้ทั้งหน้า จึงเพิ่มสูตรระยะขอบของช่องแท็กให้ความสูงลงตัวพอดี
- **แก้การจัดตำแหน่งข้อความ 96 จุด** ช่องบรรทัดเดียวให้อยู่กลาง ช่องหลายบรรทัดให้ชิดบน
- **เปลี่ยนไอคอนเป็นชุดของเครือ 144 จุด** โดยสลับผ่านช่องสลับไอคอนที่ต้นฉบับเปิดไว้ ไม่ใช่ไปแก้ทับข้างในสำเนา ซึ่งจะหลุดทันทีที่ต้นฉบับเปลี่ยน
- **ยอมรับว่าช่องบัตรซ้ำซ้อนจริงตามที่หัวหน้าทัก** ตรวจแล้วโครงเหมือนช่องกรอกทั่วไปที่เปิดช่องเสียบหน้าทุกประการ ความต่างอยู่ในโค้ดไม่ได้อยู่ในไฟล์ออกแบบ ตอนเสนอแยกออกมาผมยกเหตุผลจากงานวิจัยโดยยังไม่ได้เปิดดูโครงจริง
- **ลบชุดช่องบัตรทิ้ง 24 แบบ** ทำให้สีที่ผูกตัวแปรไม่ได้เหลือศูนย์ จากเดิม 120 จุดที่เป็นโลโก้บัตรฝังอยู่ในต้นฉบับ
- **เจอบั๊กที่ตัวเองทำไว้ตอนสร้างเอกสาร** โคลนหัวข้อหลังใส่ชุดแรกเข้าไปแล้ว ทำให้ทุกหัวข้อติดสำเนาของชุดแรกไปด้วย เหลือชุดซ้ำ 2 ชุดกับกรอบเปล่าอีก 2 อัน จับได้ตอนอ่านรายชื่อชุดหลังลบช่องบัตร แล้วเห็นชื่อเดียวกันโผล่ 3 ครั้ง
- **สแกนปิดงานผ่านหมด** สีที่ผูกตัวแปรไม่ได้เป็นศูนย์ ขีดยาวเป็นศูนย์ จุดคั่นผิดที่เป็นศูนย์ ไอคอนชุดเก่าเป็นศูนย์ ข้อความที่ไม่ได้ผูกชุดตัวอักษรเป็นศูนย์ และความสูงกล่องตรงกับปุ่มทั้งสามขนาด
