# [DS]-[Cleanup] Fix ชื่อเลเยอร์แท็กรูปภาพ จุดคั่นแม่แบบ และกติกา worklog

## รายละเอียดงาน

**Problem ปัญหาคืออะไร ?**
- ลูกของแท็กรูปภาพชื่อ number ค้างจากตอนคัดลอกมาจากแท็กตัวเลข ทำให้คนเปิดดูโครงเข้าใจผิดว่าเป็นตัวเลข กระทบ 20 ชุด 300 จุด
- แม่แบบเอกสารหน้า 00 ยังใช้จุดกลางในหัวข้อและข้อความก้อนเดียว ซึ่งกติกาอนุญาตเฉพาะบรรทัดที่เป็นรายการ แก้ที่หน้า 13 ไปแล้วแต่ต้นทางยังไม่ได้แก้ ทำให้เอกสารที่คัดลอกจากแม่แบบรับความผิดไปด้วยทุกใบ
- การ์ดสรุปเดือนสิงหาคมยังเปิดค้าง และสถานะเพี้ยนไปอยู่ที่รับบรีฟงานใหม่ ทั้งที่งานเดือนนั้นจบไปแล้ว
- กติกา worklog ยังไม่ได้เขียนข้อจำกัดที่เพิ่งเจอ คือ Asana ตั้ง Start date เดี่ยวไม่ได้ และยังเขียนกำกวมจนตีความเป็นโพสต์คอมเมนต์งานค้างใบใหม่ได้
**Goal ทำเพื่ออะไร ?**
- ชื่อเลเยอร์สื่อความหมายตรงกับสิ่งที่มันเป็นทุกจุด
- แม่แบบหน้า 00 ไม่เหลือจุดคั่นผิดกติกา เอกสารที่คัดลอกไปต่อจะได้ไม่รับความผิดไปด้วย
- บอร์ดสะท้อนสถานะจริง ไม่มีการ์ดที่เสร็จแล้วค้างอยู่ในกองรับบรีฟ
- กติกาเขียนสิ่งที่ทำได้จริง ไม่ใช่สิ่งที่ทำตามตรง ๆ ไม่ได้
**Requirements ขอบเขตงาน**
1. เปลี่ยนชื่อลูกของ image-tag และ pill-image-tag จาก number เป็น image 300 จุดใน 20 ชุด
2. ไม่แตะชื่อ number ในชุด number-tag เพราะถูกอยู่แล้ว
3. แก้จุดคั่นในแม่แบบหน้า 00 เฉพาะที่ไม่ใช่บรรทัดรายการ แล้วสแกนทั้งหน้าซ้ำ
4. ปิดการ์ดสรุปเดือนสิงหาคม พร้อมแก้สถานะให้ตรงกับที่งานเสร็จแล้ว
5. เติมกติกา 2 ข้อลง docs/rules/worklog.md
6. ตรวจหลังทำว่าขนาด COMPONENT ต้นฉบับไม่เปลี่ยน และการตัดบรรทัดของหน้า 21 ยังเป็น 5 ชิ้นต่อแถวทุกชุด

## บันทึกงาน

### 2026-09-10 Tommyy_PS

#### **worklog 1**

- เปลี่ยนชื่อลูกของแท็กรูปภาพจาก number เป็น image ครบทั้ง image-tag และ pill-image-tag ตรวจก่อนแก้ว่าไม่มีจุดไหนผูกกับ component property จึงเปลี่ยนชื่อได้โดยไม่กระทบการทำงาน ส่วนชื่อ number ในแท็กตัวเลขถูกอยู่แล้วจึงไม่แตะ
- แก้จุดคั่นในแม่แบบเอกสารหน้า 00 โดยยึดถ้อยคำเดียวกับหน้า 13 ที่แก้ไปแล้ว เช่น หัวข้อเปลี่ยนเป็น Usage ควรและไม่ควร และข้อความเกณฑ์การเข้าถึงเขียนใหม่เป็นภาษาไทยที่อ่านรู้เรื่องโดยไม่ต้องใช้จุดคั่น
- ปิดการ์ดสรุปเดือนสิงหาคมพร้อม subtask ทั้งสองอัน และแก้สถานะที่ค้างอยู่ในกองรับบรีฟทั้งที่งานเดือนนั้นจบไปแล้ว
- เติมกติกาลง worklog.md 3 ข้อ และแก้สคริปต์ push ให้ทำตามโครงใหม่ ไม่งั้นรอบ 16:30 จะยัดทุกวันกลับเป็นคอมเมนต์ใบเดียวเหมือนเดิม

#### **ผลตรวจ**

- เปลี่ยนชื่อ 300 จุดใน 20 ชุด ไม่เหลือชื่อ number ในแท็กรูปภาพเลย และแท็กตัวเลขยังคงชื่อเดิมครบ 300 จุด
- ขนาด COMPONENT ต้นฉบับของหน้า 21 เทียบก่อนหลัง 2,625 ตัว ไม่เปลี่ยนสักตัว และทั้ง 130 ชุดยังตัดบรรทัด 5 ชิ้นต่อแถว
- แม่แบบหน้า 00 แก้ 6 จุด เหลือจุดกลาง 3 จุดซึ่งอยู่ในบรรทัดรายการจริง จึงไม่ผิดกติกา และขีดยาวเป็น 0 ทุกจุดยังผูกกับ text style เดิม
- การ์ดเดือนสิงหาคมปิดแล้ว สถานะเป็นรอ Stakeholder ตรวจสอบ วันเริ่ม 5 สิงหาคม วันเสร็จ 31 สิงหาคม และ subtask ปิดครบทั้งสองอัน
- สคริปต์ push ทดสอบแบบไม่ส่งจริงแล้ว อ่านหัวข้อวันได้ถูกต้องและจะเขียนทับคอมเมนต์ของวันนั้น ไม่สร้างใบใหม่

#### **ที่แก้เพิ่มนอกขอบเขตเดิม**

- กติกาข้อ subtask งานที่ทำ เดิมเขียนว่าใช้คอมเมนต์ใบเดียวทั้งเดือน ซึ่งขัดกับที่เพิ่งเปลี่ยนเป็น 1 วัน 1 คอมเมนต์ จึงแก้ทั้งกติกาและสคริปต์ให้ตรงกัน ถ้าไม่แก้ รอบ push ถัดไปจะทำลายโครงที่เพิ่งจัดไป

- ทั้งสองเดือนไม่มีใบไหนมีหลายวันซ้อนกัน และไม่มีใบไหนที่หัวข้อติดกับเนื้อหา
