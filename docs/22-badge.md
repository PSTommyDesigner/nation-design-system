## 2. วัตถุประสงค์ (Objective & Business Logic)

- **เป้าหมาย:** ให้ทุกเว็บในเครือใช้ป้ายสถานะหน้าตาเดียวกัน และแยกออกจากแท็กได้ชัดว่าอันไหนกดได้อันไหนกดไม่ได้
- **Business logic:** เว็บข่าวในเครือติดป้าย ด่วน สด ล่าสุด และตัวเลขแจ้งเตือน อยู่แทบทุกหน้า ป้ายพวกนี้ระบบเป็นคนใส่ให้ ผู้ใช้แตะไม่ได้ ถ้าใช้ของเดียวกับแท็กที่กดได้ ผู้ใช้จะพยายามกดแล้วไม่เกิดอะไรขึ้น
- **คุณค่า:** ความสม่ำเสมอข้ามแบรนด์ แยกของนิ่งออกจากของที่โต้ตอบได้ และส่งงานให้ Developer ด้วยชื่อตัวแปรแทนตัวเลข

## 3. ขั้นตอนการใช้งาน (Workflow)

### สำหรับ Designer

1. **ถามก่อนว่าใครเป็นคนเปลี่ยนค่า** ถ้าระบบเป็นคนเปลี่ยนให้ใช้ป้าย ถ้าผู้ใช้เป็นคนเปลี่ยนให้ใช้แท็กที่หน้า 21
2. เลือกชนิดจาก 5 ชนิด ตามทรง ตามว่ามีข้อความหรือมีแต่ไอคอน และชุดข้อความล้วน `link-badge`
3. เลือกระดับความเด่นในแกน `hierarchy` แล้วเลือกขนาดจากของที่ป้ายไปเกาะ ไม่ใช่จากความสำคัญ
4. ห้ามวางป้ายลอย ป้ายต้องเกาะกับของอื่นเสมอ และหนึ่งของควรมีป้ายเดียว

### สำหรับ Developer

1. อ่านชื่อตัวแปรจากเอกสาร `Badge Token` บนหน้า Figma หรือจากตารางข้อ 4.3
2. ใช้ตัวแปร CSS จาก `tokens/output/css/variables.css` ห้ามพิมพ์ตัวเลขเอง
3. ป้ายไม่รับโฟกัสจากแป้นพิมพ์และไม่มีสถานะ hover เพราะกดไม่ได้

### สำหรับการ Sync

1. แก้ค่าที่ `tokens/scale/badge.mjs` เท่านั้น แล้วรัน `npm run tokens:build`
2. อัปเดตตัวแปรใน Figma ให้ตรงกับค่าที่ build ออกมา
3. ด่านตรวจในไฟล์สูตรจะไม่ยอมให้สร้างไฟล์ถ้าค่าบวกกลับไม่ตรง

## 4. โครงสร้างข้อมูลและ UI (Structure)

### 4.1 ชนิดของป้าย

| ชื่อ component | ทรง | จำนวนแบบต่อตระกูล | ใช้ตอนไหน |
|---|---|---:|---|
| `semi-rounded-badge` | มุมมน | 15 | ค่าปกติของงานทั่วไป เข้ากับการ์ดและตารางที่ใช้มุมมนอยู่แล้ว |
| `pill-badge` | แคปซูล | 15 | ตอนอยากให้ดูนุ่มขึ้น หรือวางคู่กับแท็กทรงแคปซูล |
| `semi-rounded-icon-badge` | มุมมน | 15 | มีแต่ไอคอน ใช้ตอนพื้นที่แคบจนใส่คำไม่ได้ |
| `circular-icon-badge` | วงกลม | 15 | มีแต่ไอคอน ใช้ตอนเกาะมุมของไอคอนหรืออวาตาร์ |
| `link-badge` | ไม่มีพื้นไม่มีขอบ | 5 | ข้อความล้วน ตอนไม่อยากให้ป้ายแย่งสายตาจากเนื้อหา |
| **รวมต่อตระกูล** | | **65** | 11 ตระกูลสี รวมทั้งหน้า 715 แบบ |

ชื่อชุดขนานกับปุ่มและแท็กโดยตั้งใจ คือ `semi-rounded-` มุมมน `pill-` แคปซูล `circular-` วงกลม `link-` ข้อความล้วน

**สไตล์อยู่ในแกน `hierarchy` ไม่ใช่ชื่อชุด** ตามแบบหน้า 12 Buttons

**ระดับล่างสุดแยกออกเป็นชุดของตัวเองแล้ว (เปลี่ยน 2026-09-22)** เดิมแกน `hierarchy` มี 4 ค่า ตอนนี้เหลือ 3 เพราะ `quaternary` ซึ่งเป็นข้อความล้วนถูกแยกออกมาเป็นชุด `link-badge` ทำตามที่แท็กแยก `link-tag` เมื่อ 2026-09-18

| ระดับ | พื้น | ขอบ | ใช้ตอนไหน |
|---|---|---|---|
| `primary` | ทึบ | ไม่มี | ของที่ต้องเห็นก่อนเพื่อน เช่น ข่าวด่วน |
| `secondary` | อ่อน | ไม่มี | ค่าปกติของงานทั่วไป |
| `tertiary` | ขาว | มี | ตอนพื้นหลังมีสีอยู่แล้ว |
| `link-badge` (คนละชุด) | ไม่มี | ไม่มี | ตอนไม่อยากให้แย่งสายตาจากเนื้อหา |

15 แบบต่อชุด คือ 3 ระดับความเด่น คูณ 5 ขนาด ส่วน `link-badge` มี 5 แบบเพราะไม่มีแกนความเด่น **ไม่มีแกน `state` โดยตั้งใจ** เพราะป้ายเป็นของนิ่ง

### 4.2 คุณสมบัติของ component

| Property | ชนิด | ค่า | คำอธิบาย |
|---|---|---|---|
| `hierarchy` | variant | `primary` `secondary` `tertiary` | ระดับความเด่น ไม่มีในชุด `link-badge` |
| `size` | variant | `xs` `sm` `md` `lg` `xl` | คุมความสูง ระยะขอบ และขนาดไอคอนพร้อมกัน |
| `badge-title` | text | ข้อความ | ข้อความในป้าย มีเฉพาะชนิดที่มีข้อความ |
| `trailing-icon` | boolean | `false` `true` | เปิดปิดไอคอนท้าย มีเฉพาะชนิดที่มีข้อความ |
| `trailing-icon-swap` | instance swap | ไอคอน | สลับไอคอนท้ายได้ |
| `leading-icon-swap` | instance swap | ไอคอน | สลับไอคอนได้ มีเฉพาะชนิดไอคอนล้วน |

### 4.3 ตัวแปรที่เกี่ยวข้อง

ป้ายใช้ตัวแปร 180 ตัว แยกตามทรงแล้วเหมือนแท็ก โครงชื่อคือ **ทรง คูณ มิติ คูณ ขนาด** ค่าจริงทุกตัวอยู่ใน `tokens/output/css/variables.css`

| ชื่อใน Figma | ชื่อในโค้ด | ค่า เรียง xs ถึง xl |
|---|---|---|
| `{ทรง}-badge/size/{ขนาด}` | `--ntg-space-badge-{ทรง}-size-{ขนาด}` | 18, 22, 26, 30, 34 |
| `{ทรง}-badge/padding/top` และ `bottom` | `--ntg-space-badge-{ทรง}-padding-top-{ขนาด}` | 1, 3, 2, 3, 4 |
| `semi-rounded-badge/padding/left` และ `right` | `--ntg-space-badge-semi-rounded-padding-left-{ขนาด}` | 4, 5, 6, 7, 8 |
| `pill-badge/padding/left` และ `right` | `--ntg-space-badge-pill-padding-left-{ขนาด}` | 6, 7, 8, 9, 10 |
| `{ทรง}-badge/padding/no` | `--ntg-space-badge-{ทรง}-padding-no` | 0 |
| `{ทรง}-badge/title-padding/left` และ `right` | `--ntg-space-badge-{ทรง}-title-padding-left-{ขนาด}` | 1, 2, 3, 4, 5 |
| `{ทรง}-badge/gap/{ขนาด}` | `--ntg-space-badge-{ทรง}-gap-{ขนาด}` | 2 |
| `{ทรง}-badge/icon/{ขนาด}` | `--ntg-space-badge-{ทรง}-icon-{ขนาด}` | 10, 12, 14, 16, 18 |
| `semi-rounded-badge/icon-badge/padding/{ขนาด}` | `--ntg-space-badge-semi-rounded-icon-badge-padding-{ขนาด}` | 4, 5, 6, 7, 8 |
| `circular-badge/padding/{ขนาด}` | `--ntg-space-badge-circular-padding-{ขนาด}` | 4, 5, 6, 7, 8 |
| `link-badge/size/{ขนาด}` | `--ntg-space-badge-link-size-{ขนาด}` | 16, 16, 22, 24, 26 |
| `semi-rounded-badge/radius/{ขนาด}/{มุม}` | `--ntg-badge-radius-semi-rounded-{ขนาด}-{มุม}` | 3, 3.5, 4, 4.5, 5 |
| `pill-badge/radius/full` | `--ntg-badge-radius-pill-full` | 9999 |
| `circular-badge/radius/full` | `--ntg-badge-radius-circular-full` | 9999 |

ความสูงของชุดข้อความมีทั้งสองฝั่ง แต่กล่องใน Figma หดตามเนื้อหา ความสูงจริงจึงเป็นผลจากระยะขอบบวกความสูงบรรทัด ตัวแปร `size` มีไว้ประกาศบันไดให้ฝั่งโค้ดเรียกใช้ตรง ๆ

## 5. ข้อควรระวังและปัญหาที่พบบ่อย (Constraints)

| # | ข้อควรระวัง | เหตุผล / วิธีปฏิบัติ |
|---|---|---|
| 1 | **ห้ามเพิ่มแกน `state` ให้ป้าย** | ป้ายเป็นของนิ่งตามนิยามสากล ถ้าที่ไหนต้องการของที่ชี้แล้วเปลี่ยนสีหรือกดได้ ให้ใช้แท็กที่หน้า 21 แทน |
| 2 | ห้ามวางป้ายลอย | ป้ายต้องเกาะกับของอื่นเสมอ ถ้าต้องวางลอยแปลว่าที่จริงต้องการแท็ก |
| 3 | ห้ามผูก tooltip กับตัวป้าย | ให้ผูกกับตัวแม่แทน เพราะป้ายไม่รับโฟกัสและไม่ควรดักการชี้ |
| 4 | หนึ่งของหนึ่งป้าย | ถ้าต้องติดหลายอันบนของชิ้นเดียว แปลว่าที่จริงต้องการแท็ก |
| 5 | ระยะขอบบนล่างไม่มีสูตร | เป็นผลลัพธ์จากความสูงเป้าหมายลบความสูงบรรทัดของ text style แล้วหารสอง ถ้าเปลี่ยน preset ต้องกลับมาคำนวณใหม่ทั้งตาราง |
| 6 | ระยะขอบของป้ายไอคอนล้วนเป็นผลลัพธ์ | คิดจากความสูงลบขนาดไอคอนแล้วหารสอง ห้ามตั้งเป็นสูตรอิสระ เพราะถ้าความสูงหรือไอคอนขยับ ค่านี้ต้องขยับตาม |
| 7 | ทุกมิติเท่ากับแท็กโดยตั้งใจ | ความสูง 18, 22, 26, 30, 34 ระยะขอบ ไอคอน และมุมโค้ง ยกมาจากแท็กทั้งชุดเมื่อ 2026-09-22 เพื่อให้ป้ายกับแท็กวางคู่กันในแถวเดียวได้ไม่เหลื่อม ถ้าจะเปลี่ยนต้องเปลี่ยนทั้งสองที่ |
| 8 | ชื่อระดับของป้ายกับของแท็กหมายถึงคนละหน้าตา | ป้าย `secondary` คือพื้นอ่อน `tertiary` คือมีขอบ ส่วนแท็กไม่มีพื้นอ่อน `secondary` ของแท็กจึงคือมีขอบ ทั้งคู่เหลือระดับละ 2 ถึง 3 ระดับหลังแยกข้อความล้วนออก รู้ตัวและยอมรับแล้ว เขียนกำกับไว้ทั้งใน `badge.mjs` และ `tag.mjs` |
| 9 | ไอคอนยังเป็นชุดเก่า | ป้ายใช้ไอคอนจากชุด Material design(2) ไม่ใช่ Nation UI Icons เหมือนแท็ก ยังไม่ได้ตัดสินว่าจะเปลี่ยนไหม |
| 10 | เขียนข้อความลงเซลล์ตารางต้องระบุ `text-value` | เซลล์มีข้อความ 2 บรรทัด ถ้าหยิบคุณสมบัติชนิดข้อความตัวแรกที่เจอจะไปลงบรรทัดรอง แล้วบรรทัดหลักจะค้างเป็นข้อความแม่แบบ เคยพลาดมาแล้ว |
| 11 | มุมโค้งทรงมุมมนมีขั้นเป็นครึ่งพิกเซล | `RADIUS_FORMULA.badge` ฐาน 3 ก้าว 0.5 ได้ 3, 3.5, 4, 4.5, 5 สูตรเดียวกับแท็ก ตั้งใจ ไม่ใช่ค่าหลุด |
| 12 | ความกว้าง variant ต้องหดตามเนื้อหา | เคยพบ 110 variant ถูกตั้งความกว้างตายตัวไว้ ทำให้ป้ายไอคอนไม่เป็นสี่เหลี่ยมจัตุรัส เช่น xl กว้าง 28 แต่สูง 34 แก้แล้ว 2026-09-22 ถ้าเพิ่ม variant ใหม่ต้องตั้งให้หดตามเนื้อหาเสมอ |
| 13 | ป้ายไอคอนล้วนไม่มีระดับข้อความล้วน | ระดับนั้นเหลือแค่ไอคอนสีเปล่าไม่มีกล่อง ซึ่งไม่ใช่ป้าย ลบออกเมื่อ 2026-09-22 ถ้าต้องการไอคอนเปล่าให้ใช้ component ไอคอนตรง ๆ |
