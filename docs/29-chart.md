## 2. วัตถุประสงค์ (Objective & Business Logic)

- **เป้าหมาย** ให้ทุกระบบในเครือแสดงตัวเลขด้วยกราฟหน้าตาเดียวกัน สีเดียวกัน และเข้าถึงได้เท่ากัน ไม่ใช่ต่างคนต่างหยิบไลบรารีกราฟมาเอง
- **Business logic** ใช้ครั้งแรกในหน้า Dashboard ของ One CMS กราฟแท่งเทียบจำนวนข่าวที่สร้างกับยอดเข้าชมรายวัน กราฟวงกลมคู่บอกสัดส่วนข่าวที่เขียนกับยอดวิวตามหมวด เพื่อให้เห็นว่าหมวดไหนเขียนเยอะแต่คนอ่านน้อย
- **คุณค่า** เขียน SVG เองด้วย React กับ CSS Modules ไม่เพิ่มไลบรารี เรนเดอร์บนเซิร์ฟเวอร์ได้ ใช้ token `--ntg-` ตรง ๆ และไม่ผูกเวอร์ชัน React ของโปรเจกต์ปลายทาง (Next 12 และ 14)

## 3. ขั้นตอนการใช้งาน (Workflow)

### สำหรับ Designer

1. เลือกกราฟจากคำถามของข้อมูล เทียบค่าตามเวลาหรือหลายชุดใช้ `bar-chart` บอกสัดส่วนของทั้งหมดใช้ `pie-chart`
2. หยิบ instance จากเอกสาร Chart Component Previews หน้า 29 **ห้ามวาดกราฟเอง** ตามกฎใช้ของ DS
3. `bar-chart` ยืดเต็มกรอบแม่ ความสูงพื้นที่กราฟเป็นค่าผังของหน้า ค่าเริ่มต้น 340 ส่วน `pie-chart` เลือกขนาด xs ถึง xl ตามที่ว่าง ค่าตั้งต้น md
4. ดูสถานะชี้ด้วย property `show-tooltip` ซึ่งเป็นภาพตัวอย่างในไฟล์ออกแบบเท่านั้น ไม่มี prop ในโค้ด
5. วางกราฟวงกลมบนพื้นหลักเท่านั้น เพราะช่องคั่นระหว่างชิ้นกับรูกลางวงเป็นสีพื้นหลัก

### สำหรับ Developer

1. ใช้ `BarChart` หรือ `PieChart` จาก `components/` ส่ง `summary` ทุกครั้ง เป็นประโยคสรุปสิ่งที่กราฟบอก ใช้เป็นชื่อของ figure ให้โปรแกรมอ่านหน้าจอ
2. ใส่ `unit` ให้ทุกชุดหรือทุกกราฟ เช่น ข่าว หรือ ครั้ง คำใบ้ ชื่อช่อง และตารางจะต่อหน่วยให้เอง
3. เปิดปุ่ม "ดูเป็นตาราง" (`showTableToggle`) ไว้เสมอเมื่อมีผู้ใช้จอสัมผัส เพราะจอสัมผัสไม่แสดงคำใบ้
4. สองกราฟวงกลมที่วางเทียบกันต้องส่ง `categories` ชุดเดียวกัน ทั้งสองวงจึงรวม "อื่น ๆ" เหมือนกัน และสีกับลำดับตรงกัน ส่วนรายการนั้นมาจากไหน เช่น 5 หมวดที่เขียนข่าวมากที่สุด เป็นกฎของโปรเจกต์
5. อย่าส่งสีดิบ สีชิ้นมาจาก `chart/color/category-*` ตามลำดับ ถ้าต้องให้หมวดหนึ่งเป็นสีเดิมทุกวัน ส่ง `color` เป็นเลขลำดับ 1 ถึง 8 หรือ `'other'`

### สำหรับ Maintainer (แก้ค่า)

1. สีแก้ที่ตัวแปรในคอลเลกชัน `component` ของ Figma และที่ `tokens/tokens.json/component.json` ให้ตรงกัน
2. ตัวเลขแก้ที่ `tokens/scale/chart.mjs` ซึ่งตรวจว่าจุดต้องใหญ่กว่าเส้นอย่างน้อยเท่าตัว ไม่กว้างเกินแท่ง และความหนาวงโดนัทต้องอยู่ราว 20 ถึง 35% ของรัศมี
3. รัน `npm run tokens:build` แล้ว `npm run tokens:verify` ต้องขึ้นว่าต้องดู 0 กลุ่ม

## 4. โครงสร้างข้อมูลและ UI (Structure)

### 4.1 ชุดในไฟล์ออกแบบ

| ชุด | ใช้ทำอะไร | แกนและ property |
|---|---|---|
| `bar-chart` | กราฟแท่งจัดกลุ่ม หลายชุด วางชุดแบบเส้นทับได้ แกน y สองฝั่ง | `show-legend`, `show-right-axis`, `show-tooltip` |
| `pie-chart` | กราฟวงกลมแบบโดนัท ยอดรวมกลางวง legend ใต้วงหรือข้างวง | `size` xs ถึง xl, `legend-placement` bottom, end, `show-legend`, `total`, `total-label`, `show-tooltip` |
| `_bar-chart-bar` | แท่งเดียว series 1 สีเข้ม series 2 สีอ่อนมีขอบ | `series` 1, 2 |
| `_bar-chart-legend-item` | จุดหรือเส้นคู่กับชื่อชุดข้อมูล | `type` bar-1, bar-2, line |
| `_bar-chart-point` | จุดกลวงบนเส้น | ไม่มี |
| `_pie-chart-legend-item` | จุดสี ชื่อหมวด และสัดส่วน | `series` 1 ถึง 8, other |

ชิ้นที่ขึ้นต้นด้วยขีดล่างใช้ประกอบกราฟเท่านั้น ไม่หยิบไปวางเดี่ยว และโค้ดไม่มี component แยกให้

### 4.2 Props ของ BarChart

| Prop | ชนิด | ค่าเริ่มต้น | คำอธิบาย |
|---|---|---|---|
| `categories` | `string[]` | บังคับ | ป้ายแกน x หนึ่งป้ายต่อหนึ่งหมวด เช่น วันที่ 1 ถึง 31 |
| `series` | `{ label, values, axis?, type?, unit? }[]` | บังคับ | ชุดข้อมูล `type` เป็น bar หรือ line, `axis` เป็น left หรือ right |
| `summary` | `string` | บังคับ | ประโยคสรุปของกราฟ |
| `categoryLabel` | `string` | `'รายการ'` | ชื่อของแกน x นำหน้าป้ายในคำใบ้ และหัวคอลัมน์แรกของตาราง |
| `showLegend` | `boolean` | `true` | ตรงกับ `show-legend` |
| `showRightAxis` | `boolean` | `true` เมื่อมีชุดบนแกนขวา | ตรงกับ `show-right-axis` |
| `showTableToggle` | `boolean` | `true` | ปุ่ม "ดูเป็นตาราง" |
| `formatValue` | `{ left?, right? }` | ตัวเลขแบบย่อ เช่น 240K | จัดรูปตัวเลขบนแกน y คำใบ้กับตารางใช้ตัวเลขเต็มเสมอ |
| `height` | `number` | `340` | ความสูงพื้นที่กราฟเป็นพิกเซล |

### 4.3 Props ของ PieChart

| Prop | ชนิด | ค่าเริ่มต้น | คำอธิบาย |
|---|---|---|---|
| `data` | `{ label, value, color? }[]` | บังคับ | ค่าของแต่ละหมวด `color` เป็น 1 ถึง 8 หรือ `'other'` |
| `summary` | `string` | บังคับ | ประโยคสรุปของกราฟ |
| `size` | `'xs'` ถึง `'xl'` | `'md'` | ขนาดวง |
| `maxSlices` | `number` | `5` | จำนวนหมวดที่แสดงชื่อ ที่เหลือรวมเป็น "อื่น ๆ" ถ้ามีหมวดไม่เกินค่านี้บวก 1 แสดงครบ |
| `categories` | `string[]` | ไม่มี | รายการหมวดที่แสดงชื่อและลำดับ ใช้กับสองวงที่เทียบกัน เมื่อส่งมาจะไม่ใช้ `maxSlices` |
| `otherLabel` | `string` | `'อื่น ๆ'` | ป้ายของชิ้นที่รวมหมวดที่เหลือ |
| `total` | `number` หรือ `string` | ผลรวมของ `data` | ยอดกลางวง ใช้แสดงอย่างเดียว เปอร์เซ็นต์ยังคิดจากผลรวมของ `data` |
| `totalLabel` | `string` | ไม่มี | ป้ายใต้ยอดรวม เช่น ข่าวทั้งหมด |
| `unit` | `string` | ไม่มี | หน่วยในคำใบ้และตาราง |
| `categoryLabel` | `string` | `'หมวด'` | หัวคอลัมน์แรกของตาราง |
| `valueLabel` | `string` | `'จำนวน'` | หัวคอลัมน์ค่าของตาราง |
| `showLegend` | `boolean` | `true` | ตรงกับ `show-legend` |
| `legendPlacement` | `'bottom'` หรือ `'end'` | `'bottom'` | ตรงกับ `legend-placement` `end` วางวงซ้าย legend ขวา วงสูงเท่า legend ไม่ต่ำกว่า 96 ความหนาวงเป็นสัดส่วนเดิมของ `size` |
| `showTableToggle` | `boolean` | `true` | ปุ่ม "ดูเป็นตาราง" |

### 4.4 Tokens

| Token | ค่า | ใช้ตรงไหน |
|---|---|---|
| `chart/color/series-1`, `series-2`, `series-2-border` | brand ตามโหมด | แท่งของ bar-chart และขอบแท่งสีอ่อน |
| `chart/color/grid`, `axis-text`, `line`, `point-fill`, `hover` | ชี้ไปตัวแปร semantic | เส้นกริด ป้ายแกน เส้น จุด แถบ hover |
| `chart/color/category-1` ถึง `8` | brand, orange, cyan, pink, brown, yellow, fuchsia, green | ชิ้นของ pie-chart ตามลำดับ ทุกสีผ่าน 3:1 ทั้งพื้นสว่างและพื้นมืด |
| `chart/color/category-other` | gray 500 | ชิ้น "อื่น ๆ" |
| `chart/color/dim` | ขาวโปร่ง 70% โหมดมืดเทาโปร่ง | ชั้นทับชิ้นที่ไม่ได้ชี้หรือโฟกัส |
| `chart/slice-gap` | 2px (`size/space/s1/xs`) | ช่องคั่นระหว่างชิ้น |
| `chart/pie/diameter/xs` ถึง `xl` | 96, 128, 160, 192, 224 | เส้นผ่านศูนย์กลางวง สูตร base 96 step 32 |
| `chart/pie/thickness/xs` ถึง `xl` | 16, 18, 20, 22, 24 | ความหนาวง สูตร base 16 step 2 |
| `chart/radius/top-left`, `top-right` | 2px | มุมบนของแท่ง |
| `chart/line-width`, `chart/point-size` | 2px, 8px | เส้นและจุดของชุดแบบเส้น |

ตารางเต็มพร้อมค่าโหมดมืดอยู่ในเอกสาร Chart Token หน้า 29 ระยะห่างทุกตัวอยู่ในเอกสาร Chart Space

## 5. ข้อควรระวังและปัญหาที่พบบ่อย (Constraints)

| # | ข้อควรระวัง | เหตุผล / วิธีปฏิบัติ |
|---|---|---|
| 1 | ห้ามใส่ข้อมูลที่ผู้ใช้ต้องใช้ไว้ในคำใบ้อย่างเดียว | จอสัมผัสไม่แสดงคำใบ้ เปิดปุ่มดูเป็นตารางไว้ ตารางแสดงตัวเลขเต็มครบทุกหมวด |
| 2 | bar-chart ไม่ควรมีเกินสองชุดแท่งกับหนึ่งชุดเส้น | ระบบมีสีแท่งแค่ series-1 กับ series-2 และสีเส้นสีเดียว |
| 3 | กราฟวงกลมใช้กับสัดส่วนของทั้งหมดเท่านั้น | ข้อมูลที่ไม่ได้รวมเป็นหนึ่งก้อน หรือเทียบตามเวลา ให้ใช้กราฟแท่ง |
| 4 | แสดงชื่อไม่เกิน 5 หมวดเป็นค่าตั้งต้น | สี 6 ถึง 8 แยกด้วยตาบอดสียากกว่า ผลจำลองอยู่ใน `docs/research/pie-chart.md` |
| 5 | สองวงที่เทียบกันต้องส่ง `categories` เดียวกัน | ถ้าแต่ละวงเลือกหมวดเอง "อื่น ๆ" จะรวมคนละชุดและเทียบกันไม่ได้ |
| 6 | ระบุ `color` เองอาจได้สีข้างกันที่ใกล้กัน | ลำดับสีตั้งต้นจัดให้สีข้างกันต่างกันมาก ระบุเองเมื่อจำเป็นต้องให้สีคงที่ต่อหมวดเท่านั้น |
| 7 | ห้ามวางกราฟวงกลมบนพื้นสีอื่น | ช่องคั่นกับรูกลางวงเป็นสีพื้นหลัก บนพื้นสีอื่นจะเห็นเป็นแผ่น |
| 8 | วงที่ตาเห็นบางและเล็กกว่าค่า token 2px | ช่องคั่นวาดเป็นเส้นขอบสีพื้นรอบทุกชิ้น ทั้ง Figma และโค้ดทำเหมือนกัน ภาพจึงตรงกัน |
| 9 | ป้ายกลางวงขนาด xs ต้องสั้น | ที่ว่างกลางวง xs กว้างแค่ 64 ป้ายเช่น "ข่าวทั้งหมด" ใส่ได้พอดี ยาวกว่านี้จะล้นรู |
| 10 | ระบบไม่มี token ความโปร่ง | ชิ้นจางใช้สีทับโปร่ง `chart/color/dim` จากชุด alpha แทน เพราะกติกาตั้งชื่อ token ไม่มีหมวด opacity |
| 11 | `show-tooltip` ไม่มีในโค้ด | เป็นภาพนิ่งของสถานะชี้ในไฟล์ออกแบบ ในโค้ดคำใบ้โผล่เมื่อชี้หรือโฟกัส มีใบเดียวที่ย้ายตามหมวดหรือชิ้น |
