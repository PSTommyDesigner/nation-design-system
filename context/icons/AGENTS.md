# icons/

Open this folder when adding an icon.

- [icon.dsds.yaml](icon.dsds.yaml): how to use Icon, the size trait, and what to do when an icon is missing
- [icon-names.md](icon-names.md): every Nation UI Icon name by category, and every Nation House icon name. Generated

## Rules
- MUST use `Icon` from `components/Icon` with a name from icon-names.md only
- MUST NOT draw your own SVG, take an icon from another set, or use a Material Icons name you saw in Figma
- MUST choose an icon by its meaning, not by how it looks
- MUST give an icon that carries meaning an accessible name (`title`)
