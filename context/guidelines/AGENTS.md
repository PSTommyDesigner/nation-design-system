# guidelines/

Open this folder when writing on-screen copy, or checking accessibility before handing off.

- [guidelines.dsds.yaml](guidelines.dsds.yaml)
  - entry `content`: language, dates, error messages and punctuation
  - shared `shared-a11y`: accessibility rules that every component links to with `same-as` (`focus-visible`, `text-contrast`, `color-not-only`, `icon-name`)

## Rules
- MUST write on-screen copy in Thai, with Buddhist Era years in dates
- MUST NOT use the em dash character. MUST NOT use the middle dot in on-screen copy or in the Figma file (in markdown docs, list lines only)
- MUST NOT change the `id` of a shared rule, because components link to that id
