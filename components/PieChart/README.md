# PieChart

กราฟวงกลมแบบโดนัท มียอดรวมกลางวง คำอธิบายสีใต้วง คำใบ้ต่อชิ้น และสลับเป็นตารางได้ ตรงกับ component `pie-chart` ในไฟล์ออกแบบหน้า **29 Chart** (node `12008:1686`) และชิ้นส่วนแถวคำอธิบายสี `_pie-chart-legend-item` (node `12007:1482`)

ที่มาของทุกการตัดสินใจอยู่ที่ `docs/research/pie-chart.md` หัวข้อ 10.1

- รูปชิ้นคำนวณเองด้วย SVG path ไม่มีไลบรารีกราฟ SVG ใช้ viewBox แบบหน่วยสัมพัทธ์แล้วยืดเต็มกล่องขนาด `--ntg-chart-pie-diameter-<size>` รูกลางวงกว้างตาม `--ntg-chart-pie-thickness-<size>` แก้ token แล้ววงเปลี่ยนตาม
- สีมาจาก `--ntg-chart-color-category-*` ช่องคั่นชิ้นคือ `--ntg-chart-slice-gap` ระยะทั้งหมดมาจาก `--ntg-size-space-*`
- ยอดรวมใช้ preset title ตามขนาด ป้ายและคำอธิบายสีใช้ preset meta/caption คำใบ้ใช้ `Tooltip` ขนาด sm ปุ่มสลับใช้ `Button` ตารางใช้ `Table` ของระบบ
- render บนเซิร์ฟเวอร์ได้ (Next 12/14) ไม่มีการวัดขนาดหลังติดตั้ง

## Usage

```tsx
import { PieChart } from '@/components/PieChart';

<PieChart
  summary="สัดส่วนข่าวตามหมวด 1,240 ข่าว เศรษฐกิจมากที่สุด 30%"
  totalLabel="ข่าวทั้งหมด"
  unit="ข่าว"
  data={[
    { label: 'เศรษฐกิจ', value: 372 },
    { label: 'การเมือง', value: 273 },
    { label: 'ธุรกิจ', value: 198 },
    { label: 'เทคโนโลยี', value: 149 },
    { label: 'ไลฟ์สไตล์', value: 99 },
    { label: 'กีฬา', value: 89 },
    { label: 'บันเทิง', value: 60 },
  ]}
/>
```

7 หมวดเกิน `maxSlices` (5) บวก 1 จึงแสดงชื่อ 5 หมวดที่มากที่สุด กีฬากับบันเทิงรวมเป็น "อื่น ๆ" สีเทาท้ายวง ชี้ชิ้นหรือกด Tab เข้าวงแล้วใช้ลูกศร ชิ้นนั้นสีเต็ม ชิ้นอื่นจาง และคำใบ้บอก ชื่อหมวด จำนวนเต็มพร้อมหน่วย และสัดส่วน

### สองวงคู่กัน

ส่ง `categories` รายการเดียวกันให้ทั้งสองวง ชิ้น ลำดับ และสีของแต่ละหมวดจึงตรงกัน หมวดนอกรายการรวมเป็น "อื่น ๆ" ชุดเดียวกัน รายการมาจากไหนเป็นกฎของแต่ละโปรเจกต์

```tsx
const shown = ['เศรษฐกิจ', 'การเมือง', 'ธุรกิจ', 'เทคโนโลยี', 'ไลฟ์สไตล์'];

<PieChart summary="จำนวนข่าวตามหมวด" data={news} categories={shown} unit="ข่าว" totalLabel="ข่าวทั้งหมด" />
<PieChart summary="ยอดวิวตามหมวด" data={views} categories={shown} unit="ครั้ง" totalLabel="ยอดวิวทั้งหมด" />
```

### legend ข้างวง

```tsx
<PieChart summary="สัดส่วนข่าวตามหมวด" data={news} unit="ข่าว" totalLabel="ข่าวทั้งหมด" legendPlacement="end" />
```

วงอยู่ซ้าย legend อยู่ขวา ห่าง 16 (`--ntg-size-space-s2-sm`) เส้นผ่านศูนย์กลางวงเท่าความสูงจริงของ legend เสมอ (วงยืดตามจำนวนแถว) แต่ไม่ต่ำกว่า `--ntg-chart-pie-diameter-xs` (96) ถ้า legend เตี้ยกว่านั้น legend จัดกลางแนวตั้งข้างวง ความหนาวงเป็นสัดส่วนเดิมของ `size` ที่เลือก (md คือ 20 ต่อ 160) ช่องคั่นยังหนา 2 ตัวเลขกลางวงยังใช้ preset title ตาม `size` ปิด legend แล้ววงกลับไปใช้ขนาดตาม `size` สองวงที่ส่ง `categories` เดียวกันมีจำนวนแถวเท่ากัน จึงสูงเท่ากัน

### ระบุสีเอง

```tsx
<PieChart
  summary="สถานะข่าว"
  data={[
    { label: 'เผยแพร่แล้ว', value: 820, color: 8 },
    { label: 'รอตรวจ', value: 260, color: 6 },
    { label: 'ตีกลับ', value: 110, color: 4 },
  ]}
/>
```

> ⚠️ **ระบุสีเองแล้วสีที่อยู่ข้างกันอาจใกล้กันจนแยกยาก** ลำดับตั้งต้น category-1 ถึง 8 เรียงมาให้สีที่อยู่ติดกันต่างกันแล้ว และสี 6 ถึง 8 แยกด้วยตาบอดสียากกว่า 1 ถึง 5 ถ้าระบุเอง ให้ดูภาพจริงก่อนใช้ทุกครั้ง `color` รับเฉพาะเลข 1 ถึง 8 หรือ `'other'` ไม่รับค่าสีดิบ

## Props

| Prop | ชนิด | ค่าเริ่มต้น | Figma | คำอธิบาย |
|---|---|---|---|---|
| `data` | `PieChartDatum[]` | (บังคับ) | | ข้อมูลทุกหมวด ลำดับใน array ไม่มีผล |
| `summary` | `string` | (บังคับ) | | สรุปใจความของกราฟเป็นประโยค เป็นชื่อของกราฟ (figcaption ที่ซ่อนไว้) และ caption ของตาราง |
| `size` | `'xs' \| 'sm' \| 'md' \| 'lg' \| 'xl'` | `'md'` | `size` | เส้นผ่านศูนย์กลาง 96, 128, 160, 192, 224 ความหนาวง 16, 18, 20, 22, 24 ยอดรวมใช้ preset title-xs ถึง title-xl |
| `maxSlices` | `number` | `5` | | จำนวนหมวดที่แสดงชื่อเมื่อไม่ส่ง `categories` มีหมวดไม่เกิน `maxSlices` บวก 1 แสดงครบ เกินกว่านั้นที่เหลือรวมเป็น "อื่น ๆ" |
| `categories` | `string[]` | | | รายการหมวดที่แสดงชื่อ เรียงตามลำดับนี้ หมวดนอกรายการรวมเป็น "อื่น ๆ" ส่งแล้วไม่ใช้ `maxSlices` หมวดในรายการที่ไม่มีข้อมูลแสดงในคำอธิบายสีเป็น 0% แต่ไม่มีชิ้น |
| `otherLabel` | `string` | `'อื่น ๆ'` | | ชื่อของชิ้นที่รวมหมวดที่เหลือ |
| `total` | `number \| string` | ผลรวมของ `data` | `total` | ยอดกลางวง ตัวเลขจัดรูปด้วย `Intl.NumberFormat('th-TH')` ข้อความแสดงตามที่ส่ง สัดส่วน % คิดจากผลรวมของ `data` เสมอ |
| `totalLabel` | `string` | | `total-label` | ป้ายใต้ยอดกลางวง เช่น "ข่าวทั้งหมด" ไม่ส่งคือไม่มีป้าย |
| `unit` | `string` | | | หน่วยต่อท้ายจำนวนในคำใบ้ ชื่อของชิ้น และหัวคอลัมน์ของตาราง |
| `categoryLabel` | `string` | `'หมวด'` | | หัวคอลัมน์ชื่อหมวดของตาราง |
| `valueLabel` | `string` | `'จำนวน'` | | หัวคอลัมน์ค่าของตาราง ต่อท้ายด้วยหน่วยในวงเล็บถ้ามี `unit` |
| `showLegend` | `boolean` | `true` | `show-legend` | แสดงคำอธิบายสี แถวละหมวด จุดสี ชื่อหมวด สัดส่วน |
| `legendPlacement` | `'bottom' \| 'end'` | `'bottom'` | `legend-placement` | `bottom` legend ใต้วง `end` วงซ้าย legend ขวา วงสูงเท่า legend (ไม่ต่ำกว่า 96) ความหนาวงเป็นสัดส่วนเดิมของ `size` |
| `showTableToggle` | `boolean` | `true` | | แสดงปุ่ม "ดูเป็นตาราง" / "ดูเป็นกราฟ" (`Button` neutral secondary sm มี `aria-pressed`) ใต้กราฟ กดแล้วกราฟถูกแทนด้วยตาราง `Table` |

`PieChartDatum`

| ฟิลด์ | ชนิด | คำอธิบาย |
|---|---|---|
| `label` | `string` | ชื่อหมวด ใช้จับคู่กับ `categories` ชื่อซ้ำถูกรวมค่ากัน |
| `value` | `number` | ค่าของหมวด ค่าติดลบปัดเป็น 0 |
| `color` | `1 \| 2 \| ... \| 8 \| 'other'` | ระบุสีของหมวดนี้เอง ไม่ส่งคือสีตามลำดับชิ้น ใช้กับหมวดที่แสดงชื่อเท่านั้น |

property `show-tooltip` ใน Figma เป็นภาพตัวอย่างสถานะ hover เท่านั้น ไม่มี prop ฝั่งโค้ดคำใบ้โผล่เองเมื่อชี้หรือโฟกัสชิ้น

ไฟล์ยังส่งออก `pieChartSlices(data, { maxSlices, categories, otherLabel })` ฟังก์ชันล้วนที่คืนชิ้นของวงหลังจัดกลุ่ม ผลรวม และแถวของตาราง ใช้ทำข้อความ `summary` หรือทดสอบได้

## กติกา

- **ลำดับชิ้น** เริ่ม 12 นาฬิกา เดินตามเข็ม มากไปน้อย (หรือตาม `categories`) ชิ้น "อื่น ๆ" อยู่ท้ายสุดเสมอ ชิ้นไม่มีมุมโค้ง
- **สี** ชิ้นที่ 1 คือ `--ntg-chart-color-category-1` ไล่ไปถึง 8 เกิน 8 วนกลับไป 1 ชิ้น "อื่น ๆ" คือ `--ntg-chart-color-category-other`
- **ช่องคั่น** ขอบกลางเส้นรอบทุกชิ้น สี `--ntg-color-background-general-primary` หนา `--ntg-chart-slice-gap` (2) แบบเดียวกับไฟล์ออกแบบ ขอบนอกและขอบในของวงจึงบางลงฝั่งละ 1 ช่องคั่นกับรูกลางวงเป็นสีพื้นหลักของหน้า จึงควรวางกราฟบนพื้นหลักเท่านั้น
- **ยอดกลางวง** ตัวเลขสี `--ntg-color-text-general-heading` preset title ตามขนาด ป้ายสี `--ntg-chart-color-axis-text` preset meta/caption
- **คำอธิบายสี** ใต้วงห่าง 16 (`--ntg-size-space-s2-sm`) แถวละหมวด ห่างกัน 8 (`--ntg-size-space-s1-lg`) จุดสี 12 (`--ntg-size-space-s2-xs`) ห่างจากข้อความ 8 ชื่อหมวดสี axis-text ค่า % สี heading ตัวอักษร meta/caption ชี้แถวแล้วชิ้นนั้นเด่น ชิ้นอื่นจางเหมือนชี้ที่ชิ้น `legendPlacement="end"` ย้าย legend ไปขวาของวง ห่าง 16 เท่ากัน
- **วงยืดตาม legend** (`end`) ความสูง legend รอบเซิร์ฟเวอร์ประมาณจากจำนวนแถว ความสูงบรรทัดของ meta/caption และช่องระหว่างแถว หลังติดตั้งวัดความสูงจริงด้วย ResizeObserver (ชื่อหมวดยาวจนขึ้นบรรทัดใหม่ก็ตามทัน) ความหนาคิดใน CSS ด้วย `tan(atan2(thickness, diameter))` เบราว์เซอร์เก่าที่ไม่รองรับ (ก่อน Chrome 111, Safari 15.4, Firefox 108) ใช้ความหนาตาม token ของ `size` แทน
- **เน้นตอนชี้** ชิ้นที่ชี้หรือโฟกัสสีเต็ม ชิ้นอื่นมีชั้นทับสี `--ntg-chart-color-dim` รอบนี้ยังไม่มีการกดชิ้น
- **คำใบ้** `Tooltip` ขนาด sm ใบเดียวทั้งกราฟ วางที่ขอบนอกตรงกลางของชิ้นที่ชี้ ชี้ออกจากวง (บน ขวา ล่าง หรือซ้ายตามมุมของชิ้น) หัวคือชื่อหมวด ตามด้วยจำนวนเต็มพร้อมหน่วยและสัดส่วน ชิ้น "อื่น ๆ" บอกด้วยว่ารวมหมวดอะไร
- **การเข้าถึง** `<figure>` ได้ชื่อจาก `summary` วงเป็น `role="group"` ที่มีจุดหยุด Tab จุดเดียว ลูกศรขวาหรือลงไปชิ้นถัดไป ซ้ายหรือขึ้นย้อนกลับ Home กับ End ไปชิ้นแรกกับชิ้นสุดท้าย Escape ปิดคำใบ้ แต่ละชิ้นมีชื่อบอกข้อมูลครบ เช่น "เศรษฐกิจ 372 ข่าว 30%" คำใบ้จึงตั้ง `relationship="inaccessible"` โฟกัสจากคีย์บอร์ดแสดงวงแหวน `--ntg-focused-ring-brand` รอบวงและชิ้นอื่นจาง ข้าง ๆ มี `<table>` จริงที่ซ่อนจากสายตา แสดงครบทุกหมวด (ไม่รวมเป็น "อื่น ๆ")
- **ข้อยกเว้นจากสเปค Tooltip** ตัวเลขเต็มในคำใบ้ยังอ่านได้จากตารางที่สลับด้วยปุ่มและจากตารางที่ซ่อนไว้ คำใบ้จึงเป็นทางลัด ไม่ใช่ทางเดียว
- **ไม่มีข้อมูล** ผลรวมเป็น 0 วาดวงว่างสี `--ntg-chart-color-grid`
- ห้ามแต่งสี ระยะ หรือขนาดจากข้างนอกด้วย `className` หรือ `style`
