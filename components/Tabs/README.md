# Tabs

แท็บสลับเนื้อหาภายในหน้าเดียว ตรงกับไฟล์ออกแบบหน้า **18 Tabs**

ตัวเดียวทำได้ทั้งสองทรง โดยเลือกจาก `shape`

| ค่าที่ส่งเข้าไป | ได้อะไร | ชุดในไฟล์ออกแบบ |
|---|---|---|
| `shape="underline"` (ค่าเริ่มต้น) | ขีดเส้นใต้ ใช้กับการสลับเนื้อหาหลักของหน้า | `underline-tab` กับ `underline-tab-group` |
| `shape="segmented"` | กล่องติดกันเป็นแถบ ใช้กับชุดตัวเลือกสั้นในกล่องหรือแผงตั้งค่า | `segmented-tab` กับ `segmented-tab-group` |

ฝั่งไฟล์ออกแบบแยกเป็นสองชุดเพราะแผง Assets เห็นแค่ชื่อ แต่โครงเหมือนกันทุกอย่าง จึงรวมเป็นตัวเดียวในโค้ด

## Usage

```tsx
import { Tabs } from '@/components/Tabs';

<Tabs
  label="หมวดข่าว"
  value={tab}
  onValueChange={setTab}
  items={[
    { id: 'latest', label: 'ล่าสุด', panel: <LatestNews /> },
    { id: 'popular', label: 'ยอดนิยม', icon: 'trending-up', panel: <PopularNews /> },
    { id: 'saved', label: 'ที่บันทึกไว้', unread: true, panel: <SavedNews /> },
    { id: 'draft', label: 'ฉบับร่าง', disabled: true, panel: <Draft /> },
  ]}
/>

<Tabs
  shape="segmented"
  size="sm"
  label="มุมมอง"
  value={view}
  onValueChange={setView}
  items={[
    { id: 'grid', icon: 'grid-view', iconOnly: true, ariaLabel: 'มุมมองตาราง' },
    { id: 'list', icon: 'list-view', iconOnly: true, ariaLabel: 'มุมมองรายการ' },
  ]}
/>
```

## Props

| prop | ค่าเริ่มต้น | หน้าที่ |
|---|---|---|
| `items` | จำเป็น | รายการแท็บ ดูตารางถัดไป |
| `value` | จำเป็น | คีย์ของแท็บปัจจุบัน ตรงกับแกน `current` |
| `onValueChange` | | คืนคีย์ของแท็บที่ผู้ใช้สั่งเปิด |
| `shape` | `underline` | `segmented` หรือ `underline` |
| `size` | `md` | `xs` ถึง `xl` |
| `label` | | ชื่อของแถบแท็บที่โปรแกรมอ่านหน้าจอจะอ่าน |
| `labelledBy` | | id ของหัวข้อที่ทำหน้าที่เป็นชื่อแถบแท็บ ใช้แทน `label` ได้ |

รายการแท็บหนึ่งอัน

| ฟิลด์ | หน้าที่ |
|---|---|
| `id` | คีย์ของแท็บ ใช้เทียบกับ `value` และใช้ประกอบ id ของแท็บกับแผงเนื้อหา |
| `label` | ข้อความบนแท็บ ตรงกับคุณสมบัติ `text` |
| `icon` | ไอคอนนำหน้า รับชื่อไอคอนของ DS (`IconName`) ไม่รับ element ที่วาดเอง |
| `unread` | จุดแจ้งเตือนนำหน้า บอกว่ามีของใหม่ยังไม่ได้อ่าน |
| `iconOnly` | ไอคอนอย่างเดียว ต้องส่ง `ariaLabel` คู่กัน |
| `ariaLabel` | ชื่อที่โปรแกรมอ่านหน้าจอจะอ่าน |
| `disabled` | ปิดใช้งาน ประกาศด้วย `aria-disabled` และลูกศรจะข้ามไป |
| `panel` | เนื้อหาของแผงที่แท็บนี้คุม ไม่ส่งก็ได้ถ้าแผงอยู่ที่อื่น |

## ไอคอน 4 แบบ

แกน `icon` ของไฟล์ออกแบบมี 4 ค่า โค้ดคำนวณให้เองจากฟิลด์ที่ส่งมา (`tabIconKind` ส่งออกไว้ให้เทียบในเทสต์ได้)

| ส่งอะไร | ได้แบบไหน | ค่าในไฟล์ออกแบบ |
|---|---|---|
| `label` เท่านั้น | ไม่มีไอคอน | `icon=false` |
| `label` กับ `icon` | ไอคอนนำหน้า | `icon=leading` |
| `label` กับ `unread` | จุดแจ้งเตือนนำหน้า | `icon=unread` |
| `icon` กับ `iconOnly` | ไอคอนอย่างเดียว | `icon=only` |

## current คนละเรื่องกับ state

| แกน | คืออะไร | ประกาศด้วย |
|---|---|---|
| `current` | แท็บที่เปิดค้างอยู่ | `aria-selected` มาจาก `value` |
| `state` | สถานะของตัวแท็บ ณ ขณะนั้น คือ default, hover, focused, disabled | CSS pseudo-class กับ `aria-disabled` |

สองอย่างนี้ซ้อนกันได้ แท็บปัจจุบันที่กำลังถูกชี้ก็มีทั้ง `current` และ hover **ห้ามใช้ `state=focused` แทนแท็บปัจจุบัน** ของเดิมในไฟล์เคยทำแบบนี้และแก้แล้วเมื่อ 2026-09-29

## แป้นพิมพ์

ตามมาตรฐาน WAI-ARIA Authoring Practices แบบ **manual activation**

| ปุ่ม | ผล |
|---|---|
| ลูกศรขวา | ย้ายโฟกัสไปแท็บถัดไป วนรอบเมื่อถึงตัวสุดท้าย |
| ลูกศรซ้าย | ย้ายโฟกัสไปแท็บก่อนหน้า วนรอบเมื่อถึงตัวแรก |
| Home และ End | ไปแท็บแรกหรือแท็บสุดท้าย |
| Enter หรือ Space | สลับเนื้อหาไปที่แท็บที่โฟกัสอยู่ |

**ลูกศรย้ายโฟกัสอย่างเดียว ไม่สลับเนื้อหา** ตั้งค่านี้เพราะแท็บเว็บข่าวดึงข้อมูลชุดใหม่ทุกครั้งที่สลับ ถ้าสลับอัตโนมัติ การเดินลูกศรผ่าน 10 หมวดจะยิง 10 คำขอ

**แท็บเดียวที่อยู่ในลำดับ Tab ของหน้าคือแท็บปัจจุบัน** แท็บอื่นได้ `tabindex="-1"` (roving tabindex) ไม่งั้นผู้ใช้แป้นพิมพ์ต้องกด Tab ผ่านทุกแท็บกว่าจะถึงเนื้อหา ส่วนแผงเนื้อหารับโฟกัสได้ด้วย `tabindex="0"` ตามที่ APG แนะนำ

ลูกศรข้ามแท็บที่ `disabled` เพราะแท็บที่กดไม่ได้ไม่ควรกินจังหวะการเดิน แต่ยังอยู่ในหน้าและยังประกาศ `aria-disabled` ให้โปรแกรมอ่านหน้าจอรู้ว่ามีอยู่

## พื้นที่แตะ

**พื้นที่แตะไม่ผ่านเกณฑ์ 44 แม้ขนาด `md`** (md สูง 40) จึงซ้อนชั้นมองไม่เห็นที่ `min-height: 44px` ด้วย `::before` **เฉพาะ `@media (pointer: coarse)`**

**ห้ามยืดความสูงของตัวแท็บเอง** เพราะจะไปทับแผงเนื้อหาด้านล่างหรือหัวข้อด้านบน ความสูงของตัวแท็บต้องคงอยู่ที่สเกลความสูงตัวควบคุมกลาง (24, 32, 40, 48, 56) เพื่อให้วางแถวเดียวกับปุ่มและช่องกรอกได้พอดี วิธีนี้เป็นวิธีเดียวกับที่ Primer ใช้กับ SegmentedControl

> 44 เป็นค่าคงที่ของเกณฑ์ WCAG 2.5.5 ไม่ใช่ค่าของระบบออกแบบ `tokens/scale/tabs.mjs` เขียนกำกับไว้ว่าไม่มี token ของเรื่องนี้ ในไฟล์ CSS จึงประกาศเป็น `--tab-touch-target` ไว้ที่เดียวแล้วอ้างจากตรงนั้น

## เส้นสองเส้นห้ามใช้ความหนาตัวเดียวกัน

| เส้น | token | ค่า | ใช้กับ |
|---|---|---|---|
| ขีดใต้แท็บปัจจุบัน | `--ntg-tab-indicator` | 2 | แท็บที่ `aria-selected="true"` |
| เส้นรางของแท็บอื่น | `--ntg-tab-rail` | 1 | แท็บที่ไม่ใช่แท็บปัจจุบัน และเส้นขอบกล่องครอบทรงกล่อง |

ถ้ารวมเป็นตัวเดียว พอทำตัวชี้หนาขึ้นเป็น 2 เส้นรางจะหนาตามไปด้วย ซึ่งไม่ใช่สิ่งที่ตั้งใจ

ทั้งสองเส้นวาดด้วย `::after` ที่ลอยอยู่ก้นกล่อง ไม่ใช่ `border-bottom` เพราะ border 1 เทียบ 2 จะดันเนื้อหาขึ้นลง 1px ตอนสลับแท็บ

## วงแหวนโฟกัสยิงเข้าด้านใน

สีและความหนายังเป็นชุดเดียวกับ effect style `focused-ring/default` ทุกค่า แต่วาดเป็น `inset` ไม่ใช่ยิงออกนอก เพราะ

- **แถบแท็บเลื่อนแนวนอนได้** จึงเป็นกรอบตัด วงแหวนที่ยิงออกนอกจะถูกตัดหายทั้งเส้น
- **ทรงกล่องเรียงติดกัน** วงแหวนที่ยิงออกนอกจะทับช่องข้างเคียง เป็นปัญหาเดียวกับที่ Primer แก้ด้วย `outline-offset` ติดลบ

เรื่องนี้งานวิจัยหัวข้อการเข้าถึงระบุไว้ว่าต้องตัดสินก่อนผูก effect style **ถ้าฝ่ายออกแบบอยากให้ยิงออกนอก ต้องเลิกให้แถบเลื่อนแนวนอนก่อน**

## ข้อควรระวัง

- **ห้ามใช้แท็บแทนตัวกรอง** ถ้าทุกแท็บแสดงข้อมูลชุดเดียวกันแค่กรองให้แคบลง ให้ใช้ตัวกรอง เพราะโปรแกรมอ่านหน้าจอจะประกาศว่าเป็นแผงเนื้อหาคนละแผง ซึ่งไม่จริง เหตุผลเต็มอยู่ในเอกสาร `Tab Usage` หน้า 18
- **ทรงกล่องที่ใช้เป็นตัวกรอง ไม่ใช่งานของตัวนี้** ตัวนี้ประกาศ `role="tab"` กับ `role="tabpanel"` ตายตัว ถ้าต้องการกล่องที่เปลี่ยนมุมมองของเนื้อหาชุดเดิม ต้องใช้ `aria-pressed` หรือ `radiogroup` ซึ่งเป็น component คนละตัว
- **ไอคอนอย่างเดียวต้องมี `ariaLabel`** ตัว component เตือนให้ตอนพัฒนาถ้าลืม และควรมี tooltip กำกับด้วยเพราะไอคอนลอยเดาความหมายไม่ออก
- **จุดแจ้งเตือนห้ามสื่อความหมายด้วยสีอย่างเดียว** ต้องมีข้อความกำกับด้วยเสมอตาม WCAG 1.4.1 จุดนี้ถูกตั้ง `aria-hidden` ไว้ เพราะเป็นภาพประกอบไม่ใช่ข้อมูล
- **ขนาด `xs` ห้ามใช้บนมือถือ** ตัวอักษรเหลือ 10px และกล่องสูง 24 ต่ำกว่าเกณฑ์พื้นที่แตะมาก ใช้เฉพาะแผงตั้งค่าที่หนาแน่นบนเดสก์ท็อป
- **ห้ามตรึงความกว้างแท็บ** ความกว้างมาจากเนื้อหา ไม่มี prop ความกว้างโดยตั้งใจ
- **ห้ามทำตัวอักษรหนาขึ้นตอนเป็นแท็บปัจจุบัน** ความกว้างจะขยับแล้วแท็บทั้งแถวเลื่อน ตอนนี้ใช้สีคู่กับขีดเส้นใต้เป็นสองสัญญาณซึ่งผ่านเกณฑ์อยู่แล้ว
- **สีไอคอนคงที่ทุกสถานะ** ไฟล์ออกแบบผูก `icon/general/quaternary` ไว้ตัวเดียวทั้ง default, hover และ disabled ไม่เปลี่ยนตามสถานะเหมือนข้อความ โค้ดทำตามไฟล์

## ยังไม่มีในรุ่นนี้

- **สถานะกด (pressed)** ทั้งไฟล์ออกแบบยังไม่มีชุดย่อยสถานะกดเลยสักหน้า ตามที่ตัดสินไว้เมื่อ 2026-09-24
- **แท็บแนวตั้ง** ถ้าต้องการต้องออกแบบใหม่ ไม่ใช่เอาแบบแนวนอนมาหมุน
- **ปุ่มลูกศรซ้ายขวาตอนแท็บล้น** รุ่นนี้ให้เลื่อนแนวนอนอย่างเดียว งานวิจัยเสนอให้ปุ่มลูกศรเป็นของเดสก์ท็อปที่ซ่อนได้ ซึ่งเป็นงานชั้นถัดไป
