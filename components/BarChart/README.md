# BarChart

กราฟแท่งแนวตั้งแบบจัดกลุ่ม (grouped bar) มีแกน y ได้สองข้าง ผสมเส้นได้หนึ่งชุด มีแถบ hover กับคำใบ้ต่อหมวด และสลับเป็นตารางได้ ตรงกับ component `bar-chart` ในไฟล์ออกแบบหน้า **29 Chart** (node `11797:2`) และชิ้นส่วนแท่ง `_bar-chart-bar` (node `11796:5`)

ที่มาของทุกการตัดสินใจอยู่ที่ `docs/research/chart-component.md` หัวข้อ 9

- แท่งกับจุดวาดเองด้วย HTML กับ CSS Modules เส้นเป็น SVG ที่ไม่มี viewBox (หน่วยเท่าพิกเซลจริง ความหนาไม่ถูกยืด) ไม่มีไลบรารีกราฟ
- สีมาจาก `--ntg-chart-color-*` มุมโค้งแท่งมาจาก `--ntg-chart-radius-top-left` กับ `--ntg-chart-radius-top-right` เส้นและจุดมาจาก `--ntg-chart-line-width` กับ `--ntg-chart-point-size` ระยะทั้งหมดมาจาก `--ntg-size-space-*`
- ตัวอักษรทุกจุดใช้ preset meta/caption คำใบ้ใช้ `Tooltip` ขนาด sm ปุ่มสลับใช้ `Button` ตารางใช้ `Table` ของระบบ
- render บนเซิร์ฟเวอร์ได้ (Next 12/14) รอบแรกแสดงแท่ง จุด และป้ายแกน x ครบ เส้นโผล่หลังติดตั้งแล้ววัดตำแหน่งจุดได้ ความกว้างจริงวัดด้วย ResizeObserver

## Usage

```tsx
import { BarChart } from '@/components/BarChart';

<BarChart
  summary="ข่าวที่สร้างและการเข้าชมรายวัน 31 วัน การเข้าชมสูงสุดวันที่ 21"
  categoryLabel="วันที่"
  categories={days}
  series={[
    { label: 'ข่าวที่สร้าง', values: news, axis: 'right', unit: 'ข่าว' },
    { label: 'การเข้าชม', values: views, axis: 'left', type: 'line', unit: 'ครั้ง' },
  ]}
/>
```

ชี้ที่หมวดใดก็ได้ (เต็มความสูงกราฟ) หรือกด Tab เข้ากราฟแล้วใช้ลูกศร จะเห็นแถบ hover กับคำใบ้ เช่น หัว "วันที่ 10" ตามด้วย "ข่าวที่สร้าง 28 ข่าว" และ "การเข้าชม 126,353 ครั้ง"

### แท่งสองชุด

ไม่ส่ง `type` คือแท่ง ชุดแท่งสองชุดอยู่ในช่องเดียว ห่างกัน 4

```tsx
<BarChart
  summary="ข่าวที่สร้างและการเข้าชมรายวัน"
  categoryLabel="วันที่"
  categories={days}
  series={[
    { label: 'ข่าวที่สร้าง', values: news, axis: 'right', unit: 'ข่าว' },
    { label: 'การเข้าชม', values: views, axis: 'left', unit: 'ครั้ง' },
  ]}
/>
```

### แกนเดียว

ทุกชุดอยู่แกนซ้าย แกนขวาปิดเองโดยอัตโนมัติ (หรือส่ง `showRightAxis={false}`)

```tsx
<BarChart
  summary="ข่าวที่สร้างและข่าวที่เผยแพร่รายวัน"
  categories={days}
  series={[
    { label: 'ข่าวที่สร้าง', values: created },
    { label: 'ข่าวที่เผยแพร่', values: published },
  ]}
/>
```

### จัดรูปตัวเลขบนแกนเอง

```tsx
<BarChart
  {...props}
  formatValue={{ left: (v) => `${v / 1000} พัน` }}
/>
```

## Props

| Prop | ชนิด | ค่าเริ่มต้น | Figma | คำอธิบาย |
|---|---|---|---|---|
| `summary` | `string` | (บังคับ) | | สรุปใจความของกราฟเป็นประโยค ไปเป็น `aria-label` ของกราฟและ caption ของตารางที่ซ่อนไว้ |
| `categories` | `string[]` | (บังคับ) | | ป้ายแกน x หนึ่งป้ายต่อหนึ่งหมวด |
| `series` | `BarChartSeries[]` | (บังคับ) | | ชุดข้อมูล ชุดแท่งได้ 2 ชุด (ตามลำดับ ชุดแรกสีเข้ม series-1 ชุดที่สองสีอ่อนมีขอบ series-2) กับชุดเส้น 1 ชุด (สี line) |
| `categoryLabel` | `string` | `'รายการ'` | | ชื่อแกน x นำหน้าป้ายในคำใบ้และชื่อช่อง (เช่น "วันที่ 10") และเป็นหัวคอลัมน์แรกของตาราง |
| `showLegend` | `boolean` | `true` | `show-legend` | แสดงคำอธิบายสีด้านบน ซ้ายคือชุดของแกนซ้าย ขวาคือชุดของแกนขวา |
| `showRightAxis` | `boolean` | มีชุดที่ `axis: 'right'` | `show-right-axis` | แสดงป้ายแกน y ด้านขวาและชื่อแกนขวา |
| `showTableToggle` | `boolean` | `true` | | แสดงปุ่ม "ดูเป็นตาราง" / "ดูเป็นกราฟ" (`Button` neutral secondary sm มี `aria-pressed`) ท้ายแถวคำอธิบายสี กดแล้วกราฟถูกแทนด้วยตาราง `Table` |
| `formatValue` | `{ left?, right? }` | `Intl.NumberFormat('th-TH', { notation: 'compact' })` | | จัดรูปตัวเลขบนแกน y แยกต่อข้าง คำใบ้และตารางใช้ตัวเลขเต็มเสมอ |
| `height` | `number` | `340` | | ความสูงของพื้นที่กราฟเป็นพิกเซล เป็นค่าผังของหน้า ไม่ใช่ token |

`BarChartSeries`

| ฟิลด์ | ชนิด | คำอธิบาย |
|---|---|---|
| `label` | `string` | ชื่อชุด แสดงในคำอธิบายสีและเป็นหัวคอลัมน์ของตาราง |
| `values` | `number[]` | ค่าของแต่ละหมวด เรียงตรงกับ `categories` ค่าติดลบปัดเป็น 0 |
| `axis` | `'left' \| 'right'` | แกนที่ใช้วัด ค่าเริ่มต้น `left` ชุดเส้นก็ใช้แกนของตัวเอง |
| `type` | `'bar' \| 'line'` | วาดเป็นแท่งหรือเส้น ค่าเริ่มต้น `bar` ชุดแท่งเท่านั้นที่กินที่ในช่อง ชุดเส้นวาดทับ |
| `unit` | `string` | หน่วยต่อท้ายตัวเลขในคำใบ้ (`28 ข่าว`) และในหัวคอลัมน์ของตาราง (`ข่าวที่สร้าง (ข่าว)`) |

property `show-tooltip` ใน Figma เป็นภาพตัวอย่างสถานะ hover เท่านั้น ไม่มี prop ฝั่งโค้ดคำใบ้โผล่เองเมื่อชี้หรือโฟกัสหมวด

## กติกา

- **แกน y** 4 ช่อง 5 เส้นเสมอ เท่ากันทั้งสองแกน เส้นกริดจึงตรงกัน ขั้นปัดขึ้นจากชุด 1, 1.5, 2, 2.5, 3, 4, 5, 6, 8 คูณสิบยกกำลัง เริ่มที่ 0 เสมอ ตัวอย่าง One CMS ได้ 0 ถึง 240K และ 0 ถึง 80
- **ช่องของหมวด** กว้าง 28 (`--ntg-size-space-s2-xl`) แท่งอยู่กลางช่อง ชุดแท่งชุดเดียวได้แท่ง 12 กลางช่อง สองชุดได้ 12 + 4 + 12
- **เส้น** สี `--ntg-chart-color-line` หนา `--ntg-chart-line-width` มุมต่อและปลายมน ลากผ่านจุดกลางช่องของทุกหมวด จุดเป็นวงกลม `--ntg-chart-point-size` พื้น `--ntg-chart-color-point-fill` ขอบสีเส้น อยู่บนแท่งและเส้น คำอธิบายสีของชุดเส้นเป็น เส้นสั้น จุด เส้นสั้น (4 + 8 + 4)
- **สี** ชุดแท่ง 2 ชุดกับชุดเส้น 1 ชุด ส่งเกินจะเตือนในโหมดพัฒนาและไม่วาดชุดที่เกิน ห้ามเติมสีเอง ให้ขอ token ก่อน
- **แถบ hover และคำใบ้** ชี้ตรงไหนก็ได้ในช่องเต็มความสูง หรือโฟกัสด้วยคีย์บอร์ด จะเห็นแถบกว้าง 40 (`--ntg-size-space-s3-sm`) สี `--ntg-chart-color-hover` ใต้แท่งและเส้น กับ `Tooltip` ขนาด sm เหนือยอดที่สูงที่สุดของหมวดนั้น (ยอดแท่งหรือจุด) หมวดที่ชิดขอบจนคำใบ้จะล้นออกนอกกราฟ ใช้ `top-start` หรือ `top-end` แทน `top`
- **ความกว้าง** ยืดเต็มกรอบแม่เสมอ ไม่มี prop ความกว้าง
- **จอแคบ** ช่องต่อกลุ่มตั้งแต่ 24 พิกเซลแสดงป้ายแกน x ทุกตัว แคบกว่านั้นแสดงเฉพาะ 1, 5, 10, 15, 20, 25, 30 ต่ำกว่า 14 พื้นที่กราฟเลื่อนแนวนอนได้ แกน y สองข้างตรึงอยู่กับที่
- **การเข้าถึง** `<figure>` ได้ชื่อจาก `summary` (figcaption ที่ซ่อนจากสายตา) พื้นที่กราฟเป็น `role="group"` ที่มีจุดหยุด Tab จุดเดียว ลูกศรซ้ายขวาเลื่อนทีละหมวด Home กับ End ไปหมวดแรกกับหมวดสุดท้าย Escape ปิดคำใบ้ แต่ละช่องมีชื่อบอกข้อมูลครบ เช่น "วันที่ 10 ข่าวที่สร้าง 28 ข่าว การเข้าชม 126,353 ครั้ง" คำใบ้จึงตั้ง `relationship="inaccessible"` ไม่ให้ฟังซ้ำ วงแหวนโฟกัสคือ `--ntg-focused-ring-brand` รอบแถบ hover ข้าง ๆ มี `<table>` จริงที่ซ่อนจากสายตา และปุ่มสลับเป็นตารางที่มองเห็น ไม่มีแอนิเมชันนอกจากของ `Tooltip`
- **ข้อยกเว้นจากสเปค Tooltip** สเปคห้ามใส่ข้อมูลจำเป็นในคำใบ้ เพราะจอสัมผัสไม่เห็นคำใบ้ ตัวเลขเต็มในคำใบ้ของกราฟนี้ยังอ่านได้จากตารางที่สลับด้วยปุ่ม และจากตารางที่ซ่อนไว้ คำใบ้จึงเป็นทางลัด ไม่ใช่ทางเดียว
- ห้ามแต่งสี ระยะ หรือมุมโค้งจากข้างนอกด้วย `className` หรือ `style`

## ยังไม่มีในรอบนี้

- ชุดแท่งที่ 3 ขึ้นไป และชุดเส้นที่ 2 ขึ้นไป (ยังไม่มี token สี)
- คำใบ้แสดงชุดข้อมูลเป็นบรรทัดละชุด (ส่งไปคั่นด้วยขึ้นบรรทัดใหม่แล้ว แต่ `Tooltip` ยังรวมเป็นย่อหน้าเดียว)
- คำใบ้ในโหมดเลื่อนแนวนอน (ช่องต่ำกว่า 14 พิกเซล) อาจถูกกล่องที่เลื่อนได้ตัดขอบบน
