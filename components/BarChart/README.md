# BarChart

กราฟแท่งแนวตั้งแบบจัดกลุ่ม (grouped bar) มีแกน y ได้สองข้าง ตรงกับ component `bar-chart` ในไฟล์ออกแบบหน้า **29 Chart** (node `11797:2`) และชิ้นส่วนแท่ง `_bar-chart-bar` (node `11796:5`)

ที่มาของทุกการตัดสินใจอยู่ที่ `docs/research/chart-component.md` หัวข้อ 9

- วาดเองด้วย HTML กับ CSS Modules ไม่มีไลบรารีกราฟ
- สีมาจาก `--ntg-chart-color-*` มุมโค้งแท่งมาจาก `--ntg-chart-radius-top-left` กับ `--ntg-chart-radius-top-right` ระยะทั้งหมดมาจาก `--ntg-size-space-*`
- ตัวอักษรทุกจุดใช้ preset meta/caption
- render บนเซิร์ฟเวอร์ได้ (Next 12/14) รอบแรกแสดงป้ายแกน x ครบ หลังติดตั้งแล้ววัดความกว้างจริงด้วย ResizeObserver

## Usage

```tsx
import { BarChart } from '@/components/BarChart';

<BarChart
  summary="ข่าวที่สร้างและการเข้าชมรายวัน 31 วัน การเข้าชมสูงสุดวันที่ 21"
  categoryLabel="วันที่"
  categories={days}
  series={[
    { label: 'ข่าวที่สร้าง', values: news, axis: 'right' },
    { label: 'การเข้าชม', values: views, axis: 'left' },
  ]}
/>
```

### แกนเดียว

ทุกชุดอยู่แกนซ้าย แกนขวาปิดเองโดยอัตโนมัติ (หรือส่ง `showRightAxis={false}`)

```tsx
<BarChart
  summary="ข่าวที่สร้างและข่าวที่เผยแพร่รายวัน"
  categories={days}
  series={[
    { label: 'ข่าวที่สร้าง', values: created },
    { label: 'ข่าวที่เผยแพร่', values: published },
  ]}
/>
```

### จัดรูปตัวเลขบนแกนเอง

```tsx
<BarChart
  {...props}
  formatValue={{ left: (v) => `${v / 1000} พัน` }}
/>
```

## Props

| Prop | ชนิด | ค่าเริ่มต้น | Figma | คำอธิบาย |
|---|---|---|---|---|
| `summary` | `string` | (บังคับ) | | สรุปใจความของกราฟเป็นประโยค ไปเป็น `aria-label` ของกราฟและ caption ของตารางที่ซ่อนไว้ |
| `categories` | `string[]` | (บังคับ) | | ป้ายแกน x หนึ่งป้ายต่อหนึ่งกลุ่มแท่ง |
| `series` | `BarChartSeries[]` | (บังคับ) | | ชุดข้อมูล รองรับ 2 ชุด ชุดแรกสีเข้ม (series-1) ชุดที่สองสีอ่อนมีขอบ (series-2) |
| `categoryLabel` | `string` | `'รายการ'` | | หัวคอลัมน์แรกของตารางที่ซ่อนไว้ เช่น `วันที่` |
| `showLegend` | `boolean` | `true` | `show-legend` | แสดงคำอธิบายสีด้านบน ซ้ายคือชุดของแกนซ้าย ขวาคือชุดของแกนขวา |
| `showRightAxis` | `boolean` | มีชุดที่ `axis: 'right'` | `show-right-axis` | แสดงป้ายแกน y ด้านขวาและชื่อแกนขวา |
| `formatValue` | `{ left?, right? }` | `Intl.NumberFormat('th-TH', { notation: 'compact' })` | | จัดรูปตัวเลขบนแกน y แยกต่อข้าง ตารางที่ซ่อนไว้ใช้ตัวเลขเต็มเสมอ |
| `height` | `number` | `340` | | ความสูงของพื้นที่กราฟเป็นพิกเซล เป็นค่าผังของหน้า ไม่ใช่ token |

`BarChartSeries`

| ฟิลด์ | ชนิด | คำอธิบาย |
|---|---|---|
| `label` | `string` | ชื่อชุด แสดงในคำอธิบายสีและเป็นหัวคอลัมน์ของตาราง |
| `values` | `number[]` | ค่าของแต่ละหมวด เรียงตรงกับ `categories` ค่าติดลบปัดเป็น 0 |
| `axis` | `'left' \| 'right'` | แกนที่ใช้วัด ค่าเริ่มต้น `left` |

## กติกา

- **แกน y** 4 ช่อง 5 เส้นเสมอ เท่ากันทั้งสองแกน เส้นกริดจึงตรงกัน ขั้นปัดขึ้นจากชุด 1, 1.5, 2, 2.5, 3, 4, 5, 6, 8 คูณสิบยกกำลัง เริ่มที่ 0 เสมอ ตัวอย่าง One CMS ได้ 0 ถึง 240K และ 0 ถึง 80
- **สี** มีแค่ 2 ชุด ส่งเกินจะเตือนในโหมดพัฒนาและไม่วาดชุดที่เกิน ห้ามเติมสีเอง ให้ขอ token ก่อน
- **ความกว้าง** ยืดเต็มกรอบแม่เสมอ ไม่มี prop ความกว้าง
- **จอแคบ** ช่องต่อกลุ่มตั้งแต่ 24 พิกเซลแสดงป้ายแกน x ทุกตัว แคบกว่านั้นแสดงเฉพาะ 1, 5, 10, 15, 20, 25, 30 ต่ำกว่า 14 พื้นที่กราฟเลื่อนแนวนอนได้ แกน y สองข้างตรึงอยู่กับที่
- **การเข้าถึง** ห่อด้วย `<figure>` ตัวกราฟเป็น `role="img"` ที่ชื่อมาจาก `summary` ข้าง ๆ มี `<table>` จริงที่ซ่อนจากสายตา แสดงตัวเลขเต็ม (240,000) แท่งไม่รับโฟกัสในรอบนี้ ไม่มีแอนิเมชัน
- ห้ามแต่งสี ระยะ หรือมุมโค้งจากข้างนอกด้วย `className` หรือ `style`

## ยังไม่มีในรอบนี้

- tooltip และการโฟกัสแท่งด้วยคีย์บอร์ด
- ชุดที่ 3 ขึ้นไป (ยังไม่มี token สี)
- กราฟเส้นหรือแท่งผสมเส้น
