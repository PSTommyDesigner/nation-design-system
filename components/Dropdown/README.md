# Dropdown

ช่องที่กดแล้วเปิดแผงรายการให้เลือกค่าเดียว ตรงกับ component set ใน Figma หน้า **27 Dropdowns** ครอบคลุมชุด `dropdown` (ช่อง) `dropdown-menu` (แผง) และชุดฐาน `_dropdown-option` กับ `_dropdown-group-header`

ใช้ token จาก `tokens/scale/dropdown.mjs` ซึ่งยืมความสูง ระยะขอบ ช่องไฟ ขนาดไอคอน และมุมโค้งจากช่องกรอกหน้า 13 Input ทั้งก้อน

## Props

| Prop | ชนิด | ค่าตั้งต้น | คำอธิบาย |
|---|---|---|---|
| `options` | DropdownOption[] | ต้องใส่ | รายการตัวเลือก เรียงตามลำดับที่จะแสดงจริง |
| `label` | ReactNode | ไม่มี | ป้ายชื่อเหนือช่อง เป็นชื่อที่โปรแกรมอ่านหน้าจออ่าน |
| `hint` | ReactNode | ไม่มี | ข้อความช่วยใต้ช่อง เปลี่ยนเป็นสีแดงเมื่ออยู่ในสถานะผิดพลาด |
| `placeholder` | string | ไม่มี | ข้อความตอนยังไม่ได้เลือก |
| `value` / `defaultValue` | string | ไม่มี | ค่าที่เลือก แบบคุมเอง / แบบปล่อยให้ component คุม |
| `onValueChange` | (value) => void | ไม่มี | เรียกเมื่อผู้ใช้เลือกค่า |
| `size` | `sm` `md` `lg` | `md` | **มีแค่ 3 ขนาด** เท่าช่องกรอกหน้า 13 Input |
| `error` | boolean | `false` | สถานะผิดพลาด ต้องมีข้อความอธิบายใน `hint` คู่เสมอ |
| `required` | boolean | `false` | แสดงดอกจันท้ายป้ายชื่อ |
| `disabled` | boolean | `false` | ปิดใช้งาน |
| `readOnly` | boolean | `false` | รับโฟกัสได้แต่เปิดแผงไม่ได้ |
| `name` | string | ไม่มี | ชื่อฟิลด์สำหรับส่งฟอร์ม แนบช่องซ่อนให้หนึ่งช่อง |
| `emptyText` | string | มีค่าในตัว | ข้อความตอนรายการว่าง |

แต่ละแถวใน `options` รับ `value` `label` `supportingText` `leadingIcon` `avatarSrc` `avatarName` `disabled` และ `group` (แถวที่สังกัดหัวกลุ่มเดียวกันต้องวางติดกัน)

## ตัวอย่าง

```tsx
<Dropdown label="จังหวัด" placeholder="เลือกจังหวัด" options={[
  { value: 'bkk', label: 'กรุงเทพมหานคร' },
  { value: 'cnx', label: 'เชียงใหม่' },
]} />
<Dropdown label="ประเภท" options={richOptions} size="lg" onValueChange={setType} />
```

## แผงลอยชั้นบนสุด (แก้ 2026-11-26)

แผงเปิดเป็น popover ของเบราว์เซอร์ จึงลอยอยู่ชั้นบนสุดของหน้าและไม่โดนกรอบที่เลื่อนได้ตัด เช่นกรอบของ `Table` (เจอที่หน้า 5 จัดการ role ของ ATS) ตำแหน่งคำนวณจากช่องทุกครั้งที่เลื่อนหรือเปลี่ยนขนาดจอ และเปิดขึ้นด้านบนเมื่อด้านล่างที่ว่างไม่พอ เบราว์เซอร์ที่ไม่มี popover ใช้แผงแบบเดิมที่วางใต้ช่อง

**ห้ามแก้ปัญหาแผงโดนตัดด้วยการแต่งกรอบแม่จากข้างนอก** เช่น ใส่ overflow หรือ z-index ให้กรอบของ `Table` ถ้าเจอกรณีที่แผงยังโดนตัด ให้รายงานเป็นงานของ Dropdown

## ข้อควรระวัง

1. **ถ้าเป็นการเลือกค่าในฟอร์มธรรมดา ให้ใช้ช่องเลือกของเบราว์เซอร์ก่อนเสมอ** (เอกสารหน้า 27 คู่มือนักพัฒนาข้อ 1) ตัวนี้มีไว้สำหรับแถวที่มีไอคอน อวาตาร์ ข้อความรอง หรือหัวกลุ่ม
2. **ตัวเลือก 2 ข้อควรเป็น Radio หรือ Toggle** ไม่ใช่ Dropdown (ดูควรและไม่ควรใน Storybook)
3. **ยังไม่รองรับการเลือกหลายค่า และยังไม่รองรับการพิมพ์กรอง** ถ้ารายการยาวเกิน 15 ตัว ให้รอชิ้นงานที่พิมพ์กรองได้ อย่าดัดตัวนี้
4. **ใช้ในที่ที่ไม่มีป้ายชื่อที่มองเห็น เช่น ในเซลตาราง ช่องจะไม่มีชื่อให้โปรแกรมอ่านหน้าจอ** ยังไม่มี prop สำหรับตั้งชื่อแบบซ่อน เป็นงานค้าง (จด 2026-11-26)
5. ความสูงแผงใช้ `--ntg-dropdown-panel-max-height-*` แล้วปล่อยให้แถบเลื่อนของเบราว์เซอร์ทำงาน ห้ามทำแถบเลื่อนเอง
