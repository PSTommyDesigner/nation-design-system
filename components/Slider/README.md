# Slider

แถบเลื่อนเลือกค่าตัวเลขในช่วงที่กำหนด ตรงกับไฟล์ออกแบบหน้า **17 Sliders**

ตัวเดียวทำได้ทั้งสองแบบ โดยดูจากรูปของค่า

| ค่าที่ส่งเข้าไป | ได้อะไร | ชุดในไฟล์ออกแบบ |
|---|---|---|
| `value={40}` | ปุ่มจับหนึ่งอัน | `slider` |
| `value={[20, 60]}` | ปุ่มจับสองอัน | `range-slider` |

ฝั่งไฟล์ออกแบบแยกเป็นสองชุดเพราะแผง Assets เห็นแค่ชื่อ แต่กลไกเหมือนกันทุกอย่าง จึงรวมเป็นตัวเดียวในโค้ด

## Usage

```tsx
import { Slider } from '@/components/Slider';

<Slider label="ความดัง" value={v} onValueChange={setV} />

<Slider
  label="ช่วงราคา"
  rangeLabels={['ราคาต่ำสุด', 'ราคาสูงสุด']}
  value={[lo, hi]}
  onValueChange={setRange}
  showValueTooltip
  showMinMaxLabel
  formatValue={n => `${n.toLocaleString()} บาท`}
/>

<Slider label="ระยะทาง" value={v} size="lg" touchTarget />
```

## Props

| prop | ค่าเริ่มต้น | หน้าที่ |
|---|---|---|
| `value` | จำเป็น | ตัวเลขเดี่ยวหรือคู่ตัวเลข เป็นตัวบอกว่าเป็นแบบไหน |
| `onValueChange` | | คืนค่าในรูปเดียวกับที่ส่งเข้าไป |
| `min` `max` `step` | `0` `100` `1` | ช่วงค่าและก้าวเล็ก |
| `largeStep` | `step × 10` | ก้าวใหญ่ของ Page Up และ Page Down |
| `size` | `md` | `xs` ถึง `xl` |
| `disabled` | `false` | เปลี่ยนสีทั้งราง แถบเติม และปุ่มจับ |
| `label` | | ชื่อที่โปรแกรมอ่านหน้าจอจะอ่าน |
| `rangeLabels` | | ชื่อของปุ่มจับแต่ละอันในแบบช่วง |
| `formatValue` | | แปลงตัวเลขเป็นข้อความ ใช้กับป้ายและ `aria-valuetext` |
| `showValueTooltip` | `false` | ป้ายค่าเหนือปุ่มจับ ตรงกับ `value-tooltip` |
| `showMinMaxLabel` | `false` | ป้ายต่ำสุดสูงสุดใต้ราง ตรงกับ `min-max-label` |
| `touchTarget` | `false` | ยกความสูงแถวถึงพื้นที่แตะขั้นต่ำสำหรับจอสัมผัส |

## โครงสองชั้น

เหมือน [`Toggle`](../Toggle/README.md) และช่องติ๊ก

| ชั้น | มาจาก | หน้าที่ |
|---|---|---|
| ภาพ | `--ntg-slider-handle-*` และ `--ntg-slider-track-*` | สิ่งที่ตาเห็น มีสเกลของตัวเอง |
| แถวที่กดได้ | `--ntg-slider-row-height-*` | พื้นที่แตะจริง อ้างสเกลความสูงเดียวกับปุ่มและช่องกรอก |

เกณฑ์ WCAG ข้อ 2.5.8 นับแถบเลื่อนทั้งตัวเป็นเป้าเดียว และข้อ 2.5.7 ต้องแตะที่รางได้ ความสูงที่มีผลจริงจึงเป็นแถว ไม่ใช่ปุ่มจับ

## แป้นพิมพ์

ตามมาตรฐาน WAI-ARIA Authoring Practices

| ปุ่ม | ผล |
|---|---|
| ลูกศรขวา ขึ้น | เพิ่มหนึ่งก้าวเล็ก |
| ลูกศรซ้าย ลง | ลดหนึ่งก้าวเล็ก |
| Page Up · Page Down | เพิ่มหรือลดหนึ่งก้าวใหญ่ |
| Home · End | ไปค่าต่ำสุดหรือสูงสุด |

แบบช่วง ปุ่มจับแต่ละอันเป็นจุดโฟกัสของตัวเอง และเลื่อนข้ามกันไม่ได้

## ข้อควรระวัง

- **แบบช่วงต้องมีช่องกรอกตัวเลขคู่เสมอ** ผลทดสอบผู้ใช้พบว่าคนอ่านแบบช่วงผิดเกินครึ่ง แถวของแถบเลื่อนสูงเท่าช่องกรอกอยู่แล้ว จึงวางเรียงแถวเดียวกันได้พอดี
- **อย่าใช้กับช่วงวันที่ ขนาดตัวอักษรที่มีไม่กี่ระดับ หรือความคืบหน้า** เหตุผลเต็มอยู่ในเอกสาร `Slider Usage` หน้า 17
- **กรอบที่ครอบต้องไม่ตัดขอบ** ปุ่มจับล้นพ้นรางขึ้นลงข้างละ 4 ถึง 12 แล้วแต่ขนาด
- **ความยาวยืดเต็มกรอบแม่** ไม่มี token ความยาวโดยตั้งใจ
- **สถานะกดเปลี่ยนแค่สี** ห้ามขยายหรือหดปุ่มจับ ให้ตรงกับที่ตัดสินไว้กับสวิตช์

## แถบเลื่อนของเครื่องเล่นสื่อเป็นคนละตัว

แถบเลื่อนตำแหน่งของเสียงและวิดีโอมีค่าที่เปลี่ยนเองตลอดและมีชั้นข้อมูลเพิ่มคือส่วนที่โหลดไว้แล้ว ควรเป็น component แยกในตระกูลเครื่องเล่นสื่อ แต่หยิบ token ของรางและปุ่มจับชุดนี้ไปใช้ร่วมกันได้
